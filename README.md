## ⚠️ 超大文件说明（重要）

GitHub 单文件硬上限为 **100 MiB**。本仓库有 **7 个文件超过该限制**（共约 1.38 GiB），
因此已按 **90 MiB** 分卷为同名 `.part-NNN` 文件存放。

**克隆后运行以下命令即可完整还原：**

```bash
./restore-large-files.sh
```

脚本会自动按序合并所有分卷，并用 SHA-256 校验完整性。

只校验不合并：

```bash
./restore-large-files.sh --verify-only
```

分卷清单与校验值见 [`LARGE-FILES.md`](./LARGE-FILES.md)。

> 还原出的原始文件与 `.gitignore` 规则同名，git 不会追踪它们，可放心还原。

## 🔧 还原脚本说明

`restore-large-files.sh` 特性：

- ✅ 兼容 macOS 自带 **bash 3.2**（不使用 `mapfile` 等 bash 4+ 语法）
- ✅ 合并后 **SHA-256 逐文件校验**，损坏立即报错退出
- ✅ **幂等**：已正确还原的文件自动跳过，可重复执行
- ✅ 支持 `--verify-only` 纯校验模式
