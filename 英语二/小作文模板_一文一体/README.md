# 英语二小作文 · 一文一模版

16 页 PDF，12 类文体，每类一篇可直接默写的整篇模板。

## 文件

| 文件 | 说明 |
|---|---|
| `英语二小作文_一文一模版.pdf` | 成品，A4，可直接打印 |
| `build_pdf.py` | 生成 LaTeX 并调用 XeLaTeX 编译，含词数统计与预览导出 |
| `content.py` | 12 类文体的模板、真题填槽、换装表、得分点、升级句、变体 |
| `英语二小作文_一文一模版.tex` | 编译产物，可单独重编译 |
| `preview/p01.png` … `p16.png` | 每页预览图 |

## 结构

1. 封面：用法与目录
2. 第 2 页：评分四维、格式四要素、通知格式、三段句数、词数与时间、六条铁律
3. 第 3 页：2010—2026 真题地图、合并题切法、文体频次
4. 第 4—15 页：12 类文体，每页六块
   - 一、整篇模板（带【槽位】）
   - 二、真题落地（同一篇填好的 95—105 词）
   - 三、换装表（槽位 / 真题填法 / 备用词块）
   - 四、阅卷人找什么 + 两个坑
   - 五、9 分升级句
   - 六、题干变体怎么改
5. 第 16 页：60 秒自评、档位定位、12 组高频错误、通用零件

## 重新编译

```bash
cd 英语二/小作文模板_一文一体
python3 build_pdf.py
```

依赖：XeLaTeX（`/Library/TeX/texbin`）、ctex、Times New Roman、PyMuPDF（仅用于预览与页数检查）。

## 说明

- 正文词数为实际统计（不含称呼、结束语、署名），全部在 95—105。
- 英文为原创，骨架按文体重写，不照搬南山《小作文万用模版》的万能句。
- 评分档位按工作区《批改指令》的民间参考标准整理，不人为封顶。
