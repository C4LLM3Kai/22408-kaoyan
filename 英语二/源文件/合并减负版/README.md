# 英语二作文：5套核心合并版

最终文件：`../../英语二作文_5套核心合并版.pdf`，9页。

本版响应用户“减少背诵、相似文体直接合并”：前版36类归入5套核心与少量查阅卡。第2—6页为核心，第7页为功能句替换，第8页为格式卡，第9页为备用材料入口与核对。5个完整示例用于理解，不作为额外背诵要求。

固定框架196个英文词（含静态、动态开头，不含填空、格式与功能卡）；小作文示例正文99—103词，大作文144词。来源评分原则保持不变。

## 可编辑与复现

- `content.py`：核心正文、示例及原36类归并映射。
- `content.json`：当前结构化正文。
- `build.py`：生成TeX。
- `英语二作文_5套核心合并版.tex`：自包含LaTeX源文件。
- `check.py`：复用上一版提取的40份原始PDF文本执行重合检查。
- `重合检查.json`：完整比对结果。
- `核对结果.json`：页数、正文完整性、原36类覆盖与编译检查。
- `预览/`：逐页渲染。

在本目录执行：

```sh
python3 content.py
python3 check.py
python3 -W ignore build.py
xelatex -interaction=nonstopmode -halt-on-error 英语二作文_5套核心合并版.tex
xelatex -interaction=nonstopmode -halt-on-error 英语二作文_5套核心合并版.tex
```
