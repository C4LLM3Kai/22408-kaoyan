## 手册结构

按 **马原 → 史纲 → 新思想** 三大板块重组，共 5 个一级章节、18 个二级章节：

1. **马克思主义基本原理**（5 节）— 基本知识、资本、生产和价值、政经计算、国际
2. **中国近现代史纲要**（9 节）— 旧民主主义革命、新文化运动、帽子题、革命开端、毛泽东思想著作、三大辨析、重要专题、1949 年后会议、建国后
3. **习近平新时代中国特色社会主义思想**（5 节）— 法、党、发展、帽子题汇总、大专题

## 排版设计

- **卡片式**：蓝底标题条 + 浅底内容区，一张卡片一个考点
- **三层视觉层次**：深蓝横幅（部分）→ 蓝色竖条（章节）→ 小标题（考点）
- **颜色语义**：蓝色=考点标题，红色=关键结论，砖红竖条=易错辨析，浅蓝底=必背结论
- **表格**：统一三线表，无竖线，打印干净
- **助记口诀**全部保留（如"六个寓于"的 J>S 驾驭、B>O 碧玉等谐音）

## 重新编译

需要 TeX Live（XeLaTeX）+ 中文字体 Songti SC / Heiti SC / Times New Roman。

```bash
cd 源文件
xelatex -interaction=nonstopmode zz-main.tex
xelatex -interaction=nonstopmode zz-main.tex   # 第二遍生成目录与页码
cp zz-main.pdf ../考研政治重点总结手册.pdf
```

### 自定义宏

| 宏 | 用途 |
|---|---|
| `\zzchapter{...}` | 一级标题（深蓝横幅，进目录） |
| `\zzsection{...}` | 二级标题（竖条，进目录） |
| `\zzsub{...}` | 段内小标题 |
| `\zzcard{标题}{内容}` | 卡片（原子，不跨页） |
| `\zzlongcard{标题}{内容}` | 可跨页卡片（长内容用） |
| `\zzkey{...}` | 必背结论条（深蓝竖条） |
| `\zzwarn{...}` | 易错/辨析（砖红竖条） |
| `\kw{...}` | 关键字（红色加粗） |
| `\bk{...}` | 强调（黑色加粗） |
| `zztable2` / `zztable3` | 两列/三列三线表 |
| `zzltable2` / `zzltable3` | 可跨页长表 |
