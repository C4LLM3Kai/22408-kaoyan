## 定长扩展操作码切法
**考频**：2026/2021/2015（第43/44题）｜三年三考，指令格式题的第一小问，4–6 分起步
**必背结论**
- 指令 = 操作码 + 地址码。指令字长固定时，操作码每扩展一级就吃掉一个地址码字段，地址码个数减 1。
- 操作码位数只决定指令条数：$n$ 位操作码最多 $2^{n}$ 条指令，与地址码几位无关。问「最多多少条」只数操作码。
- 扩展的合法做法：短操作码只留出恰好 1 个编码当扩展窗口，长操作码只能用这个窗口内的编码，短操作码已用掉的编码不许再出现。
- 通用式：$t$ 级扩展、每级 $k$ 位 → 前 $t-1$ 级各 $2^{k}-1$ 条，最后一级 $2^{k}$ 条，总数 $(t-1)(2^{k}-1)+2^{k}$。
- 最常考的四个数字（4 位一段，三/二/一/零地址四级）：15 + 15 + 15 + 16 = 61 条。
- 各地址格式要能一句答出：三地址＝两源一目的；二地址＝目的兼作源；一地址＝另一操作数隐含在 ACC；零地址＝无操作数或操作数在栈顶。
- 2015 年「访存时钟」那一问：地址码里每有一个是内存地址，执行阶段就多一次访存；三个地址全在内存 → 执行阶段读两次写一次，共 3 次访存。
- 2021 年是 R/I/J 三类格式：R 型操作数全在寄存器、I 型带立即数或地址、J 型带跳转地址；问「某类最多几条」仍只看该类操作码位数。
- 先扣地址码再算操作码：指令字长 16 位、地址码各 4 位、双操作数 → 操作码位数为 $16-4\times2=8$ 位，最多 $2^{8}=256$ 条。
- 2026 年多格式定长编码：同一 16 位字长下几种格式共用前几位操作码，求值时先按操作码判格式，再按该格式的字段边界取数，不许跨格式借位。
> 切位顺序永远是「先短码、后长码」，短码数 = $2^{k}-1$，因为必须留 1 个窗口给下一级。

**模板/流水线**

```c
/* 定长指令字 + 扩展操作码：4 位一段，三/二/一/零地址四级 */
/* 指令字长 16 位 = OP(4) + A1(4) + A2(4) + A3(4) */
/* 第 1 级 三地址：0000~1110 共 15 条，1111 留作扩展窗口 */
int c3 = (1 << 4) - 1;                 /* 15 */
/* 第 2 级 二地址：1111 + 原 A1 的 4 位，仍留 1 个窗口 */
int c2 = (1 << 4) - 1;                 /* 15 */
/* 第 3 级 一地址：再吃一个 4 位，仍留 1 个窗口 */
int c1 = (1 << 4) - 1;                 /* 15 */
/* 第 4 级 零地址：不用再留窗口，全部可用 */
int c0 = (1 << 4);                     /* 16 */
int total = c3 + c2 + c1 + c0;         /* 61 条 */
/* 通用式：t 级扩展、每级 k 位 => (t-1)*(2^k-1) + 2^k */
/* 不做扩展时：条数 = 2^操作码位数，别再自作主张减 1 */
/* 反向题：给了各级条数，按 2^k 减去本级条数反推窗口数 */
```
! 长操作码只能取扩展窗口内的编码，短码用过的编码再出现就是错·每一级必须恰好留 1 个窗口，留 0 会越界、留 2 条数就对不上·扩展操作码的前提是指令字长固定，遇到不定长格式这套算法不能套

## 寻址方式全表与 EA
**考频**：2010/2023/2024（第43/44题）｜大题里只作一问，选择题几乎年年考
**必背结论**
- 形式地址 $A$ 是地址码里那个数；有效地址 $EA$ 是操作数真正所在的地址；操作数 $X$ 要在 $EA$ 上再取一次内容。
- 括号就是「取内容」：$EA=(A)$ 表示 A 号单元的内容才是地址，操作数 $X=((A))$，多一层括号就多访存一次。
- 访存次数（不含取指）：立即 0、寄存器 0、直接 1、寄存器间接 1、间接 2。答题写「多一次访存」比写「慢」得分。
- 基址与变址只差一句：基址是 BR 不变、地址码变（便于程序浮动与重定位）；变址是 IX 变、地址码不变（专治数组）。
- 真题口径比书上多两步：变址取数组元素地址 $=A+i\times$ 元素字节数（A 是数组首地址、i 是下标）；相对寻址的 PC 用自增后的值。
- 立即寻址的数就摆在指令里，取值范围受指令字长限制；间接寻址的 A 是形式地址，寻址范围由存储字长决定。
- 指令里为什么要多一个寻址特征字段：同一个寄存器编号，寄存器寻址与寄存器间接寻址的执行流程不一样，只能靠它区分。
- 堆栈寻址的操作数在栈顶，$EA$ 由 SP 隐含给出：入栈先 $SP-1\to SP$ 再存数，出栈先取数再 $SP+1\to SP$（栈向低地址生长）。
- 用途对照比公式好记：相对寻址配转移指令，基址配多道程序重定位，变址配数组循环，堆栈配子程序调用与参数传递。

| 寻址方式 | EA | 取操作数访存 | 典型用途 |
|---|---|---|---|
| 隐含 | 无（操作数在 ACC） | 0 | 一地址指令的第二个操作数 |
| 立即 | 无（数在指令中） | 0 | 常数、计数初值 |
| 直接 | `EA=A` | 1 | 一般变量 |
| 间接 | `EA=(A)` | 2 | 指针、扩大寻址范围 |
| 寄存器 | `EA=R`（数在 R 中） | 0 | 中间结果、循环变量 |
| 寄存器间接 | `EA=(R)` | 1 | 指针、参数传递 |
| 相对 | `EA=(PC)+A` | 1 | 转移指令、程序浮动 |
| 基址 | `EA=(BR)+A` | 1 | 多道程序重定位 |
| 变址 | `EA=(IX)+A` | 1 | 数组、字符串 |
| 堆栈 | 栈顶由 SP 隐含 | 1 | 现场保护、子程序调用 |

**模板/流水线**

```c
/* 判寻址方式只看括号：括号套几层，就多访存几次 */
/* R4      -> 寄存器寻址：操作数 = (R4)，不访存 */
/* (R4)    -> 寄存器间接：EA = (R4)，再访存一次才拿到数 */
/* ((R4))  -> 再间接一层：EA = ((R4))，访存两次 */
/* A       -> 直接寻址：EA = A，访存一次 */
/* (A)     -> 间接寻址：EA = (A)，访存两次 */
/* #10     -> 立即寻址：操作数就是 10，一次也不访存 */
/* 相对寻址：EA = 当前指令地址 + 指令长度 + 系数 * 偏移量 */
/* 变址取数组：EA = 首地址 + 下标 * 元素字节数（不是下标本身） */
unsigned int ea;
if (reg_indirect)   ea = R[4];            /* 一次访存 */
else if (indirect)  ea = mem[A];          /* 两次访存 */
else if (direct)    ea = A;               /* 一次访存 */
else if (indexed)   ea = IX + A * 4;      /* A 是首地址，4 是元素字节数 */
```
! 间接寻址写 $EA=(A)$、操作数写 $((A))$，差一层括号就丢分·寄存器寻址 $EA=R$ 而操作数是 $(R)$，一次也不访存·基址与变址「谁不变」最容易背反，记「基址不动地址码动，变址动地址码不动」

## 相对寻址求转移目标
**考频**：2013/2014/2019（第43/44题）｜汇编大题的核心一问，三年三考
**必背结论**
- 目标地址 $=(PC)+\text{指令长度}+\text{系数}\times A$，式子里的 PC 是「取指后已自增」的值，不是当前指令地址。
- 一句话记：先把 PC 推到下一条指令，再加偏移量；顺序执行时 PC 直接加指令长度。
- 偏移量是有符号补码，必须先求真值再乘系数：8 位补码 $E3H$ 的真值是 $-29$，不是 $227$。
- 8 位补码范围 $-128\sim+127$：$A=-1$ 原地踏步（跳回自己），$A\ge 0$ 向高地址，$A\le-2$ 向低地址。
- 向后可用条数：$(-2)-(-128)+1=127$ 条，闭区间计数一律「末 − 首 + 1」。
- 系数从题干读：偏移量以「字/半字」为单位、或「每条指令 $n$ 字节」时要乘；2013、2014 两年系数都是 2。
- 2013 年条件转移还考标志位：无符号比较「小于等于」判 $CF$ 与 $ZF$（小于→$CF=1$；等于→$CF=0$ 且 $ZF=1$），检测位写 110；问的是「检测哪几位」不是「CF 等于几」。
- 反过来给目标地址求偏移量：$A=(\text{目标}-(PC+\text{指令长度}))\div\text{系数}$，算出的负数就是补码真值，再写成补码字节；2019 年递归题就是这么倒推出调用入口的。
- 跳转范围由偏移量字段的宽度决定（8 位 → 127 条），不是由整条指令字长决定；指令字长只管系数，两件事别混。
- 指令长度从题干的行地址差读出：下一行地址减本行地址就是本条指令的字节数（差 5 就是 5 字节），别一律默认 2 字节。

**模板/流水线**

```c
/* 转移目标 = 取指后 PC + 系数 * 偏移量（偏移量是有符号补码） */
/* 例：当前指令 200CH，指令长 2 字节，偏移量字节 E3H，系数 2 */
int pc_next = 0x200C + 2;                  /* 先推到下一条 = 200EH */
signed char off = (signed char)0xE3;       /* 求真值 -29，不能直接加 E3 */
int target = pc_next + 2 * off;            /* 0x200E - 58 = 1FD4H */
/* 等价算法：0x200C - 0x38 = 0x1FD4，两条路必须对得上 */
/* 向后条数：8 位补码 -128 ~ -2 可用 => (-2)-(-128)+1 = 127 条 */
/* 已知目标反求偏移：(target - pc_next) / 系数，负数写成补码 */
/* 若问「顺序执行时的地址」：不转移就是 pc_next，别加偏移量 */
```
! PC 用「取指后」的值，拿当前指令地址加偏移量必错·无符号地址与有符号偏移量不能直接按补码相加，先求真值·区间里有多少个数别忘 +1，向后是 127 条不是 128 条

## 机器码与汇编互译
**考频**：2023/2024（第43/44题）｜新大纲机器级表示，2023 起连续两年出现，5–8 分
**必背结论**
- 一道汇编语句 = 操作码 + 若干「寻址特征位 + 寄存器号/地址码」字段，字段宽度与顺序全部按题目给的格式表，不按书上。
- 拼机器码只做两件事：按格式表逐字段填二进制，再每 4 位一组转十六进制；先补足位数再分组。
- 反方向（机器码 → 汇编）先按同一张格式表切位，再查操作码表与寻址方式表还原助记符，最后按括号规则写成汇编。
- 操作数读法只看括号：写 `R4` 是寄存器（数在寄存器里），写 `(R4)` 是寄存器间接（寄存器里放的是地址），写 `((R4))` 再取一层。
- 大小端判据只看「字节落在哪个地址」：低字节放低地址 = 小端，高字节放低地址 = 大端。
- 判断步骤：把数写成 4 个字节（高位在前），再看内存从低地址到高地址给的字节序列与哪个顺序一致。
- 2024 年「字节重组」口径：先定大小端，再按操作数宽度（1/2/4 字节）从内存取够字节，按地址由低到高拼回一个整数，别把字节序当数值序抄。
- 2010 年「各类寻址机器码」口径：操作码 4 位 + 两个操作数各 3 位寻址方式 + 3 位寄存器号，凑满 16 位再转十六进制。
- 2023 年把跳转与大小端放在一起考：偏移量字段落在指令的高字节还是低字节，取决于指令编码的字节序，取字段前先定序。
- 定长与不定长是判 RISC 与 CISC 的唯一判据：指令长度固定 → 精简指令集；长度不定 → 复杂指令集。

**模板/流水线**

```c
/* 机器码 <-> 汇编：按格式表切位，别自己发明字段宽度 */
/* 例：16 位定长，OP(4) MOD(3) R(3) MOD(3) R(3) */
unsigned short code = 0;
code |= (op & 0xF) << 12;                  /* 操作码 4 位 */
code |= (md1 & 0x7) << 9;                  /* 目的操作数寻址方式 3 位 */
code |= (r1 & 0x7) << 6;                   /* 目的寄存器号 3 位 */
code |= (md2 & 0x7) << 3;                  /* 源操作数寻址方式 3 位 */
code |= (r2 & 0x7);                        /* 源寄存器号 3 位 */
printf("%04XH\n", code);                   /* 每 4 位一组转十六进制 */
/* 反方向：先切位，再由表还原助记符 */
op  = (code >> 12) & 0xF;  md1 = (code >> 9) & 0x7;  r1 = (code >> 6) & 0x7;
md2 = (code >> 3)  & 0x7;  r2  =  code        & 0x7;
/* 大小端：把 x 拆成 4 个字节，看最低地址放的是谁 */
unsigned char b[4];
b[0] = x & 0xFF; b[1] = (x >> 8) & 0xFF;
b[2] = (x >> 16) & 0xFF; b[3] = (x >> 24) & 0xFF;
/* b[0] 落在最低地址 => 小端；b[3] 落在最低地址 => 大端 */
```
! 寻址方式位 3 位最多 8 种方式，别和 4 位操作码混着数·大小端看的是字节在内存里的先后，不是数值书写顺序·结果写回的是「目的操作数」，寄存器自增、指针回写这类隐含动作别漏

## 汇编循环三件套
**考频**：2014/2019（第43/44题）｜循环与递归汇编三年两考，和相对寻址一起给分
**必背结论**
- 循环三件套：入口（标号地址）＋计数器（或指针）递减＋条件转移回入口。缺一件就是死循环或漏一次。
- 计数器型循环：先置初值 $n$，循环体末尾 `DEC`（或 `SUB` 置零标志），再用 `JNE` 回跳；判据是上一条指令设的标志位。
- 指针型循环（数组）：基址或变址寄存器当指针，按字节编址时每次 `ADD R,4`（元素 4 字节），按字编址时加 1。
- 循环体执行 $n$ 次、出口转移执行 $n$ 次（最后一次不跳）；顶部先判的 while 型，判断要执行 $n+1$ 次。
- 递归：`CALL` 压栈、`RET` 弹栈；调用次数 = 递归深度（$f(10)$ 依次算 10,9,…,1，共 10 次调用）。
- 数组求和套路：R0 清零当累加器、R1 存计数、R2 存指针，循环体 `ADD R0,(R2)` → `ADD R2,4` → `DEC R1` → `JNE` 回跳。
- 一定会让程序跳转执行的三条：`CALL`、`RET`、无条件 `JMP`；`Jcc` 要看标志位，条件不成立就顺序执行。
- 循环结束条件写反最致命：计数器递减用 `JNE`（不为零继续），计数器递增用 `JNE` 也行、但配 `CMP` 判上界时要看清是 `JLE` 还是 `JGE`。
- 2014 年循环汇编还要接着算流水线：循环体里相邻两条若构成写后读且间隔不足 3 条，每轮都要阻塞，轮数 × 阻塞拍数才是总代价。
- 数组循环里首地址与下标分工：形式地址 A 放首地址、变址寄存器放下标，取第 i 个元素先算 $A+i\times$ 元素大小；改成指针写法时指针初值才是首地址，每轮加元素大小。

**模板/流水线**

```c
/* 汇编循环模板：先写 C，再逐句译，别跳过计数器 */
int s = 0;                     /* MOV R0, 0      ; 累加器清零   */
int i = n;                     /* MOV R1, n      ; 计数器 = 次数 */
loop:                          /* L1:            ; 循环入口地址 */
    s = s + a[i - 1];          /* ADD R0, (R2)   ; 取元素累加   */
    i = i - 1;                 /* DEC R1         ; 计数器减一   */
    p = p - 4;                 /* SUB R2, 4      ; 指针前移一个元素 */
    if (i != 0) goto loop;     /* JNE L1         ; 非零回跳     */
/* 三件套自查：① 有入口标号 ② 计数器递减 ③ 条件转移回入口 */
/* 按字节编址加元素字节数，按字编址加 1，别加元素边长 */
/* 递归版：CALL 前参数入栈，RET 后取返回值；调用次数 = 递归深度 */
```
! 条件转移的判据是「上一条指令设置的标志位」，CMP 之后若插了不设标志的指令判断就废了·按字节编址时指针加的是元素字节数不是元素个数·循环体次数与转移执行次数不一定相等，先判后做的会多判一次

## 单总线取指周期微操作
**考频**：2009/2015（第43/44题）｜数据通路大题的开局送分题，默写即得分
**必背结论**
- 取指周期四步，顺序背死：`(PC)→MAR`、`M(MAR)→MDR`、`(MDR)→IR`、`(PC)+1→PC`。
- 顺序不能颠倒的理由：地址不进 MAR 就发不出访存，MDR 没拿到数就送不进 IR；PC 自增必须晚于 `PC→MAR`。
- 单总线铁律：一条 CPU 内部总线，一个时钟只能传一次数据；走内部总线的两步必须分两个时钟。
- 能合并的唯一判据：两步走的是两条不同总线（一步 CPU 内部总线、一步系统总线）才允许同拍。
- 访存必经 MAR 与 MDR，任何「直接 M→IR」的写法都是错的。
- 控制信号的 out/in 语义：数据流出谁就谁 `out`，流入谁就谁 `in`；一拍 = 一个 out 加一个 in。
- 执行阶段范例（2009 年 `ADD (R1),R0`，功能 $(R0)+((R1))\to(R1)$）：6 拍；把「R0→A」与「读内存→MDR」合并后 5 拍。
- 系统总线三根缩写要认：CB 控制总线、DB 数据总线、AB 地址总线；取指时地址从 AB 出去、数据从 DB 回到 MDR。
- 单总线与多总线的区别只影响「一拍能传几个数据」：题目给一条总线就一拍一步写，给多总线才敢并行。
- 同一段微操作在两种总线上写法不同：单总线要求每拍只出现一个 out 与一个 in，答题前先判题目给的是哪一种，合并才有依据。
> 取指四步 + 「访存必经 MAR/MDR」+ 「ALU 不存储」，这三句覆盖数据通路题一半的判分点。

**模板/流水线**

```c
/* 取指周期：单总线，一个时钟只走一次内部总线 */
/* C1 */ (PC) -> MAR       /* PCout=1, MARin=1              */
/* C2 */ M(MAR) -> MDR     /* 读命令=1, MDRinE=1            */
/* C2 */ (PC) + 1 -> PC    /* 并行：走的是另一条总线，可同拍 */
/* C3 */ (MDR) -> IR       /* MDRout=1, IRin=1              */
/* 若题目只给内部总线一组信号：C2 只写读命令，不写 MDRin */
/* 执行阶段 ADD (R1), R0：功能 (R0)+((R1)) -> (R1) */
/* 1 */ (R0) -> A           /* R0out, Ain                    */
/* 2 */ (R1) -> MAR         /* R1out, MARin                  */
/* 3 */ M(MAR) -> MDR       /* 读命令, MDRinE                */
/* 4 */ (A) + (MDR) -> AC   /* ACin（ALU 不写 out）          */
/* 5 */ (AC) -> MDR         /* ACout, MDRin                  */
/* 6 */ (MDR) -> M           /* MDRoutE, 写命令               */
/* 优化：第 1 步与第 3 步合并（CPU 总线 vs 系统总线）=> 5 拍 */
```
! 微操作顺序错一步全盘错：PC→MAR 必在访存之前，MDR→IR 必在 MDR 拿到数之后·同一拍里排两次内部总线传输直接判错·ALU 不存储，运算前先占住一个操作数、结果先落暂存器或 ACC

## 控制信号表怎么写
**考频**：2022/2026（第43/44题）｜数据通路题的第二问，写法固定，按行给分
**必背结论**
- 一行一条微操作，左边写功能、右边写控制信号；题目要控制信号就必须写控制信号，只写微操作等于没答。
- 生成规则三条：数据流出谁写谁 `out`、流入谁写谁 `in`、其余部件不写。
- 与内存打交道的两个专用信号：`MDRinE`（内存数据线→MDR）、`MDRoutE`（MDR→内存数据线），带 `E` 的是走系统总线那一侧。
- 同名信号看方向：`MDRin` 是内部总线→MDR，`MDRinE` 是内存→MDR，混用是这一问最大的坑。
- 读/写命令必须单列：只写 `MDRinE` 不写读命令，存储器不知道要读。
- ALU 参与运算的那条微操作只写目的寄存器的 `in`（A、MDR 是 ALU 的固定输入端，没有传输动作）。
- 为什么设暂存器（2022 年问）：ALU 无存储功能，两个操作数要先进暂存器，结果也要先落暂存器或 ACC 再上总线，否则输出又接回输入会互相干扰。
- 2026 年「扩展器控制信号」：译码器把 $n$ 位编号映射成 $2^{n}$ 路选通（多对多）；多路选择器从多路里选一路输出；三态门置 1 才让数据通过，置 0 就阻断。
- 控制信号由 CU 产生，依据是 IR 里的操作码；地址码则送去寄存器堆或 MAR 负责取数，两半分工要写清。
- 信号名以题目所给表格为准：不同教材对同一动作命名不同，语义对、方向对就给分，但 out/in 反了必错。

| 微操作 | 需要有效的控制信号 |
|---|---|
| `(PC)→MAR` | PCout、MARin |
| `M(MAR)→MDR` | 读命令、MDRinE |
| `(MDR)→IR` | MDRout、IRin |
| `(R0)→A` | R0out、Ain |
| `(A)+(MDR)→AC` | ACin（ALU 输入端固定） |
| `(AC)→MDR` | ACout、MDRin |
| `(MDR)→M` | MDRoutE、写命令 |
| `(PC)+1→PC` | PCin（或自增信号） |

**模板/流水线**

```c
/* 控制信号表模板：一行一条微操作，先功能后信号 */
/* 判据：流出谁 -> 谁 out；流入谁 -> 谁 in；ALU 不进 out/in 位置 */
/* 1 */ (PC) -> MAR        /* PCout, MARin          */
/* 2 */ M(MAR) -> MDR      /* 读命令, MDRinE        */
/* 3 */ (MDR) -> IR        /* MDRout, IRin          */
/* 4 */ (PC) + 1 -> PC     /* PCin（或 +1 信号）    */
/* 访存类别忘了读/写命令；带 E 的信号 = 与内存打交道那一侧 */
/* 问「为什么设暂存器」：ALU 没有存储功能 + 防止输出回灌输入 */
/* 问「控制信号谁产生」：CU，依据是指令的操作码（地址码去取数） */
```
! 题目只给一组内部总线信号时写 MDRin 就是错，那是 MDRinE 的活·只写微操作不写控制信号，这一问直接白给·读/写命令漏写，存储器不知道要读还是要写

## 流水线五段与三类相关
**考频**：2012/2014（第43/44题）｜五段流水线隔年考，阻塞周期数必给分
**必背结论**
- 五段：IF 取指 | ID 译码且读寄存器 | EX 执行 | MEM 访存 | WB 写回；每个流水段后面都有流水段寄存器，锁存本段结果供下一段用。
- 三类指令在 EX/MEM 的差别必须背（见下表）：这是判阻塞的地基，尤其「转移类在 MEM 段才把目的地址送进 PC」。
- 结构相关＝资源冲突：同一时刻两条指令抢同一部件，典型是 IF 访存撞上访存类的 MEM；排图时推迟 IF，根本解法是指令 Cache 与数据 Cache 分离。
- 数据相关＝写后读（RAW）：后面要用前面还没产生的结果；解法是阻塞、插入空操作、数据旁路（转发）。
- load-use 特例：前一条是 load，数据在 MEM 段末才拿到，转发也救不了，必须「延迟＋转发」，即后一条 EX 排在前一条 MEM 之后。
- 控制相关：转移指令让后面已取的指令可能白做；解法是尽早算出转移目标地址，且下一条的 IF 排在转移指令的 MEM 之后。
- 判数据相关不能只看写后读，要看间隔：WB 在第 5 拍、ID 在第 2 拍，差 3 拍，中间隔 $\ge 3$ 条指令就没有冒险。
- 阻塞周期数：$T=((K+N-1)+\text{阻塞拍数})\times\Delta t$；问「多少个时钟周期」只答拍数，不乘 $\Delta t$。
- 2012 年实算：四条无相关指令进五段流水线 $=5+4-1=8$ 个时钟周期，问的是拍数不是时间。
- 2023 年那道「已转发＋已硬件阻塞」还剩谁被阻塞：逐条卡下面四条约束，被卡住的是 load 后面那条、以及前面是转移指令那条，前两条正常。
- 三种冒险的修复手段别写串：分离 Cache 治结构、转发治数据、早算目标地址治控制。

| 指令类别 | EX 阶段 | MEM 阶段 | WB 阶段 |
|---|---|---|---|
| 计算类（ALU） | 运算 | 空，什么都不做 | 写回寄存器 |
| 访存类（load/store） | 算有效地址 | 访存（读或写） | 读出的数写回寄存器 |
| 转移类（分支） | 算转移目的地址 | 目的地址送进 PC | 无 |

**模板/流水线**

```c
/* 五段：IF ID EX MEM WB；第 i 条指令各段比上一条晚 1 拍 */
/* 后一条 IF 在第 p 拍，则 ID 在 p+1、EX 在 p+2、MEM 在 p+3、WB 在 p+4 */
int K = 5, N = 4;
int cycles = K + N - 1;          /* 无相关：5+4-1 = 8 拍 */
/* 阻塞判据（逐条卡）：
   未用转发 + 写后读 -> 后一条 ID 必须 >= 前一条 WB
   已用转发         -> 后一条 EX 必须 >= 前一条 EX
   前一条是 load    -> 后一条 EX 必须 >= 前一条 MEM
   前一条是转移指令  -> 后一条 IF 必须 >= 前一条 MEM
   任何情况        -> 后一条 IF 不早于前一条 ID          */
cycles += stall;                 /* stall = 为满足以上约束多等的拍数 */
/* 若问时间：T = cycles * dt，dt = max(各段时间) + 流水段寄存器延迟 */
```
! 只看「写后读」就断言有数据冒险，中间隔够 3 条其实没事·前一条是 load 时仍只保证「EX 在 EX 之后」必错·上一条是转移指令还把 IF 提到 MEM 之前，整张时空图就废了

## 流水线性能三公式
**考频**：2012/2014（第43/44题）｜加速比与吞吐率大题未单独设问，是流水线题的公式底座
**必背结论**
- $K$ 段流水线执行 $N$ 条指令：$T=(K+N-1)\Delta t$，这是一切小问的起点。
- 吞吐率 $TP=\dfrac{N}{(K+N-1)\Delta t}$，最大吞吐率 $TP_{max}=\dfrac{1}{\Delta t}$（$N$ 很大时趋近）。
- 加速比 $S=\dfrac{NK\Delta t}{(K+N-1)\Delta t}=\dfrac{NK}{K+N-1}$，最大加速比 $S_{max}=K$，上限就是段数。
- 效率 $E=\dfrac{S}{K}=\dfrac{N}{K+N-1}$，$N$ 越大越接近 1。
- 时钟周期不是各段平均值：$\Delta t=\max(t_i)+t_{\text{流水段寄存器}}$，取最长段再加锁存延迟。
- 有时空图先数拍：横轴时钟、纵轴流水段，一条指令占一条阶梯斜线；空格就是阻塞拍，总拍数 = 最后一行的结束列。
- 有阻塞时把 $K+N-1$ 换成实际拍数，四个公式同步改，别只改一个。
- 时空图画法：横向一格一个周期、纵向一行一个流水段，第 $i$ 条指令的 IF 画第 $i$ 列，其余段依次右移一格，相邻指令同一段错开一格成阶梯。
- 加速比公式只有在各段等长时才直接成立；各段不等长要先把时钟周期取成最长段再加锁存延迟，再套同一式子。
- 流水线装满之前有空闲段：$N<K$ 时效率低于 50%、加速比也远不到 $K$；题目把 $N$ 给得很大时，可直接按 $N\to\infty$ 取上限答。
> $T$、$TP$、$S$、$E$ 四个量共用 $(K+N-1)$，先把拍数算准，其余套公式，不会连环错。

**模板/流水线**

```c
/* k 段、n 条、一个时钟 dt */
double T   = (k + n - 1) * dt;            /* 总时间             */
double TP  = n / T;                       /* 实际吞吐率         */
double TPm = 1.0 / dt;                    /* 最大吞吐率         */
double S   = (double)n * k * dt / T;      /* 加速比 = nk/(k+n-1) */
double Sm  = k;                           /* 最大加速比 = 段数  */
double E   = S / k;                       /* 效率 = n/(k+n-1)   */
/* 时钟周期：dt = max(各段时间) + 流水段寄存器延迟 */
/* 有阻塞：把 (k+n-1) 换成实际拍数 k+n-1+stall，四式同步改 */
/* 问「多少个时钟周期」只答拍数，问「时间」才乘 dt */
```
! 加速比上限是段数 $K$，不是无限大·时钟周期取最长段再加锁存延迟，取平均必错·$N$ 很小时 $S$ 远小于 $K$，别把 $S_{max}$ 当实际加速比填
