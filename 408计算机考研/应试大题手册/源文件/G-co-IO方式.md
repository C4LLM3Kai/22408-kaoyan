## 三种 I/O 方式总表
**考频**：2018/2009｜三种方式横向对比是本章最标准的三问式大题，8-9 分，一次问三小问
**必背结论**
- 程序查询：CPU 反复读状态端口，每传一个字都由 CPU 搬，CPU 参与 100%，三种里效果最差。
- 程序中断：外设放好数据后主动请求，每传一个字中断一次；数据仍经 CPU（服务程序用 load/store 搬）。
- DMA：外设在内存与设备间直传，数据不经过 CPU；只有预处理与后处理用到 CPU。
- 传送单位：查询与中断都是「字」（32 位 = 4B）；DMA 停止 CPU 访存是「块」（512B），周期挪用是「字」。
- 能不能用中断只有一条判据：外设准备数据的时间必须大于中断处理（读走数据）的时间。
- 查询又分两种：持续查询把 CPU 全部时间花在 I/O 上；周期性（定时）查询按外设速率定间隔，占用率降下来但仍是浪费。
- 选型次序是 DMA → 中断 → 查询，按一次要搬的数据量和设备速度从大到小排。

| 方式 | CPU 参与程度 | 数据传输单位 | 是否经过 CPU | 适用场合 |
|---|---|---|---|---|
| 程序查询 | 全程忙等，100% 被占 | 字（每次 1 个字） | 经过 | 极低速、开关量、简单设备 |
| 程序中断 | 只占中断响应与服务程序 | 字（每次 1 个字） | 经过 | 低速、随机出现的设备（键盘、打印机） |
| DMA | 只占预处理与后处理 | 块（停止CPU访存）或字（周期挪用） | 不经过 | 高速、成块传送（磁盘、显卡、网卡、声卡） |

> 三种方式的差别只落在两处：数据经不经过 CPU；CPU 是全程陪着还是只在头尾露个面。

**模板/流水线**

```c
/* 选型三判据，按顺序问，问到一个就停 */
if (数据率 >= 1e6 && 每次按块传送)        方式 = DMA;   // 磁盘/网卡/显卡/声卡
else if (准备数据时间 > 中断处理时间)     方式 = 中断;  // 键盘/打印机/鼠标
else                                      方式 = 查询;  // 开关量、极低速设备
/* 中断可用性的等价写法：n * (中断响应 + 服务程序) < 1 秒，
   n 为每秒中断次数；不满足就是"读不过来"，必须换 DMA */
```

! 说「中断方式不经过 CPU」是硬错，只有 DMA 不经过·别把键盘当高速设备，判高速看数据量不看手速·DMA 也不是完全不占 CPU，预处理与后处理照样要 CPU

## 程序查询方式时间计算
**考频**：2018｜查询只作为三问里的第一问，4 分，很少单独成题
**必背结论**
- 每秒查询次数 $n=R/B$，$R$ 是数据传输率（B/s），$B$ 是每次传送字节数；32 位缓冲即 $B=4$。
- 最长查询间隔 $T=1/n$；实际查询间隔必须 $\le T$，否则数据被下一次覆盖。
- 每次查询开销 $C=$ 指令条数 $\times$ CPI。
- CPU 用于 I/O 的比例 $P=\dfrac{n\times C}{f}\times 100\%$，$f$ 是主频（每秒时钟数）。
- 查询间隔必须小于等于外设两次传送的间隔，否则数据缓冲寄存器被下一次数据覆盖，丢数据。
- 查询搬运一个数据也要 load 加 store，所以「至少执行 10 条指令」这种题面数字原样代入，不要自己改。
- 2018 第43题(1)：$R=2$ MB/s，$B=4$，10 条指令，CPI 4，$f=500$ MHz，得 $n=5\times10^5$，$T=2$ μs，$C=40$，$P=4\%$。

**模板/流水线**

```c
/* 查询方式四步，一行一个量，别跳 */
double Query(double R, double B, long ins, long cpi, double f) {
    long   n = (long)(R / B);        // 每秒查询次数
    double T = 1.0 / n;              // 最长查询间隔(s)，写上"<= T"才满分
    long   C = ins * cpi;            // 每次查询的时钟数
    return 100.0 * n * C / f;        // 占用率(%)
}
/* 2018-43(1)：Query(2e6, 4, 10, 4, 5e8)
   n=5e5 次/s，T=2μs，C=40，P=4% */
```

> 查询题的三件套：次数、间隔、开销。间隔是次数的倒数，别写成次数的倍数。

! MB/s 在数据传输率里按 10 的幂走，2MB/s 就是 $2\times10^6$ B/s·32 位先化成 4B 再去除字节率，别拿 32 去除·问「最多间隔多久查一次」答的是上界，符号写 $\le$

## 中断响应全过程与传输时间
**考频**：2016/2018/2009｜十年三考，本章最高频，必练
**必背结论**
- 中断响应又叫中断隐指令，由硬件完成，不是真正的指令。
- 必背 5 步：① 关中断 ② 保存断点（PC，有的说法含 PSW）③ 识别中断源、取中断类型号 ④ 查中断向量表得中断向量（＝服务程序入口地址）⑤ 转去执行中断服务程序。
- 断点取谁：中断取「下一条指令地址」，异常取「当前指令地址」。
- 三个概念连成一条链：中断类型号（数据线送来）→ 查中断向量表 → 得中断向量，即服务程序入口地址。
- 中断请求与响应走控制线，中断类型号走数据线；这是唯一一处「响应在控制线、编号在数据线」的分工。
- 中断处理共 9 步：1-3 由硬件（即上面三步）；4-9 由服务程序做：保护现场、开中断、设备服务、关中断、恢复现场、中断返回。
- 完成这一任务的时间 ＝ 外设准备时间 ＋ 中断响应时间 ＋ 服务程序前 $k$ 条指令的时间（跑到启动设备那条为止）。
- CPU 用于该任务的时间 ＝ 中断响应时间 ＋ 整条服务程序的时间（$n$ 条指令，不算外设准备）。
- 中断方式的开销就三块：中断响应（硬件，十来个时钟）、服务程序（指令数乘 CPI）、以及被中断程序的现场保存与恢复，后者已含在响应里。
- 服务程序第 $k$ 条指令启动设备，下一轮准备与本次服务程序的后半段重叠，所以问「完成这一任务」时只算到第 $k$ 条。
- 2009 第43题(1)：0.5 MB/s、32 位为单位、服务程序 18 条加其他开销 2 条、CPI 5、500 MHz，得 $n=1.25\times10^5$，$C=(18+2)\times5=100$，$P=2.5\%$。
- 2016 第44题：0.5 ms 折合 $0.5\text{ms}/20\text{ns}=25000$ 个时钟，响应 10 个时钟，15 条 $\times$ 4 = 60，每字符 25070；1000 字符共 $2.507\times10^7$ 个时钟；CPU 只花 $(10+20\times4)\times1000=9\times10^4$ 个时钟。

**模板/流水线**

```c
/* 两个问法，只差一个"CPU" */
long all_task(long t_pre, long t_resp, long ins, long cpi, long k) {
    long run = ins * cpi;                  // 服务程序跑到"启动设备"那条为止：15 条
    return k * (t_pre + t_resp + run);     // 问①完成这一任务
}
long cpu_only(long t_resp, long ins_all, long cpi, long k) {
    return k * (t_resp + ins_all * cpi);   // 问②CPU 用于这一任务：整 20 条
}
/* 2016-44(2)：t_pre = 0.5ms / 20ns = 25000，t_resp = 10，k = 1000
   问① 1000*(25000+10+15*4) = 2.507e7 个时钟
   问② 1000*(10+20*4)       = 9e4   个时钟  */
```

> 判「能不能用中断」：准备数据的时间小于中断处理时间就是读不过来。2018 第43题(2) 设备B 每 0.1 μs 来一个数据、中断一次要 0.8 μs，故设备B 不能采用中断。

! 异步串行算位数要加 1 位起始位，7+1+1+1=10 位，只写 9 位丢一半分·问①用 15 条、问②用 20 条，两问一混全错·「其他开销」就是中断响应的开销，不是新东西

## 中断嵌套、优先级与屏蔽字
**考频**：选择题常考，大题未考（真题年份总表未登记本题型）｜服务于 2009/2016/2018 那类中断概念问答题
**必背结论**
- 高优先级中断可以打断低优先级中断的执行，叫多重中断（中断嵌套）。
- 屏蔽字一位对应一个中断源：写 1 表示屏蔽（不响应），写 0 表示允许。
- 处理某级中断时，屏蔽字里「优先级低于或等于自己」的位全置 1，「高于自己」的位全置 0；自己的位恒为 1。
- 全 1 的屏蔽字对应最高优先级，它能打断别人，谁也打断不了它。
- 嵌套深度＝能打断自己的中断源个数 + 1；4 级中断 A>B>C>D 的深度分别是 1、2、3、4。
- 响应要三条同时满足：当前指令执行完、中断允许触发器为 1（开中断）、没有更高级的请求。
- 所以关中断的区间越长，响应越迟；保存断点必须放在关中断之后、开中断之前。

| 正在处理 | 屏蔽字 A B C D | 嵌套深度 |
|---|---|---|
| A（最高） | 1 1 1 1 | 1 |
| B | 0 1 1 1 | 2 |
| C | 0 0 1 1 | 3 |
| D（最低） | 0 0 0 1 | 4 |

**模板/流水线**

```c
/* 屏蔽字模板：n 级中断，编号 0 为最高优先级 */
int mask[N][N], i, j;
for (i = 0; i < N; i++)              // i = 正在处理的那一级
    for (j = 0; j < N; j++)          // j = 其它中断源
        mask[i][j] = (j >= i);       // 自己不高于它 → 置 1 屏蔽
/* A:1111  B:0111  C:0011  D:0001
   画表时先把自己的那一位置 1，右边（更低级）全填 1，左边（更高级）全填 0 */
```

> 屏蔽字 1 是「关」不是「开」，这是全国统一的反直觉写法：置 1 = 屏蔽该源。

! 屏蔽字和自己的中断允许触发器是两层，别混为一谈·自己的位必须是 1，漏掉就变成自己打断自己·嵌套深度算的是能打断自己的源数加一，不是优先级序号

## DMA 传送流程与争总线
**考频**：2022/2018/2012（DMA 优先级小问）｜优先级问法十年两现，必背两条理由
**必背结论**
- DMA 三阶段：预处理（CPU 设方向、首址、长度并启动设备）→ 数据传送（硬件，整块不用 CPU）→ 后处理（DMA 发中断，CPU 校验数据）。
- 停止 CPU 访存：单位是块（512B），整块传完才释放总线，CPU 在此期间完全停摆，适合块大且一次连续的场合。
- 周期挪用：单位是字（32 位 = 4B），每传完一个字立刻释放总线；CPU 不访存就直接拿，CPU 正在用就等它用完，同时请求则优先 DMA。
- 交替访存：CPU 与 DMA 分时轮流占用总线（一个周期给 CPU、一个周期给 DMA），不需要总线请求，效率最高但硬件最复杂（教材口径）。
- 预处理要写四件事：传送方向、主存首址、传送长度、启动设备；四件都由 CPU 执行，这是 DMA 唯一像中断的地方。
- 发生时机：中断只能在一条指令执行结束后响应，DMA 靠硬件，任意一个总线周期用完就能接管总线。
- DMA 优先级高于 CPU，也高于中断；答「谁获得总线」必须写两条理由：DMA 优先级高、数据必须尽快入内存否则被下一次覆盖丢失。

| 方式 | 传送单位 | 释放总线时机 | 对 CPU 的影响 |
|---|---|---|---|
| 停止 CPU 访存 | 块（512B） | 整块传完才释放 | CPU 完全停顿，适合块大且连续的场合 |
| 周期挪用 | 字（32 位） | 每传完一个字立刻释放 | 只偷一个存储周期，CPU 基本不停 |
| 交替访存 | 按周期分时 | 固定分给 DMA 一半周期 | CPU 与 DMA 各占一半，无请求开销 |

**模板/流水线**

```c
/* DMA 三阶段与请求次数 */
// 1 预处理：CPU 写方向/首址/长度，启动设备        —— 占 CPU
// 2 传送  ：设备就绪 -> DMAC 发总线请求 -> 传一个单位 -> 释放   —— 硬件，不占 CPU
// 3 后处理：DMAC 发中断，CPU 校验                    —— 占 CPU
int unit = (mode == 0) ? 512 : 4;      // 停止CPU访存取块512B；周期挪用取字4B
long req = total_bytes / unit;         // 总线请求次数，每传一个单位发一次
/* 2022-44(3)：一个扇区 512B，缓冲区 64 位 = 8B -> 512/8 = 64 次 */
```

> 问「CPU 与 DMA 同时访存谁获得总线」，只答「DMA 优先级高」等于没答，必须补上「数据要尽快放入主存，否则缓冲区被下次数据覆盖」。

! 周期挪用的单位是字不是块，拿 512B 去算请求次数必错·把「DMA 高于 CPU」和「DMA 高于中断」搞混，两个都是 DMA 高·别写 DMA 完全不占 CPU，预处理和后处理要占

## DMA 传送时间与 CPU 占用率
**考频**：2018/2009/2022｜与中断同题对比，两种方式必考其一
**必背结论**
- 每秒 DMA 次数 $n=R/B_b$，$R$ 是数据率（B/s），$B_b$ 是每块字节数。
- CPU 占用率 $P=\dfrac{n\times C_c}{f}\times100\%$，$C_c$ 是预处理加后处理的总时钟数。
- DMA 本身传送时间 $t=D/R$（$D$ 为总字节数），这段时间 CPU 不被占用，可继续执行程序。
- 总线请求次数 $=$ 一次传送总量 $\div$ 每次传送单位，每传一个单位发一次；2022 第44题(3)：512B $\div$ 8B = 64 次。
- 2018 第43题(3)：$40\times10^6/1000=4\times10^4$ 次/s，$\times500=2\times10^7$，$\div5\times10^8=4\%$。
- 2009 第43题(2)：$5\times10^6/5000=1000$ 次/s，$\times500=5\times10^5$，$\div5\times10^8=0.1\%$。

**模板/流水线**

```c
/* DMA 占用率：分子只有预处理 + 后处理 */
double DmaRate(double R, double blk, long c, double f) {
    long n = (long)(R / blk);        // 每秒 DMA 次数
    return 100.0 * n * c / f;        // 百分比
}
/* 2018-43(3)：DmaRate(40e6, 1000, 500, 5e8) = 4%
   2009-43(2)：DmaRate( 5e6, 5000, 500, 5e8) = 0.1%
   ｜块大小题给 1000B 就用 1000，不要擅自换成 1KB = 1024B */

long DmaReq(long total, long unit) { // 总线请求次数
    return total / unit;             // 2022：512 / 8 = 64
}
```

> DMA 的占用率永远是三种方式里最低的，因为它把「搬运」这件最费时的活交给了硬件。

! 1KB 与 1000B 差 24 字节，题面给 1000B 时按 1000 算，否则数值对不上·占用率的分母是主频（每秒时钟数），不是 CPI·周期挪用的请求次数按数据缓冲区宽度算，不是按主存字长算

## 磁盘参数计算
**考频**：2022｜组原近年少见的磁盘计算大题，一整题多问都从磁盘参数出发
**必背结论**
- 容量 $=$ 盘面数 $\times$ 每面磁道数 $\times$ 每道扇区数 $\times$ 每扇区字节数；盘面数 $=$ 盘片数 $\times2$。
- 地址三字段位数各取 $\lceil\log_2 N\rceil$（向上取整）：柱面号（＝磁道号）、盘面号（＝磁头号）、扇区号；定位顺序也是柱面→盘面→扇区。
- 按柱面优先编址的好处：换柱面要动机械臂最慢，同一柱面换磁头只需电子切换，所以地址让柱面号在高位。
- 一圈时间 $T=60/r$，$r$ 为转速（r/min）；7200 r/min 得 8.33 ms。
- 平均存取时间 ＝ 平均寻道时间 ＋ $T/2$ ＋ $T/N$，$N$ 为每道扇区数；旋转延迟按半圈算，传输时间按占一圈的比例算。
- 数据传输率 $=$ 每道容量 $\times$ 每秒转数。
- 一个扇区的传输时间也可以写成每扇区字节数除以数据传输率，与按角度比例算的结果一致，用哪个顺手用哪个。
- 2022 第44题：4 个双面盘片得 8 面（3 位）、20000 磁道（15 位）、500 扇区（9 位）；平均存取 $=5+4.17+0.017\approx9.18$ ms；容量 $=8\times20000\times500\times512$ B $\approx40.96$ GB；传输率 $=500\times512\times120=3.072\times10^7$ B/s。

**模板/流水线**

```c
/* 磁盘五算，全部由"一圈时间"派生 */
long   faces = platter * 2;                       // 4 双面盘片 -> 8 面
long   cap   = faces * track * sector * 512L;     // 容量(B)
int    cyb   = ceil_log2(track);                  // 柱面/磁道 15 位
int    hdb   = ceil_log2(faces);                  // 盘面/磁头  3 位
int    scb   = ceil_log2(sector);                 // 扇区       9 位
double T     = 60.0 / rpm;                        // 一圈(ms)：60/7200 = 8.33
double avg   = seek + T / 2 + T / sector;         // 平均存取 ≈ 5+4.17+0.017 = 9.18ms
double rate  = sector * 512.0 * (rpm / 60.0);     // 传输率 3.072e7 B/s
```

> 旋转延迟一律按半圈，理由是最靠前的位置一找就到、最靠后的要转一整圈，平均下来正好半圈。

! 盘面数是盘片数的两倍，4 个双面盘片是 8 面不是 4 面·柱面号等于每面磁道数，别把总磁道数再乘盘面·寻道时间题面直接给，不用自己算

## 三种方式 CPU 开销对比模板
**考频**：2018/2009｜「占多少百分比」是本章最常见问法，一问 2-4 分
**必背结论**
- 一个公式打天下：$P=\dfrac{n\times C}{f}\times100\%$，$n$ 是每秒 I/O 次数，$C$ 是每次的 CPU 开销时钟数，$f$ 是主频。
- 三种方式只有 $C$ 不同：查询 $C=$ 指令数 $\times$ CPI；中断 $C=$ 中断响应时钟 $+$ 服务程序指令数 $\times$ CPI；DMA $C=$ 预处理 $+$ 后处理时钟。
- $n$ 都要自己求：$n=$ 数据率 $\div$ 每次传送字节数，注意 1 B $=$ 8 位。
- 同题对比结论：DMA 占用率远低于中断；2009 第43题同一外设，中断 2.5%、DMA 0.1%，差 25 倍。
- 数据率越高，中断方式越撑不住（每秒次数线性涨），这时只能换 DMA，所以同一题常在(2)问逼你换 DMA。
- 答题就写三行：$n$ 等于多少、$C$ 等于多少、$nC$ 除以主频乘 100%，不写文字过程。
- 数值相同不代表含义相同：2018 第43题设备A 查询得 4%、设备B DMA 也得 4%，两问彼此独立，别互相代入。

| 方式 | 每次开销 C 的组成 | 每秒次数 n 的算法 |
|---|---|---|
| 程序查询 | 每次查询的指令数乘 CPI | 数据率除每次传送字节数 |
| 程序中断 | 中断响应时钟加服务程序全部时钟 | 数据率除每次传送字节数 |
| DMA | 预处理时钟加后处理时钟 | 数据率除每块字节数 |

**模板/流水线**

```c
/* 一张表通吃三种方式：只有 c 不同 */
double Cost(double R, double B, long c, double f) {
    long n = (long)(R / B);              // 每秒 I/O 次数
    return 100.0 * n * c / f;            // 占用率(%)
}
// 查询：c = 指令数 * CPI           2018 设备A：Cost(2e6, 4, 10*4, 5e8) = 4%
// 中断：c = 响应 + 服务程序时钟    2009：   Cost(0.5e6, 4, 100, 5e8) = 2.5%
// DMA ：c = 预处理 + 后处理时钟    2009：   Cost(5e6, 5000, 500, 5e8) = 0.1%
```

> 考场只写三行：n 等于多少、C 等于多少、nC 除主频乘百分之百。过程分极少，结果必须写单位。

! 主频 MHz 是 $10^6$，500 MHz 要写成 $5\times10^8$ 才不出错·百分比最后一步别忘乘 100·中断的「其他开销」就是中断响应，漏掉它 2009 那题会算成 2.25%
