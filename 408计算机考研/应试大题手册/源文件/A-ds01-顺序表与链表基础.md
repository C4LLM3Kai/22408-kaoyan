## 答题规范与保底策略
**考频**：2009–2025 每年一道（15分）｜每年必有一道算法题，三段式给分结构从 2009 年至今没变过
**必背结论**
- 算法题固定三段式：①中文写设计思想 ②写核心函数 ③写时空复杂度。三问全答满，即使全用暴力解也保底 11 分；只写思路不写代码最多 5 分；空着 0 分。
- 只写一个核心函数，题干给的所有已知条件（数组名、长度 n、参数 k、值域 m）全部当函数参数传进来，不自己造全局变量。
- 不写头文件、不写 main、不写输入输出；唯一例外是题干明确要求「输出」时必须写 printf，此时函数返回值反而可以不写。
- 代码只许 C 或 C++，Java 从 2015 年起不给用。
- 动笔顺序：先在草稿上定下「用什么手段」（双指针/辅助数组/三次逆置）→ 直接把代码写完 → 再回头写第一问的设计思想。这样三问必然对应，不会自相矛盾。
- 代码控制在 10~20 行，注释只加在「每个循环的入口」和「关键判断语句」两处。判卷老师不会运行代码，基本只看注释和循环骨架。
- 版面纪律：每小问的**答案写在最显眼的位置**，过程能省就省。一个大题常常拆成三四个小问、每个小问一两分，判卷按点找答案，找不到就不给分。
- 第三问的复杂度按循环结构直接算：并列的多个循环取最大阶，嵌套的相乘；开了 `k` 个辅助单元就写 O(k)，写不出最优解就照实写，虚报比写大更扣分。
- swap、abs、取最大最小直接用现成的，自己实现不加分只加错误率。
> 万能开场句（第一问第一句直接照抄）：「本算法采用一前一后两个指针从两端向中间扫描」「采用一个与值域等大的辅助数组充当哈希表，统计每个值是否出现过」「采用头插法将原链表就地逆置」，随后补一句「时间复杂度 O(n)，空间复杂度 O(1)」。先把这句落在卷面上，再展开细节。

| 小问 | 考什么 | 分值 | 拿分写法 |
| --- | --- | --- | --- |
| 第一问 | 设计思想（中文描述） | 4~5 | 一句话点明手段 + 关键指针含义 + 一趟还是两趟，绝对不要写伪代码 |
| 第二问 | 核心函数代码 | 7~8 | 只写一个函数，3~4 条注释，超长循环可拆成两段 |
| 第三问 | 时空复杂度 | 2~3 | 直接写 O(...)，每个补半句理由（几个循环、开了多大数组） |

**三条开数组纪律**
- 纪律一：动态辅助数组一律写 `int *t = (int *)malloc(k * sizeof(int));`，不要写 `int t[k]`，变长数组在标准 C 编译器下直接报错。
- 纪律二：开完立刻手动清零，`for (i = 0; i < k; i++) t[i] = 0;`。不写这一步，内存里的脏数据会让后面全错，而且判卷看不出来你错在哪。
- 纪律三：大小一次定死，**存的时候怎么偏移，取出来就怎么还原**。开 N 个就要处处 `-1`，开 N+2 个就原封不动存——宁可多开两个，不要给自己留偏移量。
! 只写设计思想不写代码，15 分里一般只给 4~5 分·`int t[p]` 这种变长数组是典型编译错误，判卷一眼看出不专业·找到答案用 break 而不是 return，break 之后那句兜底输出照样执行，答案变两个

## 顺序表暴力解模板
**考频**：2010/2013/2018/2020/2025｜线性表 18 年共出 10 道大题，其中数组类 6 道，是链表之外的另一半
**必背结论**
- 顺序表题只有两个手段：**双指针扫描**（时间换空间）和**辅助数组统计**（空间换时间）。审题第一件事就是看题干给不给值域、给不给空间 O(1)。
- 判信号：要求空间 O(1) → 左右夹逼或读写指针；值域已知且有限 → 开辅助数组当哈希表；要求保持相对次序 → 一律不许排序。
- 写不出最优解就先写通用解，本章五个模板里只有循环左移的三次逆置属于「技巧」，其余全是可套的骨架。

### 双指针 · 左右夹逼与原地逆置
**考频**：2010｜逆置是数组题的母操作，2010 循环左移与 2019 拆分合并两道题里它都是直接得分点
**必背结论**
- 左指针 `i = 0`，右指针 `j = n-1`，交换后 `i++、j--`，`i < j` 一破就停——正中间那个元素不用管。
- 逆置是「原地」的，只借一个 `temp` 变量，空间 O(1)；新开数组逆置只能拿复杂度分，拿不到最优分。
- 快排一趟划分用的是同一套指针，只是多了三条性质：取枢轴、从右往左起步、每次交换改变移动方向。
```c
/* 逆置 A[left..right]，闭区间 */
void Reverse(int A[], int left, int right) {
    int i = left, j = right, t;
    while (i < j) {
        t = A[i]; A[i] = A[j]; A[j] = t;   /* 交换左右指针所指元素 */
        i++; j--;                          /* 向中间夹逼，相遇即停 */
    }
}
/* 快排一趟划分：以 A[low] 为枢轴，小的甩左边大的甩右边，返回枢轴最终位置 */
int Partition(int A[], int low, int high) {
    int p = A[low];                        /* 枢轴取出来，位置就空出来了 */
    while (low < high) {
        while (low < high && A[high] >= p) high--;  /* 从右往左找比枢轴小的 */
        A[low] = A[high];
        while (low < high && A[low] <= p) low++;    /* 再从左往右找比枢轴大的 */
        A[high] = A[low];
    }
    A[low] = p;                            /* 两指针相遇处填回枢轴 */
    return low;
}
```
! 逆置写成 `i <= j` 会把中间那个元素和自己交换，虽不致命但白跑一趟·快排划分第一步必须从右往左扫，写反了枢轴位置必错·`while` 内层两个循环都要带 `low < high` 越界判断

### 双指针 · 前后同向（读写指针）
**考频**：2025｜2025 考的就是「一趟线性遍历 + 预处理」，这是它的标准答法
**必背结论**
- 读指针 `j` 扫全表、写指针 `i` 只写要保留的元素，一趟结束 `i` 就是新表长，空间 O(1)。
- 预处理 = 先花一趟把「到每个位置为止的信息」（前缀和、前缀最值、前缀计数）算进 `pre[]`，第二趟 O(1) 取用，总体仍是 O(n)。
- 后缀最值同理：从 `n-1` 往 `0` 倒着扫一遍就能得到「i 右边是否有更大值」这类信息。
- 题干出现「尽可能高效」「一遍扫描」「不能改变相对次序」这类措辞，答案基本就是单趟线性遍历；出现「每个位置左边/右边」就一定先预处理再回答。
```c
/* 原地压缩：读指针 j 扫全表，写指针 i 只写保留下来的，返回新长度 */
int Compact(int A[], int n) {
    int i = 0, j;
    for (j = 0; j < n; j++)
        if (A[j] != 0)                 /* 换掉这个条件就是任意「保留」规则 */
            A[i++] = A[j];
    return i;
}
/* 预处理前缀和：pre[i] = A[0]+...+A[i-1]，pre 要开 n+1 个 */
void PrefixSum(int A[], int n, int pre[]) {
    int i;
    pre[0] = 0;                        /* 空前缀，下标从 1 对齐 */
    for (i = 1; i <= n; i++)
        pre[i] = pre[i - 1] + A[i - 1];/* 把 + 换成 max/min 就是前缀最值 */
}
/* 用 pre 回答任意区间和：A[l..r] 的和 = pre[r+1] - pre[l] */
```
! 写指针 `i` 与读指针 `j` 别用同一个变量，压完就找不回原位置·前缀数组必须开 `n+1` 个，开 n 个时 `pre[n]` 越界·预处理后仍然要遍历第二趟，别忘了复杂度写成 O(n) 而不是 O(1)

### 快慢指针 · 有序表删重复
**考频**：选择常考，大题未考｜有序表的删重复与压缩，是 2015 链表绝对值去重题的数组预演
**必背结论**
- 有序表去重靠「比较相邻」：`A[j] != A[i]` 才保留，一趟 O(n)、空间 O(1)。
- 无序表去重不能这么写，必须先排序（O(nlogn)）或用辅助数组当哈希表（O(n) 时间 + O(n) 空间）。
- 快指针探路、慢指针驻守，是「原地删」这一类题的统一骨架；链表上的 2015 题是它的链式版本。
```c
/* 有序顺序表去重：i 是慢指针（最后写入位置），j 是快指针（探路） */
int Unique(int A[], int n) {
    int i = 0, j;
    if (n == 0) return 0;
    for (j = 1; j < n; j++)
        if (A[j] != A[i])              /* 与「已保留的最后一个」比，不是与 A[j-1] 比 */
            A[++i] = A[j];
    return i + 1;                      /* 新表长 = 最后下标 + 1 */
}
/* 删除所有值为 x 的元素（无序也能用）：计数法 */
int DelX(int A[], int n, int x) {
    int i, k = 0;
    for (i = 0; i < n; i++)
        if (A[i] != x) A[k++] = A[i];  /* k 同时是写指针和新长度 */
    return k;
}
```
! 去重要和「已保留序列的末尾」比，写成与 `A[j-1]` 比在有三连重复时会漏删·返回 `i` 而不是 `i+1` 是最常见的一分之差·`n == 0` 的边界判断不写，`A[0]` 直接越界

### 辅助数组当哈希表
**考频**：2013/2018｜「数组当 map」是三大高频思想之一，统计类题目通吃
**必背结论**
- 把原数组的**值当成辅助数组的下标**，`t[A[i]]++`，一趟统计完再扫辅助数组，时间 O(n)、空间 O(值域)。
- 两个前提必须写进设计思想：原数组的值必须是整数且非负（负数、小数不能当下标），且必须**提前知道值域上界**。
- 只关心「是否出现」时，`t[A[i]] = 1` 也行，但写 `++` 适用范围更广（次数为 0 即没出现），不亏。
- 值域上界不给时自己推：长度为 n 的数组，未出现的最小正整数最大只可能是 n+1，所以开 n+2 个就够。
```c
/* 统计 A[0..n-1] 中值域 0..m 各值出现次数，返回第一个没出现过的值 */
int HashCount(int A[], int n, int m) {
    int i, *t = (int *)malloc((m + 1) * sizeof(int));
    for (i = 0; i <= m; i++) t[i] = 0;          /* 纪律二：必须手动清零 */
    for (i = 0; i < n; i++)
        if (A[i] >= 0 && A[i] <= m) t[A[i]]++;  /* 越界必须挡掉，否则数组踩坏 */
    for (i = 0; i <= m; i++)
        if (t[i] == 0) { free(t); return i; }   /* 次数为 0 = 没出现过 */
    free(t);
    return -1;                                  /* 全出现过了 */
}
/* 未出现的最小正整数：辅助数组开 n+2 个，原封不动存，不减 1 */
int FirstMissing(int A[], int n) {
    int i, *t = (int *)malloc((n + 2) * sizeof(int));
    for (i = 0; i < n + 2; i++) t[i] = 0;
    for (i = 0; i < n; i++)
        if (A[i] >= 1 && A[i] <= n + 1) t[A[i]]++;   /* 只收 1..n+1，大的直接丢 */
    for (i = 1; i <= n + 1; i++)
        if (t[i] == 0) { free(t); return i; }
    free(t);
    return n + 2;                               /* 理论到不了，只为有返回值 */
}
```
! 开 n 个辅助数组要「减 1 存、加 1 取」，忘了加回来是头号扣分点，宁可开 n+2 个·不清零直接用，脏数据会让统计结果全错·输出的是值本身不是出现次数，`t[i]` 和 `i` 别写混

### 循环左移与循环右移
**考频**：2010｜数组类算法题的基础母题，逆置思想在多道真题里复用
**必背结论**
- 循环左移 p 位 = 逆置前 p 个 → 逆置后 n−p 个 → 整体逆置；循环右移 p 位 = 整体逆置 → 逆置前 p 个 → 逆置后 n−p 个。左移是「先分后合」，右移是「先合后分」。
- 时间 O(n)（三次逆置加起来 2n 次交换）、空间 O(1)，这是「时间空间都尽可能高效」的标准答法。
- 想不出三次逆置就写通用解：开 p 个辅助数组暂存前 p 个，后面整体前移，再把暂存接回末尾，时间 O(n+p)、空间 O(p)，一样拿分。
- `p %= n` 必须写，题目只保证 p 是正整数、不一定给 p < n。
```c
/* 逆置器：三道题都靠它，写成独立函数，别在每道题里重写一遍 */
void Reverse(int A[], int l, int r) {
    int i = l, j = r, t;
    while (i < j) { t = A[i]; A[i] = A[j]; A[j] = t; i++; j--; }
}
/* 循环左移 p 位：先逆置前 p 个，再逆置后 n-p 个，最后整体逆置 */
void LeftShift(int A[], int n, int p) {
    p = p % n;                       /* 防 p >= n */
    if (p == 0) return;              /* 不移，直接返回 */
    Reverse(A, 0, p - 1);            /* ① 前 p 个逆置 */
    Reverse(A, p, n - 1);            /* ② 后 n-p 个逆置 */
    Reverse(A, 0, n - 1);            /* ③ 整体逆置 */
}
/* 循环右移 p 位：顺序反过来，整体逆置放第一步 */
void RightShift(int A[], int n, int p) {
    p = p % n;
    if (p == 0) return;
    Reverse(A, 0, n - 1);            /* ① 整体逆置 */
    Reverse(A, 0, p - 1);            /* ② 前 p 个逆置 */
    Reverse(A, p, n - 1);            /* ③ 后 n-p 个逆置 */
}
/* 通用解：开 p 个辅助数组暂存，谁都能想到，照样给分 */
void LeftShiftBuf(int A[], int n, int p) {
    int i, *t;
    p = p % n;
    if (p == 0) return;
    t = (int *)malloc(p * sizeof(int));
    for (i = 0; i < p; i++) t[i] = A[i];      /* 暂存前 p 个 */
    for (i = p; i < n; i++) A[i - p] = A[i];  /* 后面 n-p 个整体前移 */
    for (i = 0; i < p; i++) A[n - p + i] = t[i]; /* 暂存接回末尾 */
    free(t);
}
```
! 三次逆置的顺序是「先逆置两个分段、最后整体」，写反就全错·`p %= n` 漏写在 p 大于 n 时数组越界·右移 p 位等价于左移 n−p 位，只需写一个函数也能换算，但换算错了比不换算扣得更多

! 顺序表题的复杂度分最容易白丢：三重循环就说 O(n³)，别硬写成 O(n)·边界条件（偏移量取模、下标上限）少一句，换组数据就崩·辅助数组开在栈上（`int t[1000]`）在 n 大时直接爆栈，一律用 malloc

## 链表结点定义与建表
**考频**：选择常考，大题未考｜但它是 2009/2012/2015/2019 四道链表题的第一段必写内容
**必背结论**
- 结点定义必须能默写，`}` 后面那个分号不能丢；结构体内自引用指针在 C 里必须写 `struct LNode *next`，写 `LNode *next` 只有 C++ 能过。
- `ElemType` 只是书上用的万能占位符，题目数据是整数就直接写 `int`，是字符就写 `char`，考场上不写 `ElemType`。
- `LNode *` 用来操作单个结点（插入、删除、修改），`LinkList` 用来操作整条链表（建表、逆置、遍历），两者本质等价但函数签名要表达意图。
- 链表题默认**带头结点**：头结点不存数据，所以一切遍历一律从 `head->next` 起步，写 `p = head` 起步必错位。
- 头插法建出的表与输入顺序**相反**，尾插法建出的表与输入顺序**一致**；头插法天然就是逆置，2019 题的后半段直接拿它用。
- 判表尾不能一律写 `p->next == NULL`：循环单链表表尾判据是 `p->next == head`，循环双链表还要 `head->prior` 指向表尾，写错就是死循环；静态链表存的是下标、末尾存 -1。

### 结点定义
**考频**：选择常考，大题必写｜2009 年官方评分说明：写出结构体类型定义与正确思想即给一半以上分数
```c
/* 考试写到答题纸上就写这几行，题目数据是 int 就写 int */
typedef struct LNode {
    int data;                  /* 数据域：题目是 char 就改 char */
    struct LNode *next;        /* 指针域：C 里必须写 struct LNode * */
} LNode, *LinkList;            /* 别名① LNode = 一个结点；别名② LinkList = 一条链表 */
/* 静态链表（选择题用）：数组存数据和下一个元素的下标，末尾存 -1 */
typedef struct {
    int data;
    int next;                  /* 存的是下标不是地址，-1 表示结束 */
} SLinkList[100];
```
! 结尾分号漏掉，编译直接不过，这是最便宜的丢分点·`struct LNode *next` 去掉 struct 在标准 C 下编译不过·定义写在答题纸最前面，判卷老师看到它就先划一半分

### 头插法建表
**考频**：2019（第二段）｜建表是所有链表题的地基，头插法顺带就是逆置
```c
/* 头插法：由数组 A[0..n-1] 建带头结点单链表，结果与输入顺序相反 */
LinkList HeadInsert(int A[], int n) {
    int i;
    LNode *head = (LNode *)malloc(sizeof(LNode));  /* 头结点，不存数据 */
    head->next = NULL;                             /* 空表：头结点后面暂时没东西 */
    for (i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = A[i];
        s->next = head->next;   /* ① 新结点先接上原来的首结点 */
        head->next = s;         /* ② 再让头结点指向新结点：先接后断 */
    }
    return head;                /* 返回头结点，它就代表整条链表 */
}
```
! 两句赋值写反成「先 `head->next = s` 再 `s->next = head->next`」，s 会指向自己，链表成环死循环·循环内 `s` 是局部变量，每轮都重新 malloc，别在循环外只 malloc 一次·忘了 `head->next = NULL` 初始化，空表时头结点指向野指针

### 尾插法建表
**考频**：2019（第一段）｜要保序时必须用尾插，头插会把你建的表倒过来
```c
/* 尾插法：由数组 A[0..n-1] 建带头结点单链表，结果与输入顺序一致 */
LinkList TailInsert(int A[], int n) {
    int i;
    LNode *head = (LNode *)malloc(sizeof(LNode));
    LNode *tail = head;         /* 尾指针先指头结点，之后一直指最后一个结点 */
    head->next = NULL;
    for (i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = A[i];
        s->next = NULL;         /* 新结点将成为新表尾，指针域显式置空 */
        tail->next = s;         /* ① 接到当前表尾后面 */
        tail = s;               /* ② 尾指针后移一步，这两句都不能少 */
    }
    return head;                /* 返回的是 head 不是 tail */
}
/* 求表长：所有链表题的第一步，除了头结点才计数 */
int Length(LinkList head) {
    int n = 0;
    LNode *p = head->next;      /* 从第一个实际结点开始 */
    while (p != NULL) { n++; p = p->next; }
    return n;
}
```
! 让 `head` 自己往后走充当尾指针，走完就找不回头结点了·漏掉 `tail = s` 这一句，下一轮会把新结点接在同一位置，链表断裂·返回 `tail` 而不是 `head`，调用者拿到的只是最后一个结点·求表长时从 `head` 数起，会把头结点算进去，全部结果差一

! 空表判据是 `head->next == NULL`，不是 `head == NULL`，带头结点的链表永远不空·建表循环里每轮都要新申请结点，在循环外申请一次等于所有结点共用同一块内存·求表长从 `head->next` 数起，从头结点数会让后面所有下标整体差一

## 通用兜底套路
**考频**：2009/2012/2015/2019/2025｜任何一年实在想不出解法时，这条流水线都能保底 10 分
**必背结论**
- 兜底核心一句：**链表题一律先转成数组，数组上用暴力解，能答满三问就有 10 分**。代价是空间 O(n)，但比空着强太多。
- 转数组有两个硬前提：必须先求出表长 n（不知道长度就开不了数组），辅助数组要开 n+1 个且 0 号下标空着不用。
- 官方评分说明写明：采用两遍或多遍扫描、或用了与表长有关的辅助数组，最高给 10 分。这不是偏方，是被官方承认的保底线。
- 数组侧的兜底三件套：暴力枚举全部情况（三重循环也认）、排序后处理（选择排序 O(n²) 就够，不要求快排）、开辅助数组当哈希表。
- 实在没思路也要先写四样东西：结点/结构体定义、函数签名（把已知条件全部当参数）、一句设计思想、复杂度。这四样写完就是一半分。
- 兜底不适用的一种情况：题干明确要求「空间复杂度为 O(1)」，此时转数组会被判为不满足要求，只能老实用双指针，把三问写满仍有 11 分左右。
```c
/* 兜底①：链表转数组。先求长，再存，0 号下标空着不用 */
int *ListToArray(LinkList head, int *pn) {
    int n = 0, i;
    int *A;
    LNode *p = head->next;
    while (p != NULL) { n++; p = p->next; }     /* 不知道长度就开不了数组 */
    A = (int *)malloc((n + 1) * sizeof(int));   /* 开 n+1 个，0 号浪费掉 */
    p = head->next;
    for (i = 1; i <= n; i++) {                  /* 从 1 号对齐链表第 1 个元素 */
        A[i] = p->data;
        p = p->next;
    }
    *pn = n;
    return A;                                   /* 调用者负责 free */
}
/* 兜底②：数组排序。要排序就写选择排序，别在考场上手写快排 */
void SelectSort(int A[], int n) {
    int i, j, k, t;
    for (i = 1; i <= n; i++) {
        k = i;
        for (j = i + 1; j <= n; j++)
            if (A[j] < A[k]) k = j;             /* 找最小值的下标 */
        if (k != i) { t = A[i]; A[i] = A[k]; A[k] = t; }
    }
}
/* 兜底③：全枚举。求最值把 ans 初始化成 INT_MAX，别初始化成 0 */
int MinDist(int A[], int B[], int C[], int na, int nb, int nc) {
    int i, j, k, d, ans = INT_MAX;              /* 初始值必须是最大值 */
    for (i = 1; i <= na; i++)
      for (j = 1; j <= nb; j++)
        for (k = 1; k <= nc; k++) {
            d = abs(A[i] - B[j]) + abs(B[j] - C[k]) + abs(A[i] - C[k]);
            if (d < ans) ans = d;               /* 三重循环 O(n³) 也给分 */
        }
    return ans;
}
```
**五步兜底流水线**
1. 先把结点/结构体定义写上（对链表题），这是白送的一半分。
2. 判断能不能转数组：不需要空间 O(1) 就转，需要就地就退回双指针。
3. 转成数组后用「排序 + 遍历 + 辅助数组」这套组合拳硬解，不要在考场上想最优解。
4. 代码写完补注释，注释只写在循环入口和关键判断处。
5. 复杂度照实写：多趟扫描就写 O(n²)、开了辅助数组就写 O(n)，**别虚报成 O(1)**，虚报反而是扣分项。
! ans 初始化成 0 求最小值，任何距离都比 0 大，永远不会更新·转数组前不先求表长，`malloc` 的参数是未知量，数组根本开不出来·数组从 0 号下标存起却按 1 号取，整体差一位·第 5 步虚报复杂度，比老老实实写 O(n²) 扣得更多
