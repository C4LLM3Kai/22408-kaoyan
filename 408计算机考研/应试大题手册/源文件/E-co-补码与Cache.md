## 补码十条性质速查
**考频**：2011/2017/2019/2020/2021/2022/2024/2025/2026（选择题年年有，大题里作第 1 小问）｜9 年 9 次，是所有运算类题目的地基，2-4 分
**必背结论**
1. 表示范围：$n$ 位补码 $-2^{n-1}\sim 2^{n-1}-1$；4 位 $-8\sim+7$，8 位 $-128\sim+127$，16 位 $-32768\sim+32767$。
2. 补码的 0 唯一（全 0），比原码多表示一个负数 $-2^{n-1}$；$-2^{n-1}$ 只有补码，没有原码和反码。
3. 正数：$[x]_补=[x]_原$，符号位 0，其余位就是二进制本身。
4. 负数求补：符号位不动，从右往左找第一个 1，这个 1 和它右边的 0 都不动，左边的数据位全部取反；等价说法是「按位取反、末位加 1」。
5. 补码求真值：符号位 0 直接读；符号位 1 则数值位取反加 1 得绝对值再加负号。
6. 特殊值：全 1 是 $-1$；1 后面跟 $k$ 个 0 是 $-2^k$（$1000$ 是 $-8$，$1000\ 0000$ 是 $-128$）。
7. 求相反数：$[-A]_补$ 是 $[A]_补$ 全部位（含符号位）取反加 1；机器内部就是「全取反 + 低位进 1」两步。
8. 比大小：同为负数时把补码当无符号数比，大者真值也大；两补码当无符号数差 $d$，真值也差 $d$。
9. 模运算：$[x]_补=2^n+x \pmod{2^n}$，所以加减溢出后截断取低 $n$ 位仍然自洽。
10. 符号扩展：有符号数高位补符号位（负数补 1），无符号数高位补 0，$0xFFF7\to0xFFFFFFF7$。

- 同一个机器数按有符号和无符号读，差值是 $2^n$：$0x86$ 读成 $-122$ 或 $134$，差 256，机器数本身没变，变的只是解释方式。
- 边界值必须背成条件反射：$0x7F=+127$、$0x80=-128$、$0xFF=-1$、$0x7FFF=+32767$、$0x8000=-32768$、$0xFFFF=-1$。

| 编码 | 正数 | 负数 | 关键差别 |
| --- | --- | --- | --- |
| 原码 | 符号位 0 加数值 | 符号位 1 加数值 | 0 有两种写法，表不出 -128 |
| 反码 | 同原码 | 数据位按位取反 | 0 有两种写法 |
| 补码 | 同原码 | 反码末位加 1 | 0 唯一，能表 -128 |
| 移码 | 补码符号位取反 | 同左 | 全 0 对应最小值，常用于阶码 |

> 一串 F 开头的负数：加几能进位成全 0，几就是它的绝对值。$0xFFD3+0x2D=0x10000$，真值 $-45$；$0xFFFF+1=0x10000$，真值 $-1$。反过来给 $-45$ 求 16 位补码，直接写 $0xFFD3$。

**模板/流水线**
```c
/* ① 真值 x → n 位补码 */
if (x >= 0) M = x;                     /* 正数：原码即补码，高位补 0 */
else        M = (1 << n) - (-x);        /* 负数：模 2^n 减去绝对值 */
/* ② n 位补码 M → 真值 */
if ((M >> (n-1)) & 1) v = M - (1 << n); /* 负数 */
else                  v = M;            /* 正数 */
/* ③ 十六进制速算：-45 的 16 位补码 */
// 45 = 0x2D → 想"加什么能进位到 0x10000" → 0xD3 → 前面补满 F → 0xFFD3
/* ④ 符号扩展：16 位 → 32 位 */
// 负数高位全填 1：0xFFD3 → 0xFFFFFFD3；正数高位全填 0：0x007F → 0x0000007F
```
! $1000\ 0000$ 在 8 位补码里是 $-128$，不是 $+128$·「全 1 是 $-1$」「1 后 $k$ 个 0 是 $-2^k$」必须秒答·进位反推法只对「前面连续一串 F」的数成立，$0xCAF8$ 这种老实转原码

## 补码加减与三种判溢出
**考频**：2011（ 补码加减与溢出判断）/2022（ALU 符号与溢出标志逻辑表达式）｜判溢出几乎年年出现，选择或大题第 1 小问，3-5 分
**必背结论**
- 加法：$[x+y]_补=[x]_补+[y]_补 \pmod{2^n}$，符号位当数值位一起加，最高位进位丢弃。
- 减法：$[x-y]_补=[x]_补+[-y]_补$，先求 $[-y]_补$ 再当加法做；也可以直接竖式相减，不够减从最高位借，结果与转加法完全一致。
- 电路实现只有一套：$Sub=1$ 时把 Y 全部取反、$C_{in}$ 给 1；$Sub=0$ 时 Y 不动、$C_{in}$ 给 0。所以减法不是另做一个减法器，而是「加相反数」。
- 三种判溢出互相等价，但机器只能用符号法和进位法；范围法只是人算时的验算手段，答题时写「计算机内部只能按符号位或进位判」才拿满分。
- 正 + 负、负 + 正一定不溢出；只有同号相加、异号相减才可能溢出。
- 上溢指超过 $2^{n-1}-1$，下溢指小于 $-2^{n-1}$；补码下溢不是「归零」，而是符号位翻转、结果被读成一个大正数。
- 进位和溢出是两件事：$0x7F+0x01$ 有溢出但没有进位出，$0xFF+0x01$ 有进位出但没有溢出，所以 OF 和 CF 必须分开算。
- 题问「寄存器里最后是什么值」时不用管溢出：机器只保留低 $n$ 位，模运算保证截断后的机器数自洽；只有题干明确问「是否溢出」才动笔判。

| 方法 | 加法判据 | 减法判据 | 用在哪 |
| --- | --- | --- | --- |
| 范围法 | 结果超出 -2^(n-1) 至 2^(n-1)-1 | 同左 | 人算、验算 |
| 符号法 | 正+正得负、负+负得正 | 正-负得负、负-正得正 | 机器 OF |
| 进位法 | C_n 异或 C_(n-1) 等于 1 | 同左 | 机器 OF |
| 双符号位 | 00 或 11 正常，01 上溢，10 下溢 | 同左 | 人算、判上下溢 |

**模板/流水线**
```c
/* 8 位补码 x - y：四步走，一步都不能省 */
step1: 写 [x]补、[y]补        // 负数：符号位不动，最右 1 及其右边 0 不动，其余取反
step2: [-y]补 = [y]补 全部 8 位取反，末位加 1
step3: [x]补 + [-y]补 列竖式  // 符号位一起加，第 9 位进位直接丢
step4: 判溢出              // 正-负得负 或 负-正得正 → 溢出；同号相加变号 → 溢出
/* 例：4 位 +5 + 3 = 0101 + 0011 = 1000，读作 -8，正+正得负 → 上溢 */
/* 例：4 位 -5 + -4 = 1011 + 1100 = 1 0111 → 0111 = +7，负+负得正 → 下溢 */
/* 例：16 位 x = 0xFFDF(-33)，y = 0x0041(+65) */
// x - y = 0xFFDF + 0xFFBF = 0x1FF9E → 取低 16 位 0xFF9E = -98
// 判溢出：负 - 正 = 负，符号没变 → 不溢出，结果可用
```
! 溢出后机器照样输出一个数，不判溢出直接写答案是大题第一扣分点·减法必须先转 $[-y]_补$ 再当加法判，别拿「正-负」去套「正+负」·双符号位只是人算工具，别写成机器判据

## 标志位 CF/ZF/OF/SF
**考频**：2022（ ALU 溢出与符号标志逻辑表达式）/2013（条件转移与标志位）/2021/2024（RISC-V 指令 ALU 溢出）｜2-3 年一次，选择必考，大题作小问，2-4 分
**必背结论**
- $OF=C_n \oplus C_{n-1}$，判有符号数溢出，只对有符号数有意义。
- $CF=Sub \oplus C_{out}$，加法时 CF 是进位、减法时 CF 是借位，只对无符号数有意义。
- $ZF=1$ 当且仅当结果各位全 0，有符号数与无符号数都有意义。
- $SF$ 取结果的最高位，判有符号数的正负。
- 要求写成逻辑表达式时（2022 考法）：$OF=\bar{A_n}\bar{B_n}S_n+A_nB_n\bar{S_n}$，即「两个加数符号相同、结果符号与之不同」。
- $Sub=1$ 做减法：Y 每一位取反且 $C_{in}=1$，即 $A-B=A+\bar{B}+1$；$Sub=0$ 做加法，Y 不动且 $C_{in}=0$。
- 同一个加法器既算无符号也算有符号，机器数相同结果就相同，差别只在标志位怎么解释。

| 运算 | 结果 | CF | OF | ZF | SF |
| --- | --- | --- | --- | --- | --- |
| 0x05 + 0x02 | 0x07 | 0 | 0 | 0 | 0 |
| 0x05 - 0x02 | 0x03 | 0 | 0 | 0 | 0 |
| 0x7F + 0x01 | 0x80 | 0 | 1 | 0 | 1 |
| 0xFF + 0x01 | 0x00 | 1 | 0 | 1 | 0 |
| 0x80 + 0x80 | 0x00 | 1 | 1 | 1 | 0 |

**条件转移就是查这张表**
- `CMP A,B` 实质是做 $A-B$ 但不写回，只置标志，所以后面的条件转移全靠 CF、ZF、SF、OF 四个位。
- 无符号比较看 CF 和 ZF：$A>B$ 是 $CF=0$ 且 $ZF=0$；$A\ge B$ 是 $CF=0$；$A<B$ 是 $CF=1$。
- 有符号比较看 SF、OF、ZF：$A>B$ 是 $SF=OF$ 且 $ZF=0$；$A<B$ 是 $SF\ne OF$；$A=B$ 是 $ZF=1$。
- 2013 年那道「条件转移指令的转移条件」就考这个对应关系，别去背汇编助记符，背「无符号看 CF、有符号看 SF 与 OF」。
- 移位指令也会改 CF：最后移出去的那一位进 CF，所以「CF 里是刚才移出的位」这句话在移位指令后成立，在加减指令后是进位或借位。
- 答题时先问一句「这条指令的数是有符号还是无符号」，再决定看 OF 还是 CF；两个都算出来但只解释一个，另一个按标准写「无意义」。

**模板/流水线**
```c
/* n 位加减法器：sub=0 加，sub=1 减，带回四个标志 */
unsigned AddSub(unsigned x, unsigned y, int sub, int n,
                int *CF, int *OF, int *ZF, int *SF) {
    unsigned mask = (n == 32) ? 0xFFFFFFFFu : ((1u << n) - 1);
    unsigned lo   = (1u << (n-1)) - 1;              /* 低 n-1 位 */
    unsigned t    = sub ? (~y & mask) : y;          /* 减法先把 Y 全取反 */
    unsigned s    = x + t + (sub ? 1u : 0u);        /* 第 n 位就是 C_out */
    unsigned r    = s & mask;                       /* 结果低 n 位 */
    unsigned cout = (s >> n) & 1u;
    unsigned cn1  = (((x & lo) + (t & lo) + (sub ? 1u : 0u)) >> (n-1)) & 1u;
    *CF = (sub ^ cout) & 1u;                        /* 加法看进位，减法看借位 */
    *OF = cout ^ cn1;                               /* C_n 异或 C_(n-1) */
    *ZF = (r == 0);
    *SF = (r >> (n-1)) & 1u;
    return r;
}
```
! CF 对无符号、OF 对有符号，别把两者当同一个东西·减法时 $CF=1$ 表示不够减（有借位），不是「有进位」·ZF 与溢出无关：0x80+0x80 结果 0、ZF=1 但已经溢出

## 移位：算术逻辑循环
**考频**：2020（ 移位乘法）/2017（无符号数循环移位）｜很少单独成题，但乘法流水线与循环移位判断年年要用，2-3 分
**必背结论**
- 算术左移与逻辑左移相同：低位补 0，左移 1 位相当于乘 2，符号位变了就溢出。
- 算术右移：高位补符号位，低位丢弃；补码算术右移 1 位等于除以 2 后向下取整，$-5$ 右移得 $-3$ 不是 $-2$。
- 逻辑右移：高位补 0，只用于无符号数；有符号数如果误用逻辑右移，负数会变成大正数。
- 循环移位：移出的位补到另一端，$n$ 位循环移动 $n$ 位数值复原；小循环只在本寄存器内转，大循环把 CF 串进来一起转。
- 原码移位规则不同：符号位不动，数据位左移补 0、右移补 0；只有补码右移才补符号位。
- 左移判溢出：移位前后符号位不同即溢出，不是看有没有位被移出去；右移不会溢出，只会丢低位。
- 移位量是常数时算「×/÷ 2 的幂」，题目问「用移位和加法实现乘 6」就拆成 $x<<2$ 加 $x<<1$。
- 乘法流水线里的「右移」是把部分积和乘数寄存器连成一个整体右移一位，不是只移部分积，写流程时别漏掉乘数寄存器。

| 类型 | 规则 | 1011 操作后 |
| --- | --- | --- |
| 算术左移 | 低位补 0 | 0110，符号位由 1 变 0，溢出 |
| 算术右移 | 高位补符号位 1 | 1101，即 -3 |
| 逻辑右移 | 高位补 0 | 0101，即 +5 |
| 循环右移 | 移出位补到最高位 | 1101 |
| 循环左移 | 移出位补到最低位 | 0111 |

**模板/流水线**
```c
/* n 位循环移位：k 必须先对 n 取模，题目常给 k > n */
unsigned rotl(unsigned x, int k, int n) {
    unsigned mask = (n == 32) ? 0xFFFFFFFFu : ((1u << n) - 1);
    k %= n;  x &= mask;
    return k ? (((x << k) | (x >> (n - k))) & mask) : x;
}
/* 例：8 位 0xA5 = 1010 0101 循环左移 3 位 */
// (0xA5 << 3) & 0xFF = 0x28，0xA5 >> 5 = 0x05 → 0x2D = 0010 1101
/* 算术右移手算：负数最高位补 1，其余右移 */
// -5 的 4 位补码 1011 算术右移 1 位 → 1101 = -3
/* 算术左移判溢出：移位前后符号位不同即溢出 */
// 0101(+5) 左移 1 位 = 1010(-6)，符号位变了 → 溢出
```
! 算术右移补的是符号位不是 0，负数右移后仍是负数·左移判溢出看符号位是否变化，不看有没有进位出·循环移位前先 $k \bmod n$，忘了取模整题错

## 乘法与除法流水线
**考频**：2020（ 移位乘法与 2n 位乘积溢出）/2019（乘法溢出）/2017/2025（补码除法器与除法异常）｜乘法约 3 年一次，除法 2025 新考，5-8 分
**必背结论**
- 没有乘法指令时：乘法 = 加法 + 移位。$13\times6=13\times(4+2)$，即 13 左移 2 位加 13 左移 1 位，得 110100 加 011010 等于 1001110。
- 控制逻辑的作用是控制累加次数（循环次数），次数等于乘数的位数 $n$；这就是「ALU 只有加减和移位也能做乘法」的标准答法。
- 时间从小到大：阵列乘法器（1 个时钟周期）< 乘法指令（一条指令多周期）< 加法加移位多条指令（每条都要取指）。
- $n$ 位乘 $n$ 位用 $2n$ 位存乘积一定不溢出；只取低 $n$ 位才判溢出：无符号看高 $n$ 位是否全 0，有符号看高 $n$ 位是否全为符号位的重复（正数全 0、负数全 1）。
- 补码一位乘（Booth）：乘数末尾加附加位 $y_{n+1}=0$，看 $y_i y_{i+1}$ 两位，00 或 11 不加，01 加 $[x]_补$，10 加 $[-x]_补$，然后部分积与乘数一起算术右移一位，共 $n$ 次；符号位自然形成，不用单独异或。
- 原码一位乘：符号位单独用异或算，数值部分当无符号数做移位乘法，最后拼回去。
- 补码除法（加减交替，又叫不恢复余数法）：余数与除数同号则商 1 并减除数，异号则商 0 并加除数，每步先左移一位；恢复余数法每步要试减、不够减还要加回来，步数不固定，考试写加减交替。
- 除法异常只有两个来源：除数为 0，以及 $(-2^{n-1})\div(-1)$ 的商溢出（结果 $+2^{n-1}$ 表示不了），两条都要写。

| 方法 | 符号处理 | 步数 |
| --- | --- | --- |
| 原码一位乘 | 符号单独异或 | n 次加与右移 |
| 补码一位乘 Booth | 符号自然形成 | n 次加与算术右移 |
| 原码除法 恢复余数 | 符号单独异或 | 不固定，最多 2n 次 |
| 补码除法 加减交替 | 符号自然形成 | 固定 n 次 |

**模板/流水线**
```c
/* 补码一位乘 Booth：n 位 x 乘 n 位 y，D 是双符号位部分积，2n 位 */
D = 0; A = x; Q = y; q = 0;             /* q 是附加位 y(n+1) */
for (i = 0; i < n; i++) {               /* 循环 n 次，n 由乘数位数定 */
    switch (((Q & 1) << 1) | q) {       /* 看 y(i) y(i+1) 两位 */
        case 0: case 3: break;          /* 00 / 11：不加 */
        case 1: D = D + A; break;       /* 01：加 [x]补 */
        case 2: D = D - A; break;       /* 10：加 [-x]补 */
    }
    q = Q & 1;                          /* 乘数最低位进附加位 */
    Q = (Q >> 1) | ((D & 1) << (n-1));  /* 部分积最低位补进乘数最高位 */
    D = (D >> 1) | (D & (1 << (2*n)));  /* 算术右移，保持双符号位 */
}
/* 乘积 = D 的低 n 位拼接 Q，共 2n 位 */
/* 只取低 n 位判溢出：高 n 位全 0（无符号）或全为符号位重复（有符号）才不溢出 */
/* 例：乘积 2^32-2，无符号 32 位上界 2^32-1 → 不溢出；有符号上界 2^31-1 → 溢出 */
```
! 判溢出必须分有符号、无符号两套判据，混用必错·循环次数由乘数位数决定，不是被乘数·除法异常要写全两条，只写「除数为 0」丢分

## Cache 五角度总览
**考频**：2010/2012（交叉存储器带宽）/2013/2014/2016/2018/2019/2020/2021/2023/2025（第 43 或 44 题）｜11 年 11 次，计组第一大题来源，10-15 分
**必背结论**
- 一句话：映射方式决定地址结构，其余四问都是从地址结构上长出来的。
- 五个角度固定：映射方式、总容量、命中率、访问过程、比较器个数与位数。
- 考法极固定，题干每句话都有用，没有一句废话；读完先把「块大小、行数、路数、地址位数」四个数圈出来。
- 命中判定两把锁：地址切出来的标记等于该行存的标记，且该行有效位为 1，缺一个都算缺失。
- 命中之后还有一步：按块内地址从该块中取出那一个数据，答「访问过程」漏这一步就扣分。
- 缺失处理固定四步：整块调入对应行、写入标记、有效位置 1、再按块内地址取数。
- 比较器个数：直接映射 1 个，全相联等于行数，组相联等于路数；位数恒等于标记位数，因为它比的就是标记。
- 与 TLB 的关系：Cache 查物理地址、存数据；快表查逻辑地址、存页框号；两者都是缓存，都不属于主存。

| 角度 | 典型问法 | 落点 |
| --- | --- | --- |
| 映射方式 | 直接还是组相联，标记几位 | 地址结构，标记等于块号除以行数（或组数）的商 |
| 总容量 | Cache 总容量多少位 | 行数乘以每行（数据加标记加有效位加脏位加替换位） |
| 命中率 | 给一段循环，求缺失率或缺失次数 | 每块首次访问必缺失，读写各算一次访问 |
| 访问过程 | 给一个地址，是否命中、怎么取数 | 定位行或组，比标记与有效位，按块内地址取数 |
| 比较器 | 几个比较器、位数几位 | 直接 1 个，全相联等于行数，组相联等于路数，位数等于标记位数 |

**模板/流水线**
```c
/* Cache 大题固定五步，按顺序写；某步写不下去说明上一步漏了条件 */
step1: 定地址位数        // 按字节编址：地址空间字节数取 log2；按字编址：先除字长
step2: 拆低位            // 块内地址 = log2(块大小)；行数 = 数据区容量 / 块大小
step3: 拆中位            // 组号 = log2(行数 / 路数)；直接映射用行号 = log2(行数)
step4: 剩余高位当标记    // 标记 = 地址位数 - 块内 - 行号(或组号)
step5: 容量与命中率      // 每行容量乘行数；先验证是否占整数个块再算缺失率
```
! 标记位数只能由地址结构算，不能拿「Cache 里存了几个标记」去凑·命中要「标记相等且有效位为 1」两个条件同时成立·说明访问过程最后一步必须写「按块内地址取出那一个数据」，漏了扣分

## Cache 地址拆分模板
**考频**：2010（映射与命中率）/2016（映射与虚实地址分段）/2019（地址分段）/2021（TLB 组相联）｜地址拆分是每年第 1 小问，4-6 分
**必背结论**
- 块内地址位数 $=\log_2(\text{块大小})$；按字编址时 $=\log_2(\text{块大小}/\text{字长})$。64B 块配 4B 字只占 16 个地址，块内地址 4 位而不是 6 位。
- 直接映射：地址 = 标记 ｜ 行号 ｜ 块内，$\text{行号}=\text{块号}\bmod\text{行数}$，$\text{标记}=\lfloor\text{块号}/\text{行数}\rfloor$。
- 全相联：地址 = 标记 ｜ 块内，标记就是整个块号，没有行号字段，所以全相联必须配替换算法。
- 组相联：地址 = 标记 ｜ 组号 ｜ 块内，$\text{组号}=\text{块号}\bmod\text{组数}$，$\text{标记}=\lfloor\text{块号}/\text{组数}\rfloor$。
- 组相联是组间直接映射、组内全相联；$k$ 路组相联就是每组 $k$ 块，行数 $=$ 组数 $\times$ 路数。
- 快表完全同构：块号换成虚页号，块内地址换成页内地址，行数或组数换成快表的行数或组数；4KB 页对应页内地址 12 位。
- 组相联的路数必是 2 的幂，所以组数也是 2 的幂，组号位数才对得上；题目给「8 行、二路组相联」就自动是 4 组、组号 2 位。
- 二进制切法：从低位往高位切，先块内，再行号或组号，剩下全是标记；十进制除法则反过来先求块号再拆。
- 两种方法互为验算：$3200$ 拆成 12 位二进制是 $1100\ 1000\ 0000$，低 6 位 $000000$ 是块内地址 0，接着 3 位 $010$ 是行号 2，剩下 $110$ 是标记 6，与除法结果完全一致。
- 虚实地址转换顺序（2016/2019 考法）：虚地址拆虚页号加页内地址，查 TLB 或页表得页框号，页框号与页内地址拼接成物理地址，再用物理地址拆 Cache 的标记、组号、块内。

**模板/流水线**
```c
/* 十进制两步除法，任何映射都能用，还能反查位数 */
q1 = addr / block_size;  r1 = addr % block_size;  /* q1 = 块号，r1 = 块内地址 */
if (直接映射) { tag = q1 / lines; idx = q1 % lines; }  /* idx = 行号 */
if (组相联)   { tag = q1 / sets;  idx = q1 % sets;  }  /* idx = 组号 */
if (全相联)   { tag = q1; }                             /* 整个块号就是标记 */
/* 校验：tag < 2^(地址位数 - log2(块大小) - log2(行数或组数)) */
/* 例：直接映射，块 64B，8 行，地址 3200 */
// 3200 / 64 = 50 余 0 → 块号 50，块内地址 0
// 50 % 8 = 2 → 行号 2；50 / 8 = 6 → 标记 6
/* 例：32 位地址，块 64B，数据区 32KB，8 路组相联 */
// 块内 6 位；32KB / 64B = 512 行，512 / 8 = 64 组 → 组号 6 位
// 标记 = 32 - 6 - 6 = 20 位
/* 例：4KB 页，32 位虚地址，快表 8 组 4 路 */
// 页内地址 12 位；虚页号 20 位；组号 3 位；标记 = 32 - 12 - 3 = 17 位
```
! 块号取余得行号、取商得标记，商和余数写反最致命·按字编址时块内地址由地址个数决定，直接写 $\log_2$ 块字节数必错·「地址里的标记」与「Cache 行里存的标记」位数相同含义不同，命中就是比较这两个

## Cache 总容量与性能计算
**考频**：2010/2013（缺失下总执行时间）/2018（Cache 参数）/2020（缺失次数）/2023（数组遍历命中率）/2025（缺失率与缺页统计）｜每年至少 1 小问，4-8 分
**必背结论**
- $\text{总容量}=\text{行数}\times(\text{数据块}+\text{标记}+\text{有效位}+\text{脏位}+\text{替换位})$，全部换成比特再相加。
- 数据块位数 = 块大小 $\times 8$；标记位数由地址结构定；有效位恒 1 位，题目不会白给，必须自己加。
- 脏位：写回 1 位、写直达 0 位；替换算法位：直接映射 0 位、全相联 $\log_2\text{行数}$、组相联 $\log_2\text{路数}$。
- 行数 = 数据区容量 ÷ 块大小；组数 = 行数 ÷ 路数。题目给的「数据区 32KB」只是数据部分，不是总容量。
- 缺失率：数据占满整数个块时 = 每块缺失次数 ÷ 每块访问次数；不占整数块时只能 = 总缺失次数 ÷ 总访问次数。
- $h=1-m$，缺失次数 = 总访问次数 $\times$ 缺失率；块的首次访问必缺失，同一块后面的访问才命中。
- 平均访问时间 $T=t_c+(1-h)\cdot t_m$；缺失代价 = 主存访问延迟 + 整块传输时间，通常几十个时钟周期。
- CPU 总时间 $=IC\times(CPI+(1-h)\times\text{缺失代价})\times T_{clk}$，2013 年那道「Cache 缺失下的总执行时间」就是直接代这个式子。
- 加速比 = 不用 Cache 的时间 ÷ 用 Cache 的时间，别把分子分母写反。
- 算完记得回单位：$274432$ 位是 $34304$ 字节，数据区 $32$KB 是 $32768$ 字节，多出来的 $1536$ 字节就是标记、有效位、替换位这些开销，答题时点一句「额外开销 1.5KB」是加分细节。

| 场景 | 每行位数 | 总容量 |
| --- | --- | --- |
| 直接映射 8 行 64B 块 256MB 主存 | 512+19+1 = 532 | 4256 位 |
| 8 路组相联 512 行 64B 块 直写 32 位地址 | 512+20+1+0+3 = 536 | 274432 位 |

**模板/流水线**
```c
/* 容量与性能：一行一行代，单位统一成比特 */
lines = data_size / block_size;        /* 数据区容量 ÷ 块大小 */
sets  = lines / ways;                  /* 组相联才需要除 */
bits_data = block_size * 8;            /* 字节转比特，最常漏的一步 */
bits_tag  = addr_bits - log2(block_size)
          - (直接 ? log2(lines) : 组相联 ? log2(sets) : 0);
bits_line = bits_data + bits_tag + 1
          + (回写 ? 1 : 0)
          + (直接 ? 0 : 组相联 ? log2(ways) : log2(lines));
total = lines * bits_line;             /* 单位：比特 */
miss = miss_times / total_access;      /* 读写各一次时访问次数要乘 2 */
T_avg = t_cache + miss * t_miss;       /* 平均访问时间 */
T_cpu = IC * (CPI + miss * miss_penalty) * T_clk;  /* CPU 总时间 */
/* 例：块 16B 每数据 4B，A[i]=A[i]+32，1000 个元素 */
// 每块 4 个数据、每元素读 1 次写 1 次 → 每块 8 次访问缺 1 次 → 缺失率 1/8
// 1000 / 4 = 250 块（占整数个块，前提成立）；缺失 250 次，命中率 7/8
/* 例：t_cache = 1 周期，t_miss = 50 周期，h = 0.95 */
// T_avg = 1 + 0.05 * 50 = 3.5 周期
/* 例：IC = 10^6，CPI = 2，缺失率 0.02，缺失代价 20 周期 */
// CPI' = 2 + 0.02 * 20 = 2.4，总时间 = 10^6 * 2.4 * T_clk
```
! 标记按比特、块大小按字节，不乘 8 直接相加是最常见算错·「数据区容量」只是数据部分，总容量必须再加标记、有效位、脏位、替换位·$A[i]=A[i]+32$ 是读一次写一次共 2 次访问，缺失率 1/8；只有读或只有写才是 1/4

## Cache 写策略与脏位
**考频**：2016（Cache 参数与虚实地址分段）/2025（缺失率与缺页统计）｜写策略常嵌在容量与缺失统计里作小问，2-4 分
**必背结论**
- 写直达又称全写法、直写：每次写都同时改 Cache 和主存，主存始终最新，没有脏位。
- 写回又称回写法：只改 Cache 并置脏位 1，该行被替换时才写回主存；脏位为 0 则直接丢弃。
- 写分配：写缺失时先把整个块调入 Cache 再写，通常配写回，因为「既然要写，先把整块拿来」。
- 非写分配：写缺失直接写主存、不调入 Cache，通常配写直达，避免为一次写搬一整块。
- 写回时写主存的次数等于被替换且脏位为 1 的行数，不等于写操作次数；写直达时写主存次数等于写操作次数。
- 写直达虽然简单，但每次写都占总线，所以要配写缓冲；多级 Cache 的 L1 多用写回以减少总线流量。
- 脏位又叫修改位、一致性维护位；写直达不需要脏位，因为它不存在「主存落后」的状态。
- 对总容量的影响只有 1 位：512 行的 Cache 从写回改直写，总容量减少 512 位，即 64B。
- 指令 Cache 只读不写，所以脏位只在数据 Cache 上有意义；题干说「指令 Cache 与数据 Cache 分离」时，算指令 Cache 可以不配脏位。

| 策略组合 | 写命中 | 写缺失 | 脏位 |
| --- | --- | --- | --- |
| 写直达加非写分配 | 同时写 Cache 与主存 | 只写主存，不调入 | 无 |
| 写回加写分配 | 只写 Cache，置脏位 1 | 先调入块再写 | 1 位 |

**模板/流水线**
```c
/* 写策略只影响两处：脏位位数、写主存次数 */
bits_line += (回写 ? 1 : 0);            /* 直写加 0 位，别多给 */
total = lines * bits_line;              /* 总容量随之变化 */
write_back_times = 脏行被替换的次数;      /* 直写策略下额外写主存为 0 次 */
/* 四个组合照抄 */
// 写直达 + 非写分配：写命中 → 两级同写；写缺失 → 只写主存
// 写回   + 写分配  ：写命中 → 只写 Cache 并置脏；写缺失 → 调入块后写
/* 判据一句话：问"总容量"看脏位是否 1 位，问"写主存几次"看脏行数 */
// 例：替换 100 次、其中脏行 60 个 → 写回时额外写主存 60 次；直写时替换不额外写回 → 0 次
```
! 写直达没有脏位，给直写加 1 位是白送分·「是否调入」由写分配决定，与写直达写回是两个独立维度·写回策略下写主存次数不等于写操作次数，只有被替换的脏行才写回
