## 排序总表（必背）
**考频**：选择常考，大题未考｜这张表是排序全部选择题的出处；服务 2022 堆排序、2023 外部排序两道应用题
**必背结论**
- 稳定的 5 个：直接插入、折半插入、冒泡、二路归并、基数排序；不稳定的 4 个：希尔、快速、简单选择、堆（口诀「快些选堆」）。
- 与初始序列无关的 4 个：简单选择、堆、归并、基数——比较次数或总时间与数据初态无关，正序逆序一样慢。
- 平均 $O(n\log n)$ 而最坏掉到 $O(n^2)$ 的只有快速排序；最好、平均、最坏三态同阶的只有堆、归并、基数、简单选择。
- 空间不是 $O(1)$ 的只有 3 个：快排 $O(\log n)$ 到 $O(n)$（递归栈）、归并 $O(n)$、基数 $O(r)$。
- 比较次数恒为 $n(n-1)/2$ 的是简单选择；移动次数至多 $n-1$ 次的也是它。
- 必须用数组实现：希尔、快速、堆（不相邻交换、要由孩子找父结点）；数组链表都行：直接插入、冒泡。
- 同为最好 $O(n)$ 但走法不同：冒泡是「1 趟乘 $n-1$ 次比较」，直接插入是「$n-1$ 趟各 1 次比较」。
- 基数排序的 $d$ 是关键字位数（三位数 $d=3$），$r$ 是每位的基数（十进制 $r=10$），两者别混。

**模板/流水线**
| 排序 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 与初始序列有关 |
| --- | --- | --- | --- | --- | --- | --- |
| 直接插入 | O(n) | O(n^2) | O(n^2) | O(1) | 稳定 | 有关 |
| 折半插入 | O(n) | O(n^2) | O(n^2) | O(1) | 稳定 | 仅比较有关 |
| 希尔 | O(n^1.3) | O(n^1.3) | O(n^2) | O(1) | 不稳定 | 有关 |
| 冒泡 | O(n) | O(n^2) | O(n^2) | O(1) | 稳定 | 有关 |
| 快速 | O(nlogn) | O(nlogn) | O(n^2) | O(logn) | 不稳定 | 有关 |
| 简单选择 | O(n^2) | O(n^2) | O(n^2) | O(1) | 不稳定 | 无关 |
| 堆排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | 不稳定 | 无关 |
| 二路归并 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | 稳定 | 无关 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 | 无关 |

> 四问四答就能选：稳定吗、空间是 1 吗、三态同不同阶、受不受初态影响。表里九行背到能默写，排序选择题一题不失。

! 快排空间不是 O(1)，写 O(logn) 才是标准答案，写 O(nlogn) 会被判错·堆排序三态都是 O(nlogn)，别顺手写成「最坏 O(n^2)」·折半插入只减比较次数、不减移动次数，总时间仍 O(n^2)

## 一趟结果的判定
**考频**：选择常考，大题未考｜排序选择题出现最多的一类反推题；服务 2016 划分结果的判定
**必背结论**
- 直接插入：第 $k$ 趟后前 $k+1$ 个有序，且第 $k+2$ 位起与原序列逐位相同——后缀原封不动是它唯一的指纹。
- 折半插入：一趟结果与直接插入完全一样，序列分不出来，只能靠「比较次数变少」认。
- 冒泡：第 $k$ 趟后末尾（大数下沉）或开头（小数上浮）连续 $k$ 个就位，其余部分被打乱。
- 简单选择：第 $k$ 趟后前 $k$ 个是全局最小的 $k$ 个且升序，看不出「逐步插入」的痕迹。
- 堆排序：第 $k$ 趟后末尾 $k$ 个升序就位，前面 $n-k$ 个仍是堆序而不是有序。
- 快排：一趟只定一个元素（枢轴），且它左边全不大于它、右边全不小于它；若一趟后已就位两个以上且分处两端，直接排除快排。
- 归并：第 $k$ 趟后每 $2^k$ 个一段内部有序（段长 1、2、4、8 倍增），段间无序。
- 希尔：每隔 $d$ 个有序；反推 $d$ 就看有序元素之间的最小下标差。
- 基数：按某一位整体有序、低位优先，看个位还是十位已经全序，就知道做了几趟。

**模板/流水线**
1. 先数「已站到最终位置」的元素个数：0 个 → 归并、希尔、基数、直接插入；恰好 1 个在中间 → 快排。
2. 就位元素在两端连成连续一块：块在后 → 冒泡或堆；块在前 → 简单选择。
3. 直接插入与冒泡、选择的硬分界：直接插入的后缀与原序列逐位相同，另外两个的后缀被打乱。
4. 有序段长度按 1、2、4、8 倍增 → 归并；每隔 $d$ 个有序 → 希尔。
5. 冒泡与堆都让末尾就位，区别在未就位段：冒泡段内无序但有交换痕迹，堆的未就位段是标准大根堆（首位是剩余最大值）。

```c
#include <stdio.h>
#define N 7
/* p 是"某一趟后"的序列：存在 k 使 p[0..k-1] 升序且 p[k..n-1] 与原序列逐位相同 -> 插入类 */
int PrefixSorted(int p[], int k) {
    int i;
    for (i = 1; i < k; i++) if (p[i - 1] > p[i]) return 0;
    return 1;
}
int SuffixSame(int a[], int p[], int n, int from) {
    int i;
    for (i = from; i < n; i++) if (a[i] != p[i]) return 0;
    return 1;
}
int IsInsertPass(int a[], int p[], int n) {
    int k;
    for (k = 2; k <= n; k++)                /* 第 1 趟后前 2 个有序，第 k 趟后前 k+1 个 */
        if (PrefixSorted(p, k) && SuffixSame(a, p, n, k)) return k;
    return -1;                              /* 不是插入类 */
}
```

! 「第二趟后前 2 个有序」是错的：第一趟才前 2 个，第二趟是前 3 个，选项里出现这种说法就是设给直接插入的陷阱·快排第二趟定义是左右两边各划分一次，不是左边一趟右边一趟·判定题先找有没有单个元素「左全小右全大」，这是快排的独家签名

## 快排划分模板
**考频**：2016｜数据结构算法题里唯一以排序为外壳的题，划分模板值 8 分
**必背结论**
- 一趟划分 $O(n)$、空间 $O(1)$、不稳定；整体快排平均 $O(n\log n)$、最坏 $O(n^2)$、空间 $O(\log n)$ 到 $O(n)$。
- 枢轴取首元素就先 `j--`，取末元素就先 `i++`：方向写反会覆盖还没用到的数据。
- 一趟划分只保证「左边全部不大于枢轴、右边全部不小于枢轴」，两侧内部仍无序。
- 2016 的真身是快速选择：找第 $n_1$ 小（$n_1=\lceil n/2\rceil$），枢轴落到下标 $n_1-1$ 时划分即达标，平均 $O(n)$、空间 $O(1)$。
- 只递归「含 $n_1$ 的那一侧」，另一侧整块丢弃——这就是从 $O(n\log n)$ 降到 $O(n)$ 的唯一原因。
- 划分的副产品：枢轴下标 $p$ 就是「左边有几个比它小」，是第 $k$ 小问题和大题里定位切点的通用工具。
- 每趟比较次数只与枢轴比，总比较约 $n\log n$；移动只发生在交换处，划分越不均匀趟数越多。
- 最坏退化：原序列已升序且取首元素做枢轴，每趟只能固定一个元素，比较次数为 $n+(n-1)+\cdots+1$。

**模板/流水线**
```c
#include <stdio.h>
#define N 9
/* 一趟划分：枢轴取 a[l]，返回枢轴最终下标；左 <= 枢轴 <= 右 */
int Partition(int a[], int l, int r) {
    int pivot = a[l], i = l, j = r;             /* 枢轴先取出，l 处成为空位 */
    while (i < j) {
        while (i < j && a[j] >= pivot) j--;     /* 先右后左，方向不能反 */
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;                               /* 相遇处填回枢轴 */
    return i;
}
/* 2016：划分成 A1、A2，A1 有 n1 个且全不大于 A2（题干要求 n1<=n2 时把 k 改成 n/2） */
int Split(int a[], int n) {
    int k = (n + 1) / 2, l = 0, r = n - 1, p;
    while (l < r) {
        p = Partition(a, l, r);
        if (p == k - 1) return p;               /* 枢轴正好落在分界线上，收工 */
        if (p < k - 1) l = p + 1;               /* 只在含分界点的一侧继续 */
        else r = p - 1;
    }
    return l;
}
```

> 设计思想第一句照抄：「采用快速排序的划分思想，以首元素为枢轴做一趟划分，枢轴落位即把数组分成不大于与不小于两半；只在含目标位置的一侧继续划分，平均时间 $O(n)$，空间 $O(1)$。」

! 枢轴必须用临时变量存住，直接拿 `a[l]` 当空位最后填不回原值·`Split` 两侧改成 `while` 迭代，写成递归虽不扣分但空间就不是 O(1) 了·$n_1$ 取上取整还是下取整看题干给 $n_1\ge n_2$ 还是 $n_1\le n_2$，方向抄反整题白做

## 堆三动作与堆排序
**考频**：2022（应用题）｜堆的建立、插入、删除三个动作的比较次数几乎隔年一道选择，2022 直接考大题
**必背结论**
- 建堆：从 $\lfloor n/2\rfloor$ 号结点倒着调到 1 号，每个结点向下调整；比较次数不超过 $4n$，时间 $O(n)$，不是 $O(n\log n)$。
- 插入：新结点放末尾，只与父结点比、只往上走，不左右比、不向下调整；比较次数不超过 $\lceil\log_2(n+1)\rceil$。
- 删除堆顶：末元素顶上来，从根持续向下；每层先左右比一次选出较大孩子，再与待调元素比一次，共约 $2\log_2 n$ 次。
- 堆排序 = 建堆 + $n-1$ 次删除堆顶；时间恒 $O(n\log n)$、空间 $O(1)$、不稳定、只能用数组。
- 下标关系（从 1 开始存）：父 $\lfloor x/2\rfloor$、左孩子 $2x$、右孩子 $2x+1$；大根堆满足 $a[x]\ge a[2x]$ 且 $a[x]\ge a[2x+1]$。
- 找最小的 $k$ 个数用大根堆（堆顶是这 $k$ 个里最大的），找最大的 $k$ 个反过来用小根堆；时间 $O(n)$、空间 $O(1)$。
- $O(n)$ 的来源：建 $k$ 个元素的堆只要 $O(k)$，之后每个元素最多下沉 $\log k$ 层，共 $O(n\log k)$，$k$ 为常数时写作 $O(n)$。

**模板/流水线**
```c
#include <stdio.h>
#define N 7
/* 下沉：a[x] 与较大的孩子比，小就换，换完继续往下——不能调一次就停 */
void SiftDown(int a[], int x, int n) {
    int ch = 2 * x, t;
    while (ch <= n) {
        if (ch + 1 <= n && a[ch + 1] > a[ch]) ch++;  /* 先左右比，选出较大的孩子 */
        if (a[ch] <= a[x]) break;                    /* 再与待调元素比，不大就停 */
        t = a[x]; a[x] = a[ch]; a[ch] = t;           /* 交换后继续向下 */
        x = ch; ch = 2 * x;
    }
}
void BuildHeap(int a[], int n) {
    int i;
    for (i = n / 2; i >= 1; i--) SiftDown(a, i, n);  /* 从最后一个非叶子结点倒着调 */
}
void HeapSort(int a[], int n) {
    int i, t;
    BuildHeap(a, n);
    for (i = n; i > 1; i--) {                        /* n-1 趟，每趟取走堆顶放末尾 */
        t = a[1]; a[1] = a[i]; a[i] = t;
        SiftDown(a, 1, i - 1);
    }
}
```

> 拿 [6,1,5,9,8,4,7] 默推一遍当自检：建堆得 [9,8,7,1,6,4,5]（比较 8 次）→ 删堆顶得 8、再删得 7 → 最终 [1,4,5,6,7,8,9]。2022 那道应用题就是把这个过程逐趟写出来。

! 建堆和删除都要「持续向下」，换下去的结点还得再比一层，漏了这一步全错（阅卷最容易扣分处）·插入只往上比，别顺手写左右比，那会把比较次数算多·堆排序的数组从 1 开始用，写成 0 起始时父子公式变成 2x+1、2x+2，考场上别两种混用

## 归并与逆序对
**考频**：选择常考，大题未考｜服务 2011 ：两有序序列中位数就是归并双指针走到第 $n$ 步
**必背结论**
- 趟数 $S=\lceil\log_2 n\rceil$，每趟 $O(n)$（全部元素扫一遍），最好平均最坏都是 $O(n\log n)$、都是 $S$ 趟。
- 空间 $O(n)$（辅助数组），必须开；想原地合并会覆盖还没搬走的数据。
- 稳定：合并时写 `a[i] <= a[j]` 取左边，相等元素不换位；写成 `<` 就变不稳定。
- 逆序对：右段元素先出时，左段剩下的 $m-i+1$ 个全比它大，逆序对数直接加 $m-i+1$，总时间仍是 $O(n\log n)$。
- 合并两个有序表：双指针谁小取谁，一段走完把另一段整段搬过去，$O(m+n)$，不需要任何排序。
- 归并是外部排序的内核；多路归并（$k$ 路）就是把两两比换成在 $k$ 个指针里挑最小。
- 2011 求两个等长有序序列的中位数：中位数就是归并后第 $n$ 个元素（两表各长 $n$），双指针走 $n$ 步即得，不必真排完，$O(n)$、$O(1)$。
- 求逆序对另有树状数组 $O(n\log n)$ 与暴力 $O(n^2)$ 两种口径，考试只写归并这一种。

**模板/流水线**
```c
#include <stdio.h>
#define N 7
int tmp[N], cnt = 0;                    /* cnt 统计逆序对 */
void MergeSort(int a[], int l, int r) {
    int m, i, j, k, t;
    if (l >= r) return;                 /* 只有一个元素天然有序，递归出口 */
    m = (l + r) / 2;
    MergeSort(a, l, m);
    MergeSort(a, m + 1, r);
    i = l; j = m + 1; k = l;
    while (i <= m && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];             /* 取等号才稳定 */
        else { cnt += m - i + 1; tmp[k++] = a[j++]; }    /* 右段先出，左段剩余全成逆序 */
    }
    while (i <= m) tmp[k++] = a[i++];                    /* 剩的整段接上 */
    while (j <= r) tmp[k++] = a[j++];
    for (t = l; t <= r; t++) a[t] = tmp[t];              /* 拷回原数组 */
}
```

! 归并空间记成 O(1) 是最高频错误，八种排序里只有它是 O(n) 辅助空间·趟数写成下取整会少算一趟：7 个元素 3 趟、8 个元素还是 3 趟，只认上取整·逆序对只在右段先出时累加，左段先出时为 0，不要两边都加

## 比较计数排序
**考频**：2021（应用题）｜排序章节的第二道应用题，只考这一类「统计位置」的思想
**必背结论**
- 比较计数排序：$c[i]$ 记「比 $a[i]$ 大」的元素个数（相等时按下标小者为大），$c[i]$ 就是排好后 $a[i]$ 的最终下标，直接 `b[c[i]] = a[i]`。
- 比较次数恒为 $n(n-1)/2$（每对元素恰好比一次），与初始序列完全无关；时间 $O(n^2)$、空间 $O(n)$。
- 相等元素按下标定序就能稳定，这一步是它唯一能考「稳定」的地方，不写下标规则就退化成不稳定。
- 计数排序（值域 $0$ 到 $r-1$）：统计个数 → 前缀和 → 倒序回填，时间 $O(n+r)$、空间 $O(r)$、稳定；倒序回填是稳定性的来源。
- 两者都不交换元素，只做「算位置 + 直接落位」：前者用比较算位置，后者用值当下标。
- 值域 $r$ 远大于 $n$ 时计数排序空间爆掉，此时还不如快排；基数排序就是把它按位拆成 $d$ 趟。

**模板/流水线**
```c
#include <stdio.h>
#define N 7
/* 比较计数排序：c[i] = 比 a[i] 大的元素个数（相等时下标小者算大），得降序 */
void CmpCountSort(int a[], int b[], int n) {
    int c[N] = {0}, i, j;
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            if (a[j] > a[i] || (a[j] == a[i] && j < i)) c[i]++;  /* 每对恰好比一次 */
    for (i = 0; i < n; i++) b[c[i]] = a[i];                     /* c[i] 就是最终下标 */
}
```

```c
#include <stdio.h>
#define N 8
/* 计数排序：关键字取值 0..r-1，r <= 10 */
void CountSort(int a[], int b[], int n, int r) {
    int c[10] = {0}, i;
    for (i = 0; i < n; i++) c[a[i]]++;                  /* 1 统计各值出现次数 */
    for (i = 1; i < r; i++) c[i] += c[i - 1];           /* 2 前缀和：c[v]-1 是末位下标 */
    for (i = n - 1; i >= 0; i--) b[--c[a[i]]] = a[i];   /* 3 倒序回填，保证稳定 */
}
```

! $c[i]$ 的方向要跟题干一致：统计「比它大」得降序，统计「比它小」得升序，方向反了答案整体倒过来·相等元素不给索引规则，稳定性必错·计数排序回填必须从后往前，从前往后会把相同元素的顺序颠倒

## 外部排序三件套
**考频**：2023（应用题）｜外排序冷门但近年上升，2023 一题；败者树概念另有选择题
**必背结论**
- 外部排序 = 归并思想，两个阶段：置换选择排序造初始归并段，再多路归并；内存装不下全部数据是它存在的唯一理由。
- 归并趟数 $S=\lceil\log_k m\rceil$（$m$ 个初始归并段、$k$ 路归并）；每多一路，趟数少一层，I/O 少一轮。
- 每趟归并要把全部数据读一遍写一遍，$N$ 个磁盘块共 $2N$ 次 I/O；$S$ 趟共 $2NS$ 次，连造初始段算上是 $2N(S+1)$。
- 置换选择排序：工作区保留 $M$ 条记录，每次输出「不小于当前段最大值的元素中最小的那个」，输出一个就从输入补一个进工作区；工作区全部小于当前段最大值时本段结束。
- 置换选择的段长：输入随机时段长平均 $2M$；输入完全有序时只生成 1 个段，段长就是 $n$。
- 败者树：内部结点存败者所在段号、叶子存关键字、`ls[0]` 是冠军；一次调整只沿一条链走，比较次数由 $k-1$ 降到 $\lceil\log_2 k\rceil$，$k=8$ 时是 3 次。
- 最佳归并树本质是哈夫曼树：每次合并 $k$ 个最短的段；磁盘块读写总数 $=2\times WPL$（权取归并段长度）。
- $k$ 路归并段数不够时补长度 0 的虚段，条件是 $(m-1)\bmod(k-1)=0$，否则哈夫曼树建不成严格 $k$ 叉。

**模板/流水线**
```c
#include <stdio.h>
#define K 4                     /* 4 路归并 */
#define INF 0x7fffffff
int b[K + 1];                   /* 各段当前关键字；b[K] 为极小哨兵 */
int ls[K];                      /* 内部结点存败者段号；ls[0] 是冠军 */
int seg[K][8] = {{1,6,9,20},{3,5,22},{2,7,8,30},{4,10,11,12,25}};
int len[K] = {4, 3, 4, 5}, pos[K], total = 16, done = 0;
/* 沿 s 的父链往上：大的留下当败者，小的继续上升，一次只走树高 log k 步 */
void Adjust(int s) {
    int t = (s + K) / 2, tmp;
    while (t > 0) {
        if (b[s] > b[ls[t]]) { tmp = s; s = ls[t]; ls[t] = tmp; }
        t /= 2;
    }
    ls[0] = s;                  /* 冠军结点：全树最小者的段号 */
}
```

> 最佳归并树算账模板：段长 2、3、2。顺序合并 (2+3) 再 +2 ⇒ 读 5 写 5 加读 7 写 7 共 24 次；哈夫曼先合 (2+2) 再 +3 ⇒ 8 加 14 共 22 次。$WPL=2\times2+2\times2+3\times1=11$，$2\times11=22$，与逐次相加一致。

! 败者树内部结点存的是段号不是关键字，叶子才存关键字·置换选择排序漏了「输出一个补一个」，工作区就不再是 M 条·归并趟数写成 $m/k$ 或 $\lceil m/k\rceil$ 都错，正确的是 $\lceil\log_k m\rceil$

## 排序思想解算法题
**考频**：2018、2020｜「用排序换时间」是的通用骨架，两道满分答法都是 $O(n)$ 加 $O(1)$
**必背结论**
- 2018 最小未出现正整数：值域当桶的原地版——把值 $x$ 换到下标 $x-1$（只处理 $1\le x\le n$），第一个 $a[i]\ne i+1$ 的位置就是答案，全对返回 $n+1$。
- 原地哈希每个元素最多被换到正确位置一次，交换总次数不超过 $n$，时间 $O(n)$、空间 $O(1)$，比先排序 $O(n\log n)$ 更优。
- 2020 三元组距离最小：三个升序数组各设一个指针，每轮算出当前距离并更新最优，然后只把「当前最小元素」所在数组的指针前挪一位，时间 $O(n_1+n_2+n_3)$。
- 只挪最小元素的原因：距离由最大值减最小值主导，挪大的只会让距离更大，挪小的才可能变小。
- 排序换时间两种范式：先排序 $O(n\log n)$ 再双指针或二分（把 $O(n^2)$ 降成 $O(n\log n)$）；或把值域当下标直接 $O(n)$。
- 看到「值域是 $1$ 到 $n$」「要求 $O(n)$ 且 $O(1)$」同时出现，基本就是原地哈希。

**模板/流水线**
```c
#include <stdio.h>
#define N 4
#define M 4
/* 2018：最小未出现正整数，时间 O(n)、空间 O(1) */
int FirstMissing(int a[], int n) {
    int i, t;
    for (i = 0; i < n; i++)
        while (a[i] >= 1 && a[i] <= n && a[a[i] - 1] != a[i]) {
            t = a[i]; a[i] = a[t - 1]; a[t - 1] = t;   /* 把 x 换到下标 x-1 */
        }
    for (i = 0; i < n; i++)
        if (a[i] != i + 1) return i + 1;                /* 第一个不合位的就是它 */
    return n + 1;
}
/* 2020：三元组距离最小，三个升序数组，每轮只挪最小元素所在数组的指针 */
int MinDist(int A[], int n1, int B[], int n2, int C[], int n3) {
    int i = 0, j = 0, k = 0, best = 0x7fffffff, d, mn;
    while (i < n1 && j < n2 && k < n3) {
        d = (A[i]>B[j]?A[i]-B[j]:B[j]-A[i]) + (B[j]>C[k]?B[j]-C[k]:C[k]-B[j])
          + (C[k]>A[i]?C[k]-A[i]:A[i]-C[k]);
        if (d < best) best = d;
        mn = A[i]; if (B[j] < mn) mn = B[j]; if (C[k] < mn) mn = C[k];
        if (A[i] == mn) i++; else if (B[j] == mn) j++; else k++;
    }
    return best;
}
```

! 原地哈希的 `while` 不能写成 `if`，换过去的新值可能还没到位，要一直换到落位或越界·`while` 里不要写 `i++`，同一位要换到落位或越界才放行，写了 `i++` 就会跳过换进来的元素·2020 每轮只挪一个指针，同时挪两个或挪最大的写法必错；距离公式三段绝对值都要算，别只算两段
