# 408 应试大题手册

一本为 12 月统考量身的大题作战手册，由《408 各科大题知识点强化课》（`../408强化课精讲/` 17 份讲义）
提炼而成，考点全部对齐 2009--2026 年统考真题**大题**。

## 文件

| 文件 | 说明 |
|---|---|
| `408应试大题手册.pdf` | 成品，A4 118 页，可直接打印 |
| `源文件/*.md` | 14 个章节片段（Markdown 源，可改可重编） |
| `源文件/handbook-preamble.tex` | 排版导言区（配色、页眉、考点标题、真题年份徽标） |
| `源文件/build_handbook.py` | 编译脚本：片段 → XeLaTeX → PDF |
| `源文件/手册.tex` / `手册.log` | 生成的完整 LaTeX 与编译日志 |
| `源文件/preview/` | 抽样预览图（每次编译会重新生成全页 PNG） |

## 重编

```bash
cd 源文件
python3 build_handbook.py
```

需要 `xelatex`（TeX Live）、`Python 3`、`PyMuPDF`。脚本会把全页预览渲染到 `preview/`。

## 结构

```
封面 / 目录
使用说明 · 分值结构 · 答题顺序 · 四科大题考点年份总表（速查）
第一编 数据结构    算法题暴力解模板库 · 链表五套路+树 · 哈夫曼与图应用 · 排序
第二编 计算机组成原理  补码 · Cache · 指令与流水线 · I/O 方式
第三编 操作系统    PV · 分页与请求分页 · 文件与磁盘
第四编 计算机网络  前三章 · 网络层 IP · 传输与应用层
```

全书 125 个考点，每个考点固定四段：**真题年份**（哪一年的大题考过）、**必背结论**、
**模板/流水线**（可直接抄的代码或编号步骤）、**易错点**。

## 准确性与口径说明

- **年份**取自《真题年份总表》（由 `../408大题分类/` 的五份真题汇编与 `../408真题+解析（09-26）/`
  原卷交叉核对）。
- **题号不保证**：408 综合应用题的题号顺序逐年微调（2009--2012 算法题在第 42 题、2016 算法题在第 43 题），
  本册只保证年份准确，进考场以题干为准。
- **分值**：大题共 70 分，四科常年约 23/23/15/9，个别年份浮动（见正文表）。
- 代码模板为 C（考试允许 C/C++），均按考场可默写的长度控制，**给的是暴力解/通用解而不是最优解**——
  这正是数据结构的评分口径：设计思想 + 代码 + 复杂度三问答满即可拿到大部分分。
