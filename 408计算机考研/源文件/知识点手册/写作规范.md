# 《408 考纲知识点手册》写作规范

## 一、总目标

编写一本**严格按 2027 年 408 考纲顺序编排**的知识点手册。读者是正在备考 408 的考生，
用途是「对着考纲查漏补缺 + 考前快速回顾」。因此：

- **覆盖**：考纲上出现的每一条，本手册都必须写到，不能漏。
- **顺序**：章节顺序、条目顺序与考纲**完全一致**。
- **深度**：以「能直接做题」为标准。定义、判定条件、公式、边界情况、常见陷阱都要写清楚。
- **不写**：考纲外的拓展知识（除非是理解考点必需的前置）、题目原文堆砌、个人学习计划。

## 二、Markdown 语法约定（转换器只认这些）

| 写法 | 用途 |
|---|---|
| `# 标题` | **不要用**。章标题由文件名与总装脚本生成 |
| `## 一、xxx` | 对应考纲的一级条目（一、二、三……） |
| `### （一）xxx` | 对应考纲的二级条目 |
| `#### 1. xxx` | 对应考纲的三级条目 / 具体知识点 |
| `##### xxx` | 更细的小点（尽量少用） |
| 普通段落 | 一句一行或一段多行皆可，段落之间空一行 |
| `- xxx` / `1. xxx` | 无序 / 有序列表，可嵌套（4 空格缩进） |
| `**粗体**` | 关键术语、需要记住的结论 |
| `` `代码` `` | 行内代码、标识符、指令名 |
| ```` ```c ... ``` ```` | 代码块（数据结构算法、汇编等），**必须标注语言** |
| `\| a \| b \|` 表格 | 对比类内容优先用表格 |
| `$...$` / `$$...$$` | 行内 / 独立公式，**必须是合法 LaTeX** |
| `> 引用` | 一般不用 |

### 提示框（重要）

用三种提示框让重点一眼可见，语法必须是：

```
:::key 标题
内容（可以多段、可以有列表、可以有公式）
:::
```

- `:::key` — **核心结论 / 必背**（蓝色）
- `:::warn` — **易错点 / 常见陷阱**（红色）
- `:::exam` — **真题考法 / 出题角度**（灰色）

提示框内不能嵌套提示框，不要在提示框里再写 `:::`。

### 禁止事项

- 不要用 `` ```text `` 或未标注语言的围栏。
- 不要写 HTML 标签（`<br>`、`<details>`、`<img>` 等）——外面转换器会原样输出成乱码。
- 不要贴图片链接、不要贴 `![](...)`。
- 不要写 `#` 一级标题。
- 不要用 `---` 分隔线（分页由总装脚本控制）。
- 公式里不要用 `\begin{align}` 之类需要额外宏包的环境；`$$...$$` 里用 `aligned` 可以。
- 表格必须是有表头的标准 Markdown 表格，列数全表一致。

## 三、每章的内容结构

每章按下面的骨架写，但**不要机械重复小标题**，按内容自然组织：

1. **本章考纲要求**（用 `> ` 引用块列出本章对应的考纲原文条目，逐条照抄考纲用词）
2. 按考纲条目顺序逐个知识点展开
3. 章末可选：**本章小结表**（一张对比/汇总表）+ **易错清单**

### 每个知识点建议包含

- **定义 / 原理**：准确、可复述。术语首次出现给出英文。
- **关键公式**：用 `$$...$$` 写清楚，说明每个符号含义与适用范围。
- **判定 / 计算步骤**：给可执行的分步流程。
- **典型例子**：小例子，带数字，能自己算一遍验证。
- **易错点**：用 `:::warn` 写考生最容易错的地方（例如「循环队列判满为什么牺牲一个单元」「Cache 写回与写直达的区别」）。
- **真题考法**：用 `:::exam` 写这一知识点在统考里以什么形式出现（能确定年份的写年份与题号，不确定的不要编）。

## 四、准确性要求（最重要）

- **不允许编造**：不确定的年份、题号、教材页码、数据，一律不写。
- **公式必须自洽**：写完自己代入一组数验证一遍。
- **术语用统考叫法**：如「二叉搜索树 / 二叉排序树」「快表 TLB」「页框 / 页帧」「缺页中断」等。
- 有争议或是不同教材写法不同的地方，说明「统考按 xxx 理解」。
- 参考资料之间冲突时，以**考纲用词 + 统考真题**为准，并在正文里点明差异。

## 五、篇幅要求

- 每章正文 **10000～18000 字符**（中文字符计）。
- 数据结构「树与二叉树」「图」、计组「存储器层次结构」「中央处理器」、操作系统「进程管理」「内存管理」这些大章写到上限。
- 公式、代码块、表格不计入上述字符数，可以更多。
- 宁可写透一个考点，也不要罗列一堆只有标题的空话。**没有解释的标题列表没有任何价值。**

## 六、来源使用

- `yuque/` 下是语雀「计算机考研408笔记」导出的 Markdown，是主要素材。
- `ref/` 下是工作区里的王道教材 OCR / 课件 / 别人的笔记 / 真题汇编。
- 读源材料时注意：它们可能包含个人笔记口吻、错别字、图片占位、以及与本考点无关的内容。
  **你要做的是提炼、校正、重写成规范的知识点条目**，不是复制粘贴。
- 源材料里 LaTeX 公式被替换成图片的地方，根据上下文把公式**重新写出来**。
