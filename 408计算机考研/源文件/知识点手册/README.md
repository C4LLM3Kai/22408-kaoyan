## 重新编译

```bash
export PATH=/Library/TeX/texbin:$PATH
cd 408计算机考研/源文件/知识点手册
python3 make_book.py            # 合订本，全量重建
python3 make_book.py D05 N04    # 只重建指定章节（快速调试）
python3 make_parts.py           # 四个分册
python3 build_book.py chapters out.tex --part 1   # 只出某一分册的 .tex
```

脚本会依次执行：Markdown 预处理（标题归并、编号剥离、转义修复）→ 生成 `book.tex` →
XeLaTeX 编译两遍 → 输出缺字、越界与页数体检结果。中间产物写在脚本同级的 `book/` 目录。

单章源文件可直接编辑后重编。若要手工编译：

```bash
xelatex -interaction=nonstopmode book.tex   # 需运行两遍以生成目录与书签
```

## 构成

全书按考纲顺序分四部分、24 章：

| 部分 | 章 |
|---|---|
| 第一部分 数据结构 | 基本概念 / 线性表 / 栈、队列和数组 / 树与二叉树 / 图 / 查找 / 排序 |
| 第二部分 计算机组成原理 | 计算机系统概述 / 数据的表示和运算 / 存储器层次结构 / 指令系统 / 中央处理器 / 总线和输入输出系统 |
| 第三部分 操作系统 | 操作系统基础 / 进程管理 / 内存管理 / 文件管理 / 输入输出管理 |
| 第四部分 计算机网络 | 计算机网络概述 / 物理层 / 数据链路层 / 网络层 / 传输层 / 应用层 |

每章开头用引用块照抄对应考纲原文条目，正文按考纲三级条目顺序展开，
章末固定给出「本章小结表」与「易错清单」。内容用三种提示框区分：
**核心结论**、**易错点**、**真题考法**。

## 语雀知识库的导出方式（供复现）

语雀桌面客户端是 Electron 应用，其主进程在启动时若检测到 argv 中含
`--inspect` / `--remote-debugging-port` 会立即退出，因此不能直接用调试端口连接。
本次采用 Chromium 的 `--remote-debugging-pipe` 传输（该参数不在检测列表内），
在 fd 3/4 上直接讲 CDP 协议，再用页面内的 `fetch` 携带登录态调用：

- `GET /api/books/48597829/docs?limit=1000` —— 取全书文档列表（182 篇）
- `GET /api/docs/{slug}?book_id=48597829&mode=markdown` —— 取单篇正文（字段 `data.sourcecode`）

导出脚本为 `yuque_extract.py` / `yuque_cdp.py` / `yuque_launcher.py`（见 `.work/` 目录）。
注意 `--remote-debugging-pipe` 需要 fd 3 与 fd 4 已就位，且 **dup2 必须在 exec 之后的进程里做**
（Python `subprocess` 的 `close_fds` 在 `preexec_fn` 之后执行，会关掉 `preexec_fn` 新建的 fd）。
