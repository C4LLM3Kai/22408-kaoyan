## 计算机性能指标
### 一、 性能评价的两个基本维度
在不同的应用场景下，人们关注的性能维度不同：

1. **响应时间 (Response Time) / 执行时间 (Execution Time)**
    - **定义**：从作业提交开始到作业完成所用的时间。
    - **组成**：包括 CPU 执行时间 + 等待时间（磁盘访问、内存访问、I/O 操作、操作系统开销等）。
    - **适用场景**：个人电脑、银行事务处理（关注是否这就办完）。
    - **性能关系**：执行时间越短，性能越好。

$ \text{性能} \propto \frac{1}{\text{执行时间}} $

2. **吞吐率 (Throughput) / 带宽 (Bandwidth)**
    - **定义**：单位时间内系统能处理的请求或任务数量。
    - **适用场景**：数据中心、多媒体流、Web 服务器（关注单位时间能处理多少数据）。

---

### 二、 与 CPU 时间相关的核心指标
这是计算题中最常考的部分，核心在于**CPU 执行时间公式**。

#### 1. 时钟周期与主频
+ **时钟周期 (**$ T $**)**：CPU 中最小的时间单位，CPU 仅完成一个最基本的动作。
+ **主频 / 时钟频率 (**$ f $**)**：时钟周期的倒数。
    - 公式：$ f = \frac{1}{T} $
    - 单位：Hz (赫兹), MHz, GHz。例如 1GHz = $ 10^9 $ Hz，对应的时钟周期 $ T = 1\text{ns} $。

#### 2. CPI (Cycles Per Instruction)
+ **定义**：执行**一条**指令所需的**平均**时钟周期数。
+ **性质**：不同指令（如加法、乘法、访存）的周期数不同，因此 CPI 通常指**平均值**。
+ **计算公式**：

$ \text{CPI} = \frac{\text{程序所需的总时钟周期数}}{\text{指令条数 (IC)}} $

$ \text{CPI} = \sum (\text{某类指令的 CPI} \times \text{该类指令的比例}) $

#### 3. CPU 执行时间 (重点)
+ **定义**：指 CPU 真正花费在运行该程序上的时间（不包括 I/O 等待时间）。
+ **分类**：
    - **用户 CPU 时间**：执行用户程序代码的时间（通常性能评价主要看这个）。
    - **系统 CPU 时间**：为了执行程序而花费在操作系统上的时间。
+ **核心推导公式**（"CPU 性能公式"）：

$ T_{\text{CPU}} = \text{总时钟周期数} \times T = \frac{\text{总时钟周期数}}{f} $

$ T_{\text{CPU}} = \frac{\text{指令条数 (IC)} \times \text{CPI}}{f} $

+ **结论**：CPU 性能由三个要素共同决定：
    1. **时钟频率 (**$ f $**)**：由硬件技术和工艺决定。
    2. **CPI**：由计算机体系结构和指令集设计决定。
    3. **指令条数 (IC)**：由指令集设计和编译器技术决定。

---

### 三、 运算速度指标
#### 1. MIPS (Million Instructions Per Second)
+ **定义**：每秒执行多少**百万**条指令。
+ **公式**：

$ \text{MIPS} = \frac{\text{指令条数}}{\text{执行时间} \times 10^6} = \frac{f}{\text{CPI} \times 10^6} $

+ **局限性**：不同机器的指令集不同，指令功能强弱不同（比如一条复杂指令顶五条简单指令），单纯比较指令条数主要用于同系列机对比。

#### 2. IPC (Instructions Per Cycle)
+ **定义**：每个时钟周期执行的指令数。
+ **关系**：IPC 是 CPI 的倒数 ($ IPC = 1 / CPI $)。现代 CPU 利用流水线和多核技术，IPC 可能大于 1。

#### 3. 浮点运算指标 (FLOPS)
+ 主要用于衡量**科学计算**能力。
+ **MFLOPS** (Million): $ 10^6 $ 次/秒
+ **GFLOPS** (Giga): $ 10^9 $ 次/秒
+ **TFLOPS** (Tera): $ 10^{12} $ 次/秒
+ **PFLOPS** (Peta): $ 10^{15} $ 次/秒
+ **EFLOPS** (Exa): $ 10^{18} $ 次/秒
+ **ZFLOPS** (Zetta): $ 10^{21} $ 次/秒

---

### 四、 硬件规格相关概念 (易混淆点)
#### 1. "字长" 的辨析
+ **机器字长**：
    - 指 CPU **一次能处理**的二进制数据的位数。
    - 通常等于 **CPU 内部寄存器** 的位数、**ALU** 的宽度。
    - 直接影响计算机的**运算精度**和数的表示范围。
+ **指令字长**：
    - 一个指令字中包含的二进制代码的位数。
    - 取决于操作码的长度、操作数地址的个数及长度。
    - **注意**：指令字长与机器字长**没有必然联系**，可以是机器字长的整数倍或一半。
+ **存储字长**：
    - 一个存储单元存储的二进制代码长度。
    - 通常等于 **MDR** (存储数据寄存器) 的位数。

#### 2. 存储容量
+ **主存容量**：存储单元个数 ($ M $) $ \times $ 存储字长 ($ N $)。
    - 例如：$ 1K \times 8\text{位} $。
+ **单位换算注意事项**：
    - 在描述**存储容量**时，K, M, G, T 通常按 $ 2 $ 的幂次计算（$ 1K = 2^{10} = 1024 $）。
    - 在描述**速率、频率**时，k, M, G, T 通常按 $ 10 $ 的幂次计算（$ 1k = 10^3 = 1000 $）。
