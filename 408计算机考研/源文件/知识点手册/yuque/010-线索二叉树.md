# 线索二叉树

:::success
本节主要以**选择题**的形式考察，对于线索二叉树来说，遍历序列的第一个结点前驱指向NULL,最后一个结点的后继指向NULL；其余结点没有左孩子的话`lchild`指向前驱结点，没有右孩子的话线索`rchild`指向后继结点；这里的前驱后继取决于这是哪一种线索二叉树，如果是先序线索二叉树，其前驱和后继就是先序序列中的前驱和后继，如果是中序或者后序的话就按找照对应规则找。

:::

之前在二叉树的链式存储结构中提到，传统的二叉树结构只能体现一种父子关系，不能直接得到某节点的前驱和后继，每次都要设置一个`p`和`pre`指针从根结点开始遍历。并且，在含有`n`个结点的二叉树中，有`n+1`个空指针，为此，我们可以利用这些空指针来实现线索二叉树，从而加快查找某节点的前驱和后继的速度。

规定：若无左子树，令`lchild`指向其前驱节点；若无右子树，令`rchild`指向其后继结点。为了区分指针指的是孩子节点还是前驱或后继，还要增加两个标志域标识。

![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785172314190-8215ca07-99a4-41bd-8615-41b85edd9136.png)

其中，标志域的含义如下：

+ `**ltag == 0**`**时指向左孩子;** `**ltag == 1**`**时指向前驱**
+ `**rtag == 0**`**时指向右孩子;** `**rtag == 1**`**时指向后继**

因此，线索二叉树的结构体定义为

```c
typedef struct ThreadNode {
    int data;    //数据域
    struct ThreadNode* lchild,*rchild;    //左、右孩子指针
    int ltag,rtag;     //左、右线索指针
}ThreadNode,*ThreadTree;
```

**这样的指针称之为线索，加上线索的二叉链表称之为线索链表，相应的二叉树就称之为线索二叉树。**

###  中序线索二叉树的构造
线索化的实质**就是将二叉链表中的空指针改为指向前驱或后继的线索**。由于前驱和后继的信息只有在遍历该二叉树时才能得到，所以**线索化的过程就是在遍历的过程中修改空指针的过程**.线索二叉树类似于一个非循环的双向链表。

![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785522206448-73e63600-d87a-4cf1-8586-e88af2993b28.png)

**构造过程**：设置两个指针，`p`和`pre`，`pre`用于指向刚刚访问过的结点，`p`用于指向正在访问的结点，即`pre`指向的是`p`的前驱。在中序遍历的过程中，如果`p`没有左孩子，则将其左孩子指针指向`pre`；如果`pre`没有右孩子，则将其右孩子指针指向`p`；

```c
void InThread(ThreadNode* p,ThreadNode *&pre){ 
    if(p != NULL) {     
        InThread(p->lchild,pre);   //递归线索化左子树
        if(p->lchild == NULL) {   //如果p没有左孩子，即左孩子指针为空，建立前驱线索
            p->lchild = pre;    //将其指向前驱结点；
            p->ltag = 1;   //修改标识，表示线索化；
        }else{ 
            p -> ltag = 0;   
        }
        if(pre!=NULL && pre -> rchild == NULL) {   //如果pre没有右孩子，即右孩子指向空；
            pre -> rchild = p;   //将其右孩子指针指向p；
            pre -> rtag = 1;   //修改标识；
        }else if (pre != NULL) { //首次访问时 pre 为空，不能解引用空指针
            pre->rtag = 0;
        }
        pre = p;   //更新遍历结点；表示当前结点成为刚刚访问过的结点；
        InThread(p->rchild,pre);   //递归线索化右子树；
    }
}

void CreateInThread(ThreadTree root) {   
    ThreadNode *pre = NULL;   
    if(root) {      //非空二叉树线索化；
        InThread(root,pre);   //线索化二叉树；
        pre -> rchild = NULL;   //处理遍历的最后一个结点，将其后继指向空；
        pre -> rtag = 1;
    }
}
```

类似于带头结点的链表，线索二叉树也可以带头结点，将该头结点的`lchild`指向二叉树的根节点，其`rchild`执行中序遍历最后一个访问的结点；再令中序遍历的第一个结点的`lchild`指向该头结点，最后一个结点的`rchild`指向该头结点。这样的话，相当于为该二叉树建立了一个**双向线索链表**，从而方便从前往后或者从后往前对该线索二叉树遍历。

```c
ThreadTree CreateInThread(ThreadTree root) { 
    ThreadNode *head = new ThreadNode();
    head->ltag = 0;   //预设指向root;
    head->rtag = 1;   //指向后继，即遍历序列最后一个节点；
    head -> rchild = head;  //先初始化右指针指向自己；
    ThreadNode *pre = NULL;   
    if(root) {      //非空二叉树线索化；
        head -> lchild = root;   //头结点的lchild指向二叉树的根节点  
        pre = head;
        InThread(root,pre);   //线索化二叉树；
        head -> rtag = 1;     //头结点的右指针始终是后继线索，避免被通用线索化过程改为孩子标志
        pre -> rchild = head;   //最后一个遍历到的结点后继指向头节点head；
        pre -> rtag = 1;
        head -> rchild = pre;   //头结点的后继应指向最后一个遍历到的结点，不能覆盖指向根的 lchild；
    }else{
        head -> lchild = head;  //树为空的话，左指针指向自己；
    }
    return head;
}
```

### 中序线索二叉树的遍历
#### 中序线索二叉树中找结点`p`的后继
若`p`的`rtag = 1`,则该结点的后继就是`p->rchild`;若`rtag = 0`,则该结点的后继就是其右子树中第一个被访问到的结点（**右子树中最左下的结点**）



![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785568972884-71d84be4-a36c-43f6-bbac-ba6a112b565e.png)

```c
//找到以p为根的子树中，第一个被中序遍历访问到的结点；
ThreadNode *FirstNode(ThreadNode *p) {
    if (p == NULL) return NULL; //空树时不能直接访问 p->ltag
    //循环找到最左下结点（不一定是叶结点）
    while(p -> ltag == 0) {
        p = p -> lchild;
    }
    return p;
}

//在中序线索二叉树中找到结点p的后继结点；
ThreadNode *NextNode(ThreadNode* p){
    if(p->rtag == 0) {   //表示p结点有右孩子；
        return FirstNode(p->rchild);  //则其后继为其右子树的最左下结点；
    }else{      //rtag == 1,表明p结点没有右孩子，其右孩子指针指向其后继；
        return p -> rchild;   //直接返回后继结点；
    }
}

//对中序线索二叉树进行中序遍历(利用线索化实现的非递归，空间复杂度为O(1));
void Inorder(ThreadNode* root){
    for(ThreadNode *p = FirstNode(root);p!=NULL;p = NextNode(p))
        visit(p);
}
```

#### 中序线索二叉树中找结点`p`的前驱
若`p`的`ltag = 1`,则该结点的前驱就是`p->lchild`;若`ltag = 0`,则该结点的前驱就是其左子树中最后一个被访问到的结点（**左子树中最靠近右下的结点**）

![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785578465711-ddb99f21-e293-4fc4-b0bc-6238440613b9.png)

```c
//找到以p为根的子树中，最后一个被中序遍历访问到的结点；
ThreadNode *LastNode(ThreadNode *p) { 
    if (p == NULL) return NULL;       
    //循环找到最右下结点（不一定是叶结点）
    while(p -> rtag == 0) {
        p = p -> rchild;
    }
    return p;
}

//在中序线索二叉树中找到结点p的前驱结点；
ThreadNode *PreNode(ThreadNode* p){
    if(p->ltag == 0) {   //表示p结点有左孩子；
        return LastNode(p->lchild); 
    }else{      //ltag==1,表明p结点没有左孩子，其左孩子指针指向其前驱；
        return p -> lchild; //直接返回前驱结点；
    }
}

//对中序线索二叉树进行逆向中序遍历
void Revorder(ThreadNode* root){
    for(ThreadNode *p = LastNode(root);p!=NULL;p = PreNode(p))
        visit(p);
}
```

### 先序和后序线索二叉树
建立先序和后序线索二叉树的代码与上述建立中序线索二叉树的代码类似，只需变动线索化改造的代码段和调用线索化左右子树递归函数的位置即可.

```c
//先序线索化
void PreThread(ThreadNode* p,ThreadNode *&pre){ 
    if(p != NULL) {     
        if(p->lchild == NULL) {   //如果p没有左孩子，建立前驱线索
            p->lchild = pre;    //将其指向前驱结点；
            p->ltag = 1;   //修改标识，表示线索化；
        }else{ 
            p -> ltag = 0;   
        }
        if(pre!=NULL && pre -> rchild == NULL) {   //如果pre没有右孩子，则建立前驱结点的后继线索
            pre -> rchild = p;   //将其右孩子指针指向p；
            pre -> rtag = 1;   //修改标识；
        }else if (pre != NULL) { 
            pre->rtag = 0;
        }
        pre = p;   //更新遍历结点；表示当前结点成为刚刚访问过的结点；
        if(p->ltag == 0){
            PreThread(p->lchild,pre);   //递归线索化左子树；
        }
        if(p->rtag == 0){	//必须判断后再递归，否则会陷入死循环，王道课件代码没加，是有问题的
            PreThread(p->rchild,pre);   //递归线索化右子树；
        }
        
    }
}

void CreatePreThread(ThreadTree root) {   
    ThreadNode *pre = NULL;   
    if(root) {      //非空二叉树线索化；
        PreThread(root,pre);   //线索化二叉树；
        if(pre -> rchild == NULL)    //处理遍历的最后一个结点；
            pre -> rtag = 1;
    }
}
```

```c
//后序线索化
void PostThread(ThreadNode* p,ThreadNode *&pre){ 
    if(p != NULL) {   
        PostThread(p->lchild,pre);   //递归线索化左子树；       
        PostThread(p->rchild,pre);   //递归线索化右子树；
        if(p->lchild == NULL) {   //如果p没有左孩子，建立前驱线索
            p->lchild = pre;    //将其指向前驱结点；
            p->ltag = 1;   //修改标识，表示线索化；
        }else{ 
            p -> ltag = 0;   
        }
        if(pre!=NULL && pre -> rchild == NULL) {   //如果pre没有右孩子，则建立前驱结点的后继线索
            pre -> rchild = p;   //将其右孩子指针指向p；
            pre -> rtag = 1;   //修改标识；
        }else if (pre != NULL) { 
            pre->rtag = 0;
        }
        pre = p;   //更新遍历结点；表示当前结点成为刚刚访问过的结点；       
    }
}

void CreatePostThread(ThreadTree root) {   
    ThreadNode *pre = NULL;   
    if(root) {      //非空二叉树线索化；
        PostThread(root,pre);   //线索化二叉树；
        if(pre -> rchild == NULL)    //处理遍历的最后一个结点；
            pre -> rtag = 1;
    }
}
```

####  先序线索二叉树找指定节点p的先序后继 
:::color1
如果有左孩子，则左孩子就是其后继，如果无左孩子但是有右孩子，则右孩子为其后继；如果p是叶节点，则右链域指向的就是其后继；

:::

####  先序线索二叉树找指定节点p的先序前驱 
![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785581536758-c5ea69f9-7036-483f-82e8-39f40c8bfc44.png)

:::color2
若`p->ltag == 1`,则`pre = p -> lchild`;

若`p->ltag == 0`,由于**先序遍历的遍历顺序是根左右，因此其左右孩子都只能是**`**p**`**结点的后继而不可能是前驱**，所以此时只能从头开始找才能找到`p`的前驱；

或者可以在结构体中设置一个父节点指针，将其变为**三叉链表，**那样的话，找`p`结点的前驱有以下四种情况；
