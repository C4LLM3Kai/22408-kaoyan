3. 【2016-09】在有 n(n>1000) 个元素的升序数组 A 中查找关键字 x 。查找算法的伪代码如下所示。

```c
k = 0;
while (k < n 且 A[k] < x) k = k + 3;
if (k < n 且 A[k] == x) 查找成功;
else if (k - 1 < n 且 A[k - 1] == x) 查找成功;
else if (k - 2 < n 且 A[k - 2] == x) 查找成功;
else 查找失败;
```

本算法与折半查找算法相比，有可能具有更少比较次数的情形是（ ）。

A. 当 x 不在数组中

B. 当 x 接近数组开头处

C. 当 x 接近数组结尾处

D. 当 x 位于数组中间位置

<details class="lake-collapse"><summary id="uf7306688"><strong><span class="ne-text">解析</span></strong></summary><p id="ude4fc519" class="ne-p"><span class="ne-text">该算法检查的位置依次为</span><span id="Vb6Bv" class="ne-math"><img src="https://cdn.nlark.com/yuque/__latex/676c73b865e04f7f25d31b884ab16dc5.svg"></span></p><p id="ufc28d036" class="ne-p"><span class="ne-text">当越过 x 后，再检查该组中的前两个位置。</span></p><p id="u5228351a" class="ne-p"><span class="ne-text">若 x 接近数组开头，只需很少几次跨步比较就能定位。例如 x 位于前几个元素中，算法可能只比较 1 至 3 次。</span></p><p id="u4a915632" class="ne-p"><span class="ne-text">折半查找无论目标靠近开头还是结尾，通常仍需约</span><span id="AfhzC" class="ne-math"><img src="https://cdn.nlark.com/yuque/__latex/841a4d40f4b11b689814397ff54d5eb2.svg"></span><span class="ne-text">次比较。由于 </span><span id="AG2N1" class="ne-math"><img src="https://cdn.nlark.com/yuque/__latex/f7736e56300294e16fdefeb85d9b819c.svg"></span><span class="ne-text">，这个值约为 10。</span></p><p id="u66613a0e" class="ne-p"><span class="ne-text">若 x 位于中间、结尾或不存在，跨步算法可能需要扫描约 </span><span id="jdRKU" class="ne-math"><img src="https://cdn.nlark.com/yuque/__latex/bdfce002762e5f684c1839e01f06cb3d.svg"></span><span class="ne-text">、</span><span id="ncYhu" class="ne-math"><img src="https://cdn.nlark.com/yuque/__latex/c67ad5c8e54230e43b1802f225827760.svg"></span><span class="ne-text"> 级别的位置，远多于折半查找。</span></p><p id="udad9ca16" class="ne-p"><strong><span class="ne-text">答案：B</span></strong></p></details>
