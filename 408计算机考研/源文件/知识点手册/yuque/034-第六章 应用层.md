17. 【2021-47】（9分）某网络拓扑如题47图所示，以太网交换机S通过路由器R与Internet互联。路由器部分接口、本地域名服务器、H1、H2的IP地址和MAC地址如图中所示。在 t0 时刻H1的ARP表和S的交换表均为空，H1在此刻利用浏览器通过域名 www.abc.com 请求访问Web服务器，在 t1 时刻（ t1>t0 ）S第一次收到了封装HTTP请求报文的以太网帧，假设从 t0 到 t1 期间网络未发生任何与此次Web访问无关的 网络通信。

![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1783973471072-d8f645b9-d728-4d76-8806-c63e6bd34e40.png)

请回答下列问题。

(1) 从 t0 到 t1 期间，H1除了HTTP之外还运行了哪个应用层协议？从应用层到数据链路层，该应用层协议报文是通过哪些协议进行逐层封装的？

(2) 若S的交换表结构为：<MAC地址，端口>，则 t1 时刻S交换表的内容是什么？

(3) 从 t0 到 t1 期间，H2至少会接收到几个与此次Web访问相关的帧？接收到的是什么帧？帧的目的MAC地址是什么？

**解析：**

**（1）除 HTTP 外的应用层协议及封装**

H1 只有域名 `www.abc.com`，发送 HTTP 请求前必须获得 Web 服务器的 IP 地址，因此还运行了 **DNS**。

普通 DNS 查询报文的逐层封装为：

```latex
DNS 报文 → UDP 数据报 → IP 分组 → 以太网帧
```

**（2）**$ t_1 $** 时刻 S 的交换表**

交换机根据收到帧的**源 MAC 地址和入端口**进行自学习。$ t_0 $ 到 $ t_1 $ 至少发生：

1. H1 查询本地域名服务器 MAC，S 从端口 4 学到 H1 的 MAC。
2. 本地域名服务器回复，S 从端口 1 学到服务器的 MAC。
3. H1 查询默认网关 R 的 MAC，R 回复时 S 从端口 2 学到 R 的 MAC。
4. 随后的 DNS、TCP 和 HTTP 帧会刷新已有表项，但不会引入 H2 的源 MAC，因为 H2 没有发送帧。

因此 $ t_1 $ 时刻交换表至少为：

| MAC 地址 | 端口 |
| :---: | :---: |
| `00-11-22-33-44-BB` | 1 |
| `00-11-22-33-44-AA` | 2 |
| `00-11-22-33-44-CC` | 4 |


没有 H2 的 `00-11-22-33-44-DD` 表项。

**（3）H2 至少收到的相关帧**

H2 至少收到 **2 个帧**：

1. H1 为获得本地域名服务器 MAC 而发送的 ARP 请求帧；
2. H1 为获得默认网关 R 的 MAC 而发送的 ARP 请求帧。

这两个帧都是 ARP 请求帧，目的 MAC 均为以太网广播地址：

`FF-FF-FF-FF-FF-FF`。

交换机把广播帧从除入端口外的所有端口转发，所以 H2 会收到它们。各 ARP 应答和后续 DNS、TCP、HTTP 帧都可按已经学习到的 MAC 表项单播转发，H2 无需接收。
