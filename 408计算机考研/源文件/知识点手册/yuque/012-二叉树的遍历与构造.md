# 二叉树的遍历与构造

##  二叉树的遍历
**二叉树遍历**：从根节点出发，按照**某种次序**依次访问二叉树中的**所有结点**，使得每个结点被访问**一次且仅被访问一次**。

简单说就是：**把树里所有节点都走一遍，每个只走一次**。

**两种遍历思想**

二叉树主要有两大类遍历方式，它们也是图论中最基本的两种遍历思想：

| 遍历方式 | 核心思想 | 典型实现 |
| :---: | :---: | :---: |
| **深度优先遍历** (DFS) | 先往深走，走到头再往回走 | 递归 / 栈 |
| **广度优先遍历** (BFS) | 一层一层横着走 | 队列 |


![](https://cdn.nlark.com/yuque/__mermaid_v3/c2edc7017d1978e2440e8bc1cf22b641.svg)

**前中后序是什么意思？**

**前、中、后，指的是「中间节点（根）」在遍历中的位置**。记住这一句话就够了：

+ **前**序：**根** → 左 → 右（根在最前面）
+ **中**序：左 → **根** → 右（根在中间）
+ **后**序：左 → 右 → **根**（根在最后面）

大家可以对着如下图，看看自己理解的前后中序有没有问题。

### 二叉树的递归遍历
在介绍三种深度优先遍历之前，先介绍一下递归算法的三要素：****

1.  **确定递归函数的****<u><font style="color:#DF2A3F;">参数和返回值</font></u>****：**确定哪些参数是递归的过程中需要处理的，那么就在递归函数里加上这个参数， 并且还要明确每次递归的返回值是什么进而确定递归函数的返回类型。
2. **确定****<font style="color:#DF2A3F;">终止条件</font>****：** 写完了递归算法, 运行的时候，经常会遇到栈溢出的错误，就是没写终止条件或者终止条件写的不对，操作系统也是用一个栈的结构来保存每一层递归的信息，如果递归没有终止，操作系统的内存栈必然就会溢出。
3. **确定****<font style="color:#DF2A3F;">单层递归的逻辑</font>****：** 确定每一层递归需要处理的信息。在这里也就会重复调用自己来实现递归的过程。



**以下以前(先)序遍历为例：**

1. **确定递归函数的参数和返回值**：因为要打印出前序遍历节点的数值，所以参数里需要传入`vector`来放节点的数值，除了这一点就不需要再处理什么数据了也不需要有返回值，所以递归函数返回类型就是`void`，代码如下：

```c
void traversal(TreeNode* cur, vector<int>& vec)
```

2. **确定终止条件**：在递归的过程中，如何算是递归结束了呢，当然是当前遍历的节点是空了，那么本层递归就要结束了，所以如果当前遍历的这个节点是空，就直接return，代码如下：

```c
if (cur == NULL) return;
```

3. **确定单层递归的逻辑**：前序遍历是中左右的循序，所以在单层递归的逻辑，是要先取中节点的数值，代码如下：

```c
vec.push_back(cur->val);    // 中
traversal(cur->left, vec);  // 左
traversal(cur->right, vec); // 右
```

单层递归的逻辑就是按照中左右的顺序来处理的，这样二叉树的前序遍历，基本就写完了，再看一下完整代码：

class Solution {
public:
    void traversal(TreeNode* cur, vector<int>& vec) {
        if (cur == NULL) return;
        vec.push_back(cur->val);    // 中
        traversal(cur->left, vec);  // 左
        traversal(cur->right, vec); // 右
    }
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        traversal(root, result);
        return result;
    }
};

//C实现代码
/**
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */

void traversal(struct TreeNode* cur, int* vec, int* idx) {
    if (cur == NULL) return;
    vec[(*idx)++] = cur->val;       // 中
    traversal(cur->left, vec, idx); // 左
    traversal(cur->right, vec, idx);// 右
}

int* preorderTraversal(struct TreeNode* root, int* returnSize) {
    *returnSize = 0;
    int* result = (int*)malloc(sizeof(int) * 1000); 
    traversal(root, result, returnSize);
    return result;
}

>

>

### 二叉树的迭代遍历
为什么可以用迭代法（非递归的方式）来实现二叉树的前后中序遍历呢？

**递归的实现就是：每一次递归调用都会把函数的局部变量、参数值和返回地址等压入调用栈中**，然后递归返回的时候，从栈顶弹出上一次递归的各项参数，所以这就是递归为什么可以返回上一层位置的原因。

因此我们用栈也可以实现二叉树的前后中序遍历,两种方式是等价的，区别在于**递归的时候隐式地维护了一个栈，而我们在迭代的时候需要显式地将这个栈模拟出来**，其余的实现与细节都相同.

#### 前序遍历（迭代法）
我们先看一下前序遍历。

前序遍历是`中左右`，每次先处理的是`中间节点`，那么先将`根节点`放入栈中，然后将`右孩子`加入栈，再加入`左孩子`。

为什么要先加入 右孩子，再加入左孩子呢？ 因为这样出栈的时候才是中左右的顺序。

动画如图：

![](https://cdn.nlark.com/yuque/0/2026/gif/42876865/1785172310264-6da7dcf7-e8fd-4d3f-b7bc-1a5fed24d4ad.gif)



不难写出如下代码: （**注意代码中空节点不入栈**）

```c
class Solution {
    public:
    vector<int> preorderTraversal(TreeNode* root) {
        stack<TreeNode*> st;    
        vector<int> result;       //用于返回遍历序列
        if (root == NULL) return result;        
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();                       // 中
            st.pop();
            result.push_back(node->val);    //访问并处理当前结点， <==> 本层递归处理
            if (node->right) st.push(node->right);           // 右孩子入栈（空节点不入栈） <==> 后递归处理右子树
            if (node->left) st.push(node->left);             // 左孩子入栈（空节点不入栈）<==> 先递归处理左子树
        }
        return result;
    }
};
```

> 由上面可以看出，前序遍历的非递归处理与递归处理实现对比：每一层的出栈都相当于进入一层递归函数。因为后入栈的元素先被处理，那么每次出栈顶元素都先将右孩子结点入栈，后入栈其左孩子，这就相当于先递归处理左子树，后递归处理右子树。即入栈顺序是递归顺序的逆置。
>
>  
>
> 补充：根据此代码可以轻松写出统计二叉树中有且仅有一个孩子结点的结点个数，设置一个变量`count`用于统计个数，每次访问栈顶元素然后出栈的时候，判断其是否仅有一个孩子结点(`if((!node->left && node -> right) || (node->left && !node -> right))`)，是的话`count++`,否则`count--`.
>

此时会发现貌似使用迭代法写出前序遍历并不难，确实不难。

**此时是不是想改一点前序遍历代码顺序就把中序遍历搞出来了？**

其实还真不行！

但接下来，**再用迭代法写中序遍历的时候，会发现套路又不一样了，目前的前序遍历的逻辑无法直接应用到中序遍历上。**



####  中序遍历（迭代法）
为了解释清楚，我说明一下 刚刚在迭代的过程中，其实我们有两个操作：

1. **处理：将元素放进result数组中**
2. **访问：遍历节点**

分析一下为什么刚刚写的前序遍历的代码，不能和中序遍历通用呢，因为前序遍历的顺序是中左右，先访问的元素是中间节点，要处理的元素也是中间节点，所以刚刚才能写出相对简洁的代码，**因为要访问的元素和要处理的元素顺序是一致的，都是中间节点。**

那么再看看中序遍历，中序遍历是左中右，先访问的是二叉树顶部的节点，然后一层一层向下访问，直到到达树左面的最底部，再开始处理节点（也就是在把节点的数值放进result数组中），这就造成了**处理顺序和访问顺序是不一致的。**

那么**在使用迭代法写中序遍历，就需要借用指针的遍历来帮助访问节点，栈则用来处理节点上的元素。**

动画如下：

![](https://cdn.nlark.com/yuque/0/2026/gif/42876865/1785172310333-bb464f93-1f83-46f8-98f2-0ac777376396.gif)



**中序遍历，可以写出如下代码：**

```c
class Solution {
    public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;     //定义一个结果数组用于存放中序遍历序列；
        stack<TreeNode*> st;     
        TreeNode* cur = root;      //cur为遍历指针
        while (cur != NULL || !st.empty()) {
            if (cur != NULL) { // 指针来访问节点，访问到最底层
                st.push(cur); // 将访问的节点放进栈
                cur = cur->left;                // 左
            } else {
                cur = st.top(); // 从栈里弹出的数据，就是要处理的数据（放进result数组里的数据）
                st.pop();
                result.push_back(cur->val);     // 中
                cur = cur->right;               // 右
            }
        }
        return result;
    }
};
```

其实，我们也可以**套用这个中序遍历的模式来实现先序遍历，只需要将访问结点操作放在入栈操作的前面即可，**即先将当前结点的值加入先序遍历序列，再将当前结点和它的所有左节点入栈即可，代码如下：

```c
class Solution {
public:
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;     //定义一个结果数组用于存放中序遍历序列；
        stack<TreeNode*> st;     
        TreeNode* cur = root;      //cur为遍历指针
        while (cur != NULL || !st.empty()) {
            if (cur != NULL) { // 指针来访问节点，访问到最底层
                result.push_back(cur->val);     // 中
                st.push(cur); // 将访问的节点放进栈
                cur = cur->left;                // 左
            } else {
                cur = st.top();
                st.pop();
                cur = cur->right;               // 右
            }
        }
        return result;
    }
};

//也可以修改为
vector<int> preorderTraversal(TreeNode* root) {
    vector<int> result;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (!st.empty() || cur != NULL) {
        while (cur != NULL) {
            result.push_back(cur->val);
            st.push(cur);
            cur = cur->left;
        }
        cur = st.top();
        st.pop();
        cur = cur->right;
    }
    return result;
}
```



#### 后序遍历（迭代法）
再来看后序遍历，先序遍历是中左右，后续遍历是左右中，那么我们只需要调整一下先序遍历的代码顺序，就变成中右左的遍历顺序，然后在反转result数组，输出的结果顺序就是左右中了，如下图：



![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785172310370-5b426f10-754b-4f3b-a50e-f51f665b91f5.png)



**所以后序遍历只需要前序遍历的代码稍作修改就可以了，代码如下：**

```c
class Solution {
    public:
    vector<int> postorderTraversal(TreeNode* root) {
        stack<TreeNode*> st;
        vector<int> result;
        if (root == NULL) return result;
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            result.push_back(node->val);
            if (node->left) st.push(node->left); // 相对于前序遍历，这更改一下入栈顺序 （空节点不入栈）
            if (node->right) st.push(node->right); // 空节点不入栈
        }
        reverse(result.begin(), result.end()); // 将结果反转之后就是左右中的顺序了
        return result;
    }
};
```

> 在考试时，如果不敢直接用`reverse`函数，可以再设置一个辅助栈，每次访问结点的时候，直接将该结点加入辅助栈，遍历结束以后，再从辅助栈出栈得到的就是后序遍历序列；
>

这种方法属于讨巧的解法，其实后序遍历的非递归遍历难度最大，接下来我们来看一种正经的迭代解法，摘自[该题解](https://leetcode.cn/problems/binary-tree-postorder-traversal/solutions/431066/er-cha-shu-de-hou-xu-bian-li-by-leetcode-solution/comments/1194730)。

与中序的不同之处在于：

+ 中序遍历中，从栈中弹出的节点，其左子树是访问完了，可以直接访问该节点，然后接下来访问右子树。
+ 后序遍历中，从栈中弹出的节点，我们只能确定其左子树肯定访问完了，但是无法确定右子树是否访问过。

因此，我们在后序遍历中，引入了一个`pre`来记录历史访问记录。

+ 当访问完一棵子树的时候，我们用`pre`指向该节点。
+ 这样，在回溯到父节点的时候，我们可以依据`pre`是指向左子节点，还是右子节点，来判断父节点的访问情况。

```c
class Solution {
public:
    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> res;
        stack<TreeNode*> stk;
        TreeNode* cur = root, *pre = NULL;
        //主要思想：
        //由于在某颗子树访问完成以后，接着就要回溯到其父节点去
        //因此可以用prev来记录访问历史，在回溯到父节点时，可以由此来判断，上一个访问的节点是否为右子树;
        while(cur != NULL || !stk.empty()){
            while(cur!=NULL) {     //步骤1：沿着根的左孩子依次入栈，直到左孩子为空；
                stk.push(cur);
                cur = cur ->left;
            }
            cur = stk.top();  
            stk.pop();  //步骤2：此时从栈中弹出的元素，左子树一定是访问完了的；
            //现在需要确定的是是否有右子树，或者右子树是否访问过
            //如果没有右子树，或者右子树访问完了，也就是上一个访问的节点是右子节点时
            //说明可以访问当前节点
            if(cur->right == NULL || pre == cur->right) {
                res.push_back(cur->val);
                pre = cur;//更新历史访问记录，这样回溯的时候父节点可以由此判断右子树是否访问完成；
                cur = NULL;  //结点访问完，重置cur指针，以免跳到步骤1；
            }else{
                stk.push(cur);//如果右子树没有被访问，那么将当前节点压栈，访问右子树
                cur = cur -> right;  //将其右子树转去执行步骤2.
            }
        }
        return res;
    }
};
```

#### 二叉树的层序遍历
层序遍历一个二叉树。就是从左到右一层一层的去遍历二叉树。这种遍历的方式和我们之前讲过的都不太一样。

需要借用一个辅助数据结构即队列来实现，**队列先进先出，符合一层一层遍历的逻辑，而用栈先进后出适合模拟深度优先遍历也就是递归的逻辑。**

**而这种层序遍历方式就是图论中的广度优先遍历，只不过我们应用在二叉树上。**

使用队列实现二叉树广度优先遍历，动画如下：

class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        queue<TreeNode*> que;
        if (root != NULL) que.push(root);
        vector<vector<int>> result;
        while (!que.empty()) {
            int size = que.size();
            vector<int> vec;
            // 这里一定要使用固定大小size，不要使用que.size()，因为que.size是不断变化的
            for (int i = 0; i < size; i++) {
                TreeNode* node = que.front();
                que.pop();
                vec.push_back(node->val);
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }
            result.push_back(vec);
        }
        return result;
    }
};

vector<int> levelOrder(TreeNode *root) {
    vector<int> res;

    if(root == NULL) return res;

    while(!que.empty()){
        TreeNode *cur = que.front();
        que.pop();
        res.push_back(cur->val);
        if(cur->left!=NULL) que.push(cur->left);
        if(cur->right!=NULL) que.push(cur->right);
    }
    return res;
}

###  根据先序和中序遍历序列还原二叉树
给定一棵二叉树的**先序遍历序列**和**中序遍历序列**，在**<u><font style="color:#DF2A3F;">结点值互不相同</font></u>**的前提下，可以**<u>唯一</u>**还原这棵二叉树。

:::color1
+ 先序遍历：`**根 -> 左 -> 右**`
+ 中序遍历：`**左 -> 根 -> 右**`
+ 先序序列的第一个元素一定是当前子树的根。
+ **在中序序列中定位根，根左边全部属于左子树，根右边全部属于右子树。**
+ **左子树的结点数决定先序序列如何切分**；这一步是该还原算法的关键。

:::

### 根据层序和中序序列还原二叉树
**层序遍历的关键性质**：

+ 第 1 个元素是**根节点**
+ 节点按**层次**出现，同一层的节点在序列中连续（或基本连续）
+ 父节点一定出现在其子节点**之前**

根据层序和中序序列还原二叉树的原理：

:::color1
**层序序列告诉我们"谁是根"，中序序列告诉我们"根的左右各有谁"。**

:::

具体来说：

1. **层序序列的第一个元素**就是整棵树的**根节点**
2. 在**中序序列**中找到根节点的位置，根节点**左边**是**左子树**的所有节点，**右边**是**右子树**的所有节点
3. 从**层序序列**中筛选出左子树的节点（保持原有顺序），得到左子树的层序序列
4. 从**层序序列**中筛选出右子树的节点（保持原有顺序），得到右子树的层序序列
5. 对左右子树**递归**执行上述过程

:::color2
**为什么需要"重新筛选层序序列"？**

:::

层序序列是**整棵树**的层序，当我们确定了根节点后，左子树的节点和右子树的节点在原层序序列中是**交错排列**的。我们需要从中分别"挑出"属于左子树和右子树的节点，各自组成新的层序序列，才能继续递归。

**示例**：

+ 层序：`A B C D E F`
+ 中序：`D B E A F C`
+ 根是 `A`，左子树中序：`D B E`，右子树中序：`F C`
+ 左子树层序：从原层序中挑出 `{D, B, E}` 中的元素，保持顺序 → `B D E`
+ 右子树层序：从原层序中挑出 `{F, C}` 中的元素，保持顺序 → `C F`

### 其他不能唯一确定一棵二叉树的组合
#### 已知先序和后序序列
 已知先序和后序序列为什么不能确定唯一的一棵二叉树，  

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">核心原因：</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">单分支子树无法区分左右</font>**

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">先序（根 - 左 - 右）和后序（左 - 右 - 根）虽然都能确定</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">根节点</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">，但当某个节点</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">只有一个子节点</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">时，无法判断这个子节点是</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">左孩子</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">还是</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">右孩子</font>**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">—— 两种情况产生的先序和后序序列完全相同。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785488132316-4b603c1d-1622-41ba-b54e-3b8bf58eb637.png)

先序和后序都遵循"**根 → 子树**"和"**子树 → 根**"的模式：

+ 先序去掉根后，剩下的是「左子树先序 + 右子树先序」
+ 后序去掉根后，剩下的是「左子树后序 + 右子树后序」

**但问题是：你不知道左子树有几个节点、右子树有几个节点。**

只有当某个节点**同时有左右两个孩子**时，才能通过先序的第二个元素（左子树的根）和后序的倒数第二个元素（右子树的根）来确定分界。一旦某个节点只有一个孩子，这个孩子在左在右都不影响先序和后序的结果，歧义就产生了。



**<font style="color:#DF2A3F;">什么样的二叉树能被先序 + 后序唯一确定</font>**

在**结点值互不相同**、且区分左右孩子的前提下：**只有****<u><font style="color:#DF2A3F;">严格二叉树</font></u>****（也叫真二叉树、正则二叉树）才能由“先序 + 后序”唯一确定。**

其结构条件是：

+ 每个结点要么没有孩子；
+ 要么同时有左、右两个孩子；
+ **不能出现只有一个孩子的结点。**

:::color1
注意：这里的“严格二叉树”不等同于“完美二叉树”。它不要求所有叶子在同一层，**只要求非叶结点必须恰好有两个孩子。**

:::

> **表达式树就是一棵典型的真二叉树**，如果给出该表达式树的先序序列(前缀表达式)和后序序列(后缀表达式)，就可以唯一确定一棵表达式树。
>

![](https://cdn.nlark.com/yuque/0/2026/png/42876865/1785493507331-6ef1912c-bd6a-4dbb-98c0-17775a31d60e.png)



#### 已知层序+前序或层序+后序
已知二叉树的**层序遍历**和**前序遍历**，一般不能唯一确定二叉树；已知**层序遍历**和**后序遍历**，同样不能唯一确定二叉树。

根本原因是：**<u>当某个结点只有一个孩子时，遍历序列可以确定这个孩子的结点内容和所在层次，但不能判断它是左孩子还是右孩子。</u>**

最小反例

考虑两棵不同的二叉树：

```latex
树 1：        A             树 2：       A
             /                           \
            B                             B
             \                           /
              C                         C
```

它们的结构不同：树 1 中 `B` 是 `A` 的左孩子，树 2 中 `B` 是 `A` 的右孩子。

但两棵树的遍历结果分别是：

| 遍历方式 | 树 1 | 树 2 |
| :---: | :---: | :---: |
| 层序 | `A B C` | `A B C` |
| 前序 | `A B C` | `A B C` |
| 后序 | `C B A` | `C B A` |


因此：

+ 层序 + 前序都是 `A B C`，却对应两棵不同的树；
+ 层序 + 后序分别都是 `A B C` 和 `C B A`，也仍对应两棵不同的树。

****

**为什么中序遍历可以帮助确定，而这里不行**

前序和后序主要确定“访问顺序”：

+ 前序先访问根，再访问孩子；
+ 后序最后访问根，先访问孩子。

但是，如果只有一个孩子，访问顺序不会暴露它位于左边还是右边。层序遍历只记录从上到下、从左到右的层次访问顺序；在只有一个结点的下一层中，也没有另一个同层结点可用于比较左右位置。

中序遍历则把根放在左右子树之间。配合前序或后序时，可以用根在中序序列中的位置切分左右子树，所以通常能够递归地唯一确定二叉树（假设**<u>结点值互不相同</u>**）。



**<font style="color:#DF2A3F;">什么时候层序+前序或层序+后序可以唯一确定一棵二叉树</font>**

:::color1
在**结点值互不相同**、**对于不附加任何形状限制的二叉树：当且仅当该树是****<u><font style="color:#DF2A3F;">严格二叉树</font></u>****（每个结点要么有 0 个孩子，要么有 2 个孩子）层序 + 前序或层序 + 后序才能够唯一确定二叉树。**

:::

**也就是不能存在“只有一个孩子”的结点。**

**以“层序 + 前序”为例：**

1. **层序第一个结点是根；**
2. **严格二叉树保证根有左右两个孩子；**
3. **层序中根后面的两个结点分别是左、右子树根；**
4. **在前序中找到右子树根，即可把前序划分为：**

```latex
根 | 左子树 | 右子树
```

5. **对左右子树递归处理。**

**“层序 + 后序”同理，只是利用后序的结构：**

```latex
左子树 | 右子树 | 根
```

****

**注意：如果有额外形状约束，条件可以更宽**

**例如****<font style="color:#DF2A3F;">完全二叉树</font>****中，即使某个结点只有一个孩子，也规定它只能是左孩子；而且层序遍历本身结合完全二叉树的形状就能确定位置。**

**所以更准确地说：**

+ **对一般二叉树：必须是****<font style="color:#DF2A3F;">严格二叉树</font>****；**
+ **对带有额外形状约束的树：只要这些约束能确定单孩子的位置，也可能唯一确定，例如****<font style="color:#DF2A3F;">完全二叉树</font>****。**
