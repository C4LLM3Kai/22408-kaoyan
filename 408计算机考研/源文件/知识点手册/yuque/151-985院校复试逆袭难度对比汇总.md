# 985院校复试逆袭难度对比汇总

![](https://cdn.nlark.com/yuque/0/2024/png/42876865/1721475911911-3745fd11-c260-47f2-bdaf-7eec509aaba5.png)

<font style="color:rgba(0, 0, 0, 0.9);">例图如上所示，本文将985各院校的初复试分值占比进行分类汇总，然后统计各专业的一志愿复试逆袭人数和一志愿录取人数。比如中国人民大学信息学院中的 1+3+0 代表三个专业081200计算机科学与技术、085400电子信息和电子信息-非全日制的一志愿复试逆袭人数，而 20+24+9 表示这三个专业的录取人数，逆袭率 = 一志愿复试逆袭人数 / 一志愿录取人数，可以根据逆袭率的大小比较各院校的复试逆袭难度，</font>**<font style="color:#DF2A3F;">逆袭越小表示越难通过复试逆袭，可以关注逆袭率为零的院校</font>**<font style="color:rgba(0, 0, 0, 0.9);">，还可以结合其他文章一起择校。</font>
