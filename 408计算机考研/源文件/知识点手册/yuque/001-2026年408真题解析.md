**2.** 已知带头结点的双向链表 $ L $ 含有 $ n\,(n\geqslant 3) $ 个元素，结点结构为 `[ p2 | d | p1 ]`，其中，p2 和 p1 分别是指向其直接前驱和直接后继结点的指针，指针 head 指向头结点，指针 `cu = head`。现要将 $ L $ 各结点中的 p2 指针修改为指向 p1 所指结点的直接后继结点。当指针指向的结点不存在时，相应的指针值为 NULL。下列选项中，可以完成修改功能的是

A. while(cu != NULL) { cu->p2 = cu->p1->p1; cu = cu->p1; }

B. while(cu != NULL && cu->p2 != NULL) { cu->p2 = cu->p1->p1; cu = cu->p1; }

C. while(cu != NULL) { if (cu->p1 != NULL) { cu->p2 = cu->p1->p1; cu = cu->p1; } }

D. while(cu != NULL) { if (cu->p1 != NULL) cu->p2 = cu->p1->p1; else cu->p2 = NULL; cu = cu->p1; }

**11.** 采用 $ k $-路归并对外存中保存的数据进行排序，排序的趟数记为 $ d $。下列叙述中，正确的是

### 41.（本题 13 分）
已知二叉搜索树采用二叉链表存储，类型定义如下：

```c
typedef struct BSTNode {            //二叉搜索树结点
    int data;                       //保存结点的关键字值
    struct BSTNode *left, *right;   //指向左孩子、右孩子的指针
} BinTNode;

typedef BinTNode *BTree;            //二叉搜索树
```

对于给定的非空二叉搜索树 $ T $（root 为指向 $ T $ 的根结点的指针）和整数 $ k $，请设计尽可能高效的查找算法：`void searchX(BTree root, int k)`，查找 $ T $ 中其关键字值与 $ k $ 之差的绝对值最小的所有结点，输出差值的绝对值和结点中的关键字值。要求：

1. 给出算法的基本设计思想。（4 分）
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（9 分）

**官方答案：（1）算法的基本设计思想**

按照在二叉搜索树中查找目标 $ k $ 的方法，从根开始沿着某条向下的路径进行查找。若当前结点中的关键字值与 $ k $ 相等，则结果只包含一个结点，差值的绝对值为 0；不相等时，结果最多包含两个结点，差值的绝对值大于 0。

对于不相等的情况，若当前结点中的关键字值大于 $ k $，则结果只可能是当前结点或/及左子树中的结点，此时沿 left 指针继续查找；若当前结点中的关键字值小于 $ k $，则结果只可能是当前结点或/及右子树中的结点，此时沿 right 指针继续查找。直到遇到空指针时为止。

**（2）算法实现**

```c
void searchX(BTree root, int k)
{
    BTree p = root, pmin1, pmin2;
    int min = MAX;                 //MAX 为能表示的整型最大值

    if (p == NULL) return;         //若为空树，则返回

    while (p != NULL) {
        if (p->data == k) {        //结果只包含一个结点
            min = 0;
            printf("差值绝对值 = %d 结点 = %d\n", min, p->data);
            return;
        }
        else if (abs(p->data - k) < min) {   //出现差值绝对值更小的结点
            min = abs(p->data - k);
            pmin1 = pmin2 = p;
        }
        else if (abs(p->data - k) == min) {  //出现另一个差值绝对值为 min 的结点
            pmin2 = p;
        }

        if (p->data > k)
            p = p->left;           //若当前结点 data>k，则结果还可能在左子树中
        else
            p = p->right;          //若当前结点 data<k，则结果还可能在右子树中
    }

    if (pmin1->data != pmin2->data)
        printf("差值绝对值 = %d 结点1 = %d 结点2 = %d\n",
               min, pmin1->data, pmin2->data);
    else
        printf("差值绝对值 = %d 结点 = %d\n", min, pmin1->data);

    return;
}
```

+ 最高 4 位 = `0000` → R 型（具体运算看**最低 4 位** op1）；
+ 最高 4 位 = op2 → I 型；最高 4 位 = op3 → M 型。
+ **op1 与 op2 可以相同**：op1 在 R 型**最低 4 位**，op2 在 I 型**最高 4 位**，位置不同，靠"最高 4 位是否 0000"区分类型，不会混淆；
+ **op2 与 op3 不能相同**：二者都在**最高 4 位**，编码相同就无法区分 I 型与 M 型。

（3）字段：`0000`（R 型）、rt=0010=2、rs=1001=9、op1=0001（加）。

$ R[2]\leftarrow R[2]+R[9]=\text{ABCDH}+\text{F001H}=\text{9BCEH} $

（按十进制：$ 43981+61441=105422=\text{1 9BCEH} $，16 位截断为 `9BCEH`。）

+ **R2 = 9BCEH**；
+ R9 不被写入，**R9 = F001H**。

（4）实现 $ y=16x-5 $（x 地址在 R15，y 紧随 x），x 在 $ [R15+0] $，y 为 16 位（2 字节）在 $ [R15+2] $；M 型固定用 R0 中转：

| 指令 | 操作 | 编码 |
| --- | --- | --- |
| I1 取数 | R0←M[R15+0]（取 x） | `1110` `0000 0000 0000` |
| I2 左移 4 位 | R0←R0<<4（即 ×16） | `0000` `0000` `0100` `0010` |
| I3 加立即数 | R0←R0+(−5) | `0100` `0000` `1111 1011` |
| I4 存数 | M[R15+2]←R0（存 y） | `1111` `0000 0000 0010` |


故：

+ ① `1110`
+ ② `0000 0100`（rt=R0=0000，num=4=0100）
+ ③ `1111 1011`（−5 的 8 位补码）
+ ④ `0000 0000 0010`（offset=2）

**② inode 已在内存，访问偏移 21460 字节最多访问几个盘块？—— 2。**

逻辑块号$ \left\lfloor\frac{21460}{4096}\right\rfloor=5. $直接地址只覆盖逻辑块 0～4，逻辑块 5 须经**一次间接**：

1. 读一次间接地址项所指的**索引盘块**（1 次访盘）；
2. 从中取得逻辑块 5 的数据盘块号，再读**数据盘块**（1 次访盘）。

inode 已在内存、无需读 inode 盘块，故最多 $ \mathbf{2} $ 个盘块（索引块若已缓存则更少）。

（1）TCP 建立连接采用三次握手：

| 次序 | 方向 | 主要字段 | 作用 |
| ---: | --- | --- | --- |
| 1 | C → $ S_i $ | `SYN=1, seq=1000` | C 请求建立连接，SYN 占用序号 1000 |
| 2 | $ S_i $ → C | `SYN=1, ACK=1, seq=2000, ack_seq=1001` | $ S_i $ 确认 C 的 SYN，并发送自己的 SYN |
| 3 | C → $ S_i $ | `ACK=1, seq=1001, ack_seq=2001` | C 确认 $ S_i $ 的 SYN |


所以建立连接需要$ 3\text{ 次握手} $

C 收到的第二个报文段中，确认的是 C 的 SYN 序号 1000。由于 SYN 占用一个序号，确认号为

$ ack\_seq=1000+1=1001. $

（2）连接建立后，C 的第一个数据字节序号为 1001。题目给出的确认段为

```latex
ACK=1, seq=2001, ack_seq=2001, rwnd=1000
```

其中：

+ `seq=2001`：$ S_i $ 的 SYN 使用了序号 2000，因此服务器后续报文的序号从 2001 开始；
+ `ack_seq=2001`：确认 C 已经发送的序号 1001～2000，共 1000 B，也就是两个 500 B 的数据段。

按慢启动的常用初始值 `cwnd=1 MSS` 计算：

1. 收到第一个数据段确认后，`cwnd` 从 $ 1\text{ MSS} $ 增加到 $ 2\text{ MSS} $；
2. 收到第二个数据段确认后，`cwnd` 从 $ 2\text{ MSS} $ 增加到 $ 3\text{ MSS} $。

因此$ cwnd=3\text{ MSS}=3\times500=1500\text{ B}. $

TCP 实际发送窗口取拥塞窗口和接收窗口的较小值：$ \text{发送窗口}=\min(cwnd,rwnd)
=\min(1500,1000)
=1000\text{ B}. $

（3）文件数据的序号范围为：

| 数据段 | 序号 | 长度 | 下一个序号 |
| :---: | :---: | :---: | :---: |
| 第 1 段 | 1001 | 500 | 1501 |
| 第 2 段 | 1501 | 500 | 2001 |
| 第 3 段 | 2001 | 500 | 2501 |
| 第 4 段 | 2501 | 500 | 3001 |


因此 C 的数据发送完后，下一个可用序号为 3001。C 发送 FIN 时使用 `seq=3001`，而 FIN 也占用一个序号，所以服务器确认它时使用 `ack_seq=3002`。

$ S_i $ 的 SYN 使用了序号 2000，之后没有发送数据，因此服务器发送 FIN 时使用的序号仍为 2001。

四次挥手可以写成：

| 次序 | 方向 | 主要字段 |
| ---: | --- | --- |
| 1 | C → $ S_i $ | `FIN=1, ACK=1, seq=3001, ack_seq=2001` |
| 2 | $ S_i $ → C | `ACK=1, seq=2001, ack_seq=3002, FIN=0` |
| 3 | $ S_i $ → C | `FIN=1, ACK=1, seq=2001, ack_seq=3002` |
| 4 | C → $ S_i $ | `ACK=1, seq=3002, ack_seq=2002, FIN=0` |


所以释放连接需要$ 4\text{ 次挥手}. $

C 收到的最后一个 TCP 报文段是第 3 个报文段，其字段为$ \boxed{seq=2001,\quad ack\_seq=3002,\quad FIN=1}. $

（4）按题目通常采用的 RTT 计时方式，传输过程可以分成以下 4 个 RTT：

1. 第 1 个 RTT：完成 TCP 三次握手；
2. 第 2 个 RTT：发送第 1 个数据段并收到确认；
3. 第 3 个 RTT：在拥塞窗口和接收窗口允许的范围内发送第 2、3 个数据段并收到确认；
4. 第 4 个 RTT：发送第 4 个数据段并收到最后确认。

因此 C 收到确认、确定 $ S_i $ 已成功接收整个文件的时刻为$ 4\times RTT=4\times5\text{ ms}=20\text{ ms}. $
