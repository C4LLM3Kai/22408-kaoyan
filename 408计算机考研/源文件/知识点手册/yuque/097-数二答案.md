17、设函数 $ y\left( x\right) \left( {x \geq  0}\right) $ 由方程 $ {y}^{3} + {xy} - 8 = 0 $ 确定，求曲线 $ y = y\left( x\right) $ 与直线 $ x = 7 $ 以及两个坐标轴所围曲边梯形绕 $ x $ 轴旋转一周所得旋转体的体积 $ V $ .

**解析：**令 $ F\left( {x, y}\right)  = {y}^{3} + {xy} - 8 $ ,当 $ x \geq  0 $ 时, $ {F}_{y}^{\prime }\left( {x, y}\right)  = 3{y}^{2} + x \neq  0 $ ,所以 $  y\left( x\right) (x \geq 0) $ 为由方程 $ {y}^{3} + {xy} - 8 = 0 $ 唯一确定的单值函数.

当 $ x = 0 $ 时，$ y = 2 $ ; 当 $ x = 7 $ 时，由 $ {y}^{3} + {7y} - 8 = 0 $ 知 $ \left( {y - 1}\right) \left( {{y}^{2} + y + 8}\right)  = 0 $ ,得 $ y = 1 $ .

由 $ {y}^{3} + {xy} - 8 = 0 $ 解得 $ x = \frac{8 - {y}^{3}}{y},\mathrm{\;d}x = \left( {-\frac{8}{{y}^{2}} - {2y}}\right) \mathrm{d}y $ ，所以

$ V = \pi {\int }_{0}^{7}{y}^{2}\mathrm{\;d}x =  - {2\pi }{\int }_{2}^{1}\left( {{y}^{3} + 4}\right) \mathrm{d}y = {2\pi }{\int }_{1}^{2}\left( {{y}^{3} + 4}\right) \mathrm{d}y = {\left. 2\pi \left( \frac{1}{4}{y}^{4} + 4y\right) \right| }_{1}^{2} = \frac{31}{2}\pi . $

21、设函数$ f(x) $在$ [0,1] $上连续，且$ \int_0^1f(x)dx=\int_0^1xf(x)dx $，证明：

	  （1）存在$ \xi\in[0,1] $，使$ (\xi-1)f(\xi)=\xi f(1-\xi) $；

	  （2）存在$ \eta\in[0,1] $，使$ \int_0^{\eta}f(x)dx=0 $ .

**解析：**证：（1）由$ \int_0^1f(x)dx=\int_0^1xf(x)dx $知$ \int_0^1(1-x)f(x)dx=0 $，

令$ 1-x=t $，得$ \int_0^1tf(1-t)dx=0 $，即$ \int_0^1xf(1-x)dx=0 $，

所以$ \int_0^1[(1-x)f(x)dx+xf(1-x)]dx=0 $，由积分中值定理得，存在$ \xi\in[0,1] $，使得

$ (\xi-1)f(\xi)=\xi f(1-\xi) $

（2）令$ g(x)=\int_0^x(x-t)f(t)dt $，则$ g(0)=g(1)=0 $，由$ f(x) $在$ [0,1] $上连续得$ g(x) $在$ [0,1] $连续，在$ (0,1) $内可导，由罗尔定理知，存在$ \eta\in[0,1] $，使$ g^{\prime}(\eta)=0 $，$ g(x)=x\int_0^{x}f(t)dt-\int_0^xtf(t)dt $，

则$ g^{\prime}(x)=\int_0^xf(t)dt+xf(x)-xf(x)=\int_0^xf(t)dt $，即$ \int_0^{\eta}f(x)dx=0 $。



22、设矩阵$ A = \begin{bmatrix} a &amp; 0 &amp; -a \\ -a &amp;a &amp;0 \\ 0 &amp;-a &amp; a \\ \end{bmatrix} $，$ B = AA^T $，二次型 $ f(x_1, x_2, x_3) = x^TBx  $经过正交变换$ x=Qy $化为标准型为 $ ky_1^2 + 3y_2^2 + 3y_3^2 $。

（1）求$ a $和$ k $的值；

（2）求正交矩阵$ Q $。

**解析：**（1）$ A^T\begin{bmatrix}1\\1\\1\end{bmatrix}=0\begin{bmatrix}1\\1\\1\end{bmatrix} $，从而$ AA^T\begin{bmatrix}1\\1\\1\end{bmatrix}=0\begin{bmatrix}1\\1\\1\end{bmatrix} $，从而得到B的一个特征值为0，则$ k=0 $

$ tr(B)=tr(AA^T)=6a^2=6 $，从而$ a=1 $或$ -1 $。

（2）$ \lambda_1=0 $对应的特征向量为$ \alpha_1=(1,1,1)^T $，设$ \lambda_2=\lambda_3=3 $的特征向量为$ \alpha=(x_1,x_2,x_3)^T $

则有$ x_1+x_2+x_3=0 $，所以$ \alpha_2=(-1,1,0)^T,\alpha_3=(1,1,-2)^T $（二者已正交）

单位化得$ Q=\begin{bmatrix}\frac1{\sqrt3}&amp;\frac{-1}{\sqrt2}&amp;\frac{1}{\sqrt6}\\\frac1{\sqrt3}&amp;\frac{1}{\sqrt2}&amp;\frac{1}{\sqrt6}\\\frac1{\sqrt3}&amp;0&amp;\frac{-2}{\sqrt6}\end{bmatrix} $
