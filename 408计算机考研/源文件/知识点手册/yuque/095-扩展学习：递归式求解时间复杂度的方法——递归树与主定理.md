1. 下列代码的时间复杂度是（）

```go
int func(int n) {
    if (n == 1) return 1;
    return func(n - 1) * n;
}
```

  A. $ O(n^2) $  B. O(n)  C. $ O(2^n)  $ D. $ O(nlog_2n) $

<details class="lake-collapse"><summary id="ucbcc14c4"><span class="ne-text">解析</span></summary><p id="u788e9a95" class="ne-p" style="text-align: left"><span class="ne-text">  答案：B。【解析】递归关系式为T(n)=T(n−1)+O(1)，为什么这里是O（1）不是O（n），因为 * n是单个乘法操作，时间消耗为常数。</span></p><p id="u1c83f153" class="ne-p" style="text-align: left"><span class="ne-text">  展开递归：T(n)=T(n−1)+O(1)=(T(n−2)+O(1))+O(1)=(T(n−3)+O(1))+O(1)+O(1)=...=T(1)+O(n)</span></p><p id="u9413f09a" class="ne-p" style="text-align: left"><span class="ne-text">  因为 </span><strong><span class="ne-text">T(1) = O(1)</span></strong><span class="ne-text">，最终得：T(n)=O(n)</span></p></details>
