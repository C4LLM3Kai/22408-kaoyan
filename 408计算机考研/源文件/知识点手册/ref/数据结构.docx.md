# 四、树与二叉树

## (一)树的基本概念

没有节点，叫空树，

n个节点的树一定只有n-1条边，否则就有环存在了

祖先是指从该节点到根节点路上沿途出现的节点。

区分兄弟节点和堂兄弟节点。

子孙既包括孩子也包括孙子、重孙子；

树的度=最大的节点的度

分支节点一定不是叶节点，即它一定有孩子

树的路径长度=所有节点到根节点路径长度的总和

树的性质：

①树的节点数n=所有节点度数之和+1

②度为m的树，在其第i层，最多有mi-1个节点

③高度为h的m叉树，最多有1+m+m2+m3.......

④度为m的具有n个节点的树，最小高度为，自己算吧，把前面几层铺满就行

⑤度为m，具有n个节点的树的最大高度为n-m+1，因为在树中至少要出现一个度为m的节点，否则不符合题意

## (二)二叉树

### 1.二叉树的定义及其主要特征

度为2的树至少有根节点+两个子节点（保护度为2的特征），但二叉树不需要这样，即它最少可以为空节点。

度为2的树，孩子的相对顺序是根据另一个孩子所确定的，如果没有另一个孩子，也就不需要确定孩子的顺序。但是二叉树的孩子必须确定顺序！

双亲节点的编号问题：如果编号为i，那么它的左孩子为2i，右孩子为2i+1，另外，它的父亲节点位i/2向下取整

①二叉排序树：中序排列的二叉树；左子树小于右子树

②平衡二叉树：树中任意一个节点的左子树和柚子树的高度之差的绝对值不超过1.

③正则二叉树：每个分支节点都有2个孩子

二叉树的性质：

①叶子节点数=度为2的节点数+1

下面是针对完全二叉树：

②对完全二叉树编号1~n,最后一个分支节点的编号为n/2向下取整；完全二叉树只可能出现一个度为1的节点，且它的编号为最后一个分支节点n/2向下取整，在该节点之后的一定是叶子结点；

如果一个节点没有左孩子、必是叶子结点

完全二叉树总共n个节点，最后一个分支节点的编号为N/2向下取整

最简单的一种情况，只需要关注如果没有边的话记为0或者无穷大即可。

①邻接表中可以很快找出所有顶点的邻边，邻接矩阵中需要完全读取一行

③图的邻接表并不唯一，因为各个顶点的链接顶点的顺序可以更改的

## (三)图的遍历

### 1.广度优先搜索

（1）基本概念

①类似于树的层序遍历

②借助队列存储临时的节点，当某个节点出队时，需要把它的链接的节点扫描入队

③非递归算法、不需要回退操作

④设置一个visited数组来设置节点状态

（2）性能分析

队列最长存储V-1个节点，即其余v-1个结点全都与剩余的那个节点相连，故空间复杂度为O(V)

采用邻接表时，每个顶点和每条边都需要访问一次，所以时间复杂度是O（V+E），空间复杂度为O（n）；采用邻接矩阵存储时，查找每个顶点的邻接点时间为O（V），所以时间复杂度为O（V2）

3. 广度优先算法求最短路径

注意广度优先搜索插入队列的过程中，需要按照邻接表中的边的顺序插入到队列中

4. 广度优先生成树

邻接矩阵的广度优先生成树是唯一的，但邻接表（表示法不唯一）的广度优先生成树不是唯一的

### 2.深度优先搜索

（1）基本概念

①类似于树的先序遍历

②借助栈存储临时的节点，当某个节点没有可访问的其他邻边时，回退到上一个节点，访问上一个节点的其他邻边

③递归算法、需要回退操作

④设置一个visited数组来设置节点状态

⑤若采用邻接矩阵则BFS与DFS一致，若采用邻接表法则DFS和BFS不一致

（2）性能分析

空间复杂度为O(V)

采用邻接表时，每个顶点和每条边都需要访问一次，所以时间复杂度是O（V+E），空间复杂度为O（n）；采用邻接矩阵存储时，查找每个顶点的邻接点时间为O（V），所以时间复杂度为O（V2）

5. 深度优先生成树和生成森林

邻接矩阵的广度优先生成树是唯一的，但邻接表（表示法不唯一）的广度优先生成树不是唯一的

图的遍历和图的连通性：

在图的DFS和BFS中，添加了第二个for循环来选取初始点继续遍历，防止一次无法遍历图的所有顶点。

### 1.最小(代价)生成树

生成树（减去一条边变成非连通图、加上一条边有回路）

②最小生成树的边数=顶点数n 减去1

④最小生成树是基于贪心算法！

2. Prim普利姆算法（选择与上一步最近的一个顶点Point---2P组合）

算法思路：

首先，初始化空树、然后加入任意一个顶点；在其余所有顶点当中，找到与之树距离最近的顶点，加入树中，循环操作

3. Kruskal克鲁斯卡尔算法（选择原图中权重最小的边）

最终的终止结果是：没有形成回路、且又n-1条边

最坏的情况是需要对所有的边都扫描一次O（E），每次扫描需要O（log2E）的时间，所以时间复杂度为为O（E log2E），所以适用于边稀疏而顶点较多的图

### 3.拓扑排序

AOV（有向无环图、用顶点表示活动的网）

算法关键点：找到入度为0的节点

拓扑排序算法的关键在于设置了一个indegree数组、设置了一个print数组、设置了一个栈或者队列。

## (八)堆排序

（1）算法思想

基于交换思想、堆的数据结构、与顺序存储的完全二叉树概念接近，结合复习！

①建立大根堆（一次性先排成二叉树，然后进行调整，而不是一个一个元素加入）、检查该堆是否符合大根堆的特性：

首先找到大根堆中最大编号（n/2向下取整）的非叶节点，从该节点出发检查所有非叶结点是否满足根>左右，若不满足，则把该结点的最大孩子节点与之互换即可。同时遇到了一个麻烦的问题：把该节点与孩子节点互换之后，导致子树又不满足堆的定义了，这时候代码会继续探测子树是否满足条件，然后不断调整子树。而不是固有思想，让它从最后一个非叶结点再扫描一遍，这是错误的

②基于大根堆进行排序

首先是把末尾元素与根节点（含有最大值）进行互换，删除交换之后的末尾节点（相当于取出了最大值），然后继续调整大根堆使之满足大根堆的定义

③大根堆的插入算法

首先把元素插在最后一个元素的位置上，然后调整大根堆的结构使之满足定义。

这里要区分于基于大根堆进行排序的算法，这里只需要与父节点进行对比即可，不需要对兄弟节点进行对比，因为兄弟节点一定小于父节点。（2011真题）

## (十)基数排序

（1）算法思想

是对个位元素、十位元素、百位元素依次进行对比：

首先对个位元素依次放入对应的“链表中”，全部放入后，从每个链表中取下数据

然后对十位元素依次放入对应的“链表中”.......

其实本质上每一趟对个位、十位+个位、百位+十位+个位进行了排序，最终得到想要的结果

（2）算法性能

| 空间 | O（r），r个队列、r个队尾和队首指针 |
| --- | --- |
| 一趟排序 | O（n），扫描整个数组元素 |
| 一趟收集 | O（r），这个r其实就代表10个队列，每个队列首尾相接即可，只需要O（1）,所以总共是O（r） |
| 全部时间 | 关键看元素中总共有d位，完整的一趟=排序+收集，总共需要d趟，所以时间是O（d*(n+r)） |
| 稳定性 | 稳定！ |
| 适用性 | 顺序表、链表 |

（3）特殊点

①基数排序不是基于“比较”的算法

②与数据的初始状态无关

③擅长的应用

④实数包含整数、float和double，显然针对实数来说，基数排序并不合适。基数排序只能针对于整数
