## 一、二叉树存储结构与递归三大遍历母板（手写笔记第5页）

408 树类算法大题满分 13~15 分，90% 直接套用先序、中序或后序递归母板即可得分。

### 1. 存储结构定义与下标规律
- **顺序存储（下标从 1 开始）**：左孩子为 $2i$，右孩子为 $2i+1$，父节点为 $\lfloor i/2 \rfloor$（若从 0 开始：左 $2i+1$，右 $2i+2$）。
- **链式存储结构体（考场必默写）**：
```c
typedef struct BiNode {
    int data;                            /* 考题为字符改 char */
    struct BiNode *lchild, *rchild;      /* 左右孩子指针 */
} BiNode, *BiTree;
```

### 2. 链式二叉树递归三大遍历通用母板
```c
/* ① 中序遍历（左 根 右）：两种写法均可，写法二更不易漏括号（手写笔记第5页） */
void InOrder(BiTree T) {
    if (T == NULL) return;              /* 递归基：空结点直接返回 */
    InOrder(T->lchild);
    visit(T);                           /* 访问根结点：如 printf("%d", T->data); */
    InOrder(T->rchild);
}
/* ② 先序遍历（根 左 右） */
void PreOrder(BiTree T) {
    if (T == NULL) return;
    visit(T); PreOrder(T->lchild); PreOrder(T->rchild);
}
/* ③ 后序遍历（左 右 根） */
void PostOrder(BiTree T) {
    if (T == NULL) return;
    PostOrder(T->lchild); PostOrder(T->rchild); visit(T);
}
```

## 二、顺序存储二叉树递归遍历模板（手写笔记第6页）

**考场通杀场景**：2022 真题判定顺序存储二叉树、完全二叉树数组遍历。

```c
/* 顺序存储二叉树中序遍历（数组 binaryTree 下标从 1 开始，-1 表示空结点） */
int binaryTree[100];
int maxnum;                             /* 数组最大有效范围 */

void Inorder_Seq(int root) {
    if (root > maxnum || binaryTree[root] == -1) return;
    Inorder_Seq(root * 2);              /* 1. 递归左子树：下标 2*root */
    printf("%d ", binaryTree[root]);    /* 2. 访问当前结点本身 */
    Inorder_Seq(root * 2 + 1);          /* 3. 递归右子树：下标 2*root + 1 */
}
```

## 三、二叉树层次遍历辅助队列模板（手写笔记第6页）

**基本思想**：① 根结点入队；② 队列非空则出队并访问该结点，若有左孩子将左孩子入队，若有右孩子将右孩子入队；③ 重复直到队空。

```c
/* 通用母板：二叉树层次遍历（BFS），时间 O(n)，空间 O(w) */
void LevelOrder(BiTree T) {
    if (T == NULL) return;
    BiTree queue[1000];                 /* 考场简写静态循环队列 */
    int front = 0, rear = 0;
    queue[rear++] = T;                  /* 1. 将根结点入队 */
    while (front < rear) {              /* 2. 队列不空则循环 */
        BiTree p = queue[front++];      /* 队头出队 */
        visit(p);                       /* 访问出队结点 */
        if (p->lchild != NULL) queue[rear++] = p->lchild;  /* 左孩子入队 */
        if (p->rchild != NULL) queue[rear++] = p->rchild;  /* 右孩子入队 */
    }
}
```

## 五、树与图核心真题：暴力解法 vs 最优解法

### 1. 2014 求二叉树带权路径长度 WPL
- **通用解（递归深度累加）**：遇到叶子节点返回 $weight \times depth$，非叶结点返回左右子树和。主调入口 `CalWPL(root, 0)`。时间 $O(n)$，空间 $O(h)$。
- **层次遍历暴力解**：用队列层次遍历，每层记录当前深度，出队若为叶子直接累加到全局 `wpl`。

### 2. 2017 中缀表达式加括号输出
- **中序遍历模板改造**：仅在“非根分支结点（$depth > 1$ 且有孩子）”进入前输出 `(`，中序遍历左右子树后输出 `)`。

### 3. 2022 顺序存储二叉树判定 BST
- **暴力解（降维转数组直接检查严格递增）**：直接中序遍历把顺序存储的值顺序写入数组 `arr[]`，最后写一层 `for (i = 1; i < len; i++) if (arr[i] <= arr[i-1]) return 0;`。考场极度稳妥，稳拿 11 分！
- **最优解**：带指针 `int *pre` 在中序递归中直接与前驱比较，空间 $O(h)$。

```c
/* 2022 暴力解核心示范：中序存入数组，检查是否严格单调递增，保底 11 分 */
int arr[1000], k = 0;
void InOrderSave(int tree[], int n, int root) {
    if (root >= n || tree[root] == -1) return;
    InOrderSave(tree, n, 2 * root + 1); /* 左子树（下标 0 起算） */
    arr[k++] = tree[root];              /* 顺序暂存到一维数组 */
    InOrderSave(tree, n, 2 * root + 2); /* 右子树 */
}
int JudgeBST_Brute(int tree[], int n) {
    k = 0; InOrderSave(tree, n, 0);
    for (int i = 1; i < k; i++) {
        if (arr[i] <= arr[i - 1]) return 0; /* 出现非严格递增直接判否 */
    }
    return 1;
}
```
