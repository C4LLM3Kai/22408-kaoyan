## 二、五星重难点分级

每个考点标题后带星标，星标取「考频 × 难度 × 分值」的综合：

| 星标 | 名称 | 含义 | 复习要求 |
|---|---|---|---|
| ★★★★★ | 决胜考点 | 几乎年年必考，且是难题/易错点 | 闭卷默写 + 限时算对 |
| ★★★★ | 高频重点 | 反复考，套路固定但计算量不小 | 熟练到条件反射 |
| ★★★ | 常考点 | 隔年出现或以小题形式考 | 理解 + 会用 |
| ★★ | 一般考点 | 低频或基础工具 | 会算即可 |
| ★ | 了解性考点 | 大纲要求"了解" | 记住结论 |

全书星标由 `源文件/考点星级总表.md` 统一裁定（高数 5 章 88 条、线代 6 章 39 条），
所有章节的星标已用脚本逐条比对，无一处擅自改星。

## 四、工程结构与重建方式

```
数学二/
├── 数学二考纲知识点手册-1-高等数学.pdf   ← 成品
├── 数学二考纲知识点手册-2-线性代数.pdf   ← 成品
├── 源文件/
│   ├── build_m2.py           总装脚本：Markdown → XeLaTeX → PDF（两个分册）
│   ├── build_book.py         转换器（复用 408 手册的管线）
│   ├── check_m2.py           质检脚本：星标一致性 / 公式配平 / 生僻字符 / 超纲词 / 表格竖线
│   ├── 写作规范-数学二.md     语法、星级、考纲边界、篇幅规范
│   ├── 考点星级总表.md        星级权威表（改星只改这里）
│   ├── 高数/、线代/           各章 Markdown 源文件（可直接改）
│   └── 提炼/
│       ├── 高数-源提炼.md、线代-源提炼.md   《数学大观》思维导图提炼
│       ├── raw/               各素材 PDF 的逐页文本抽取
│       └── 切分/              按章切好的素材（写作用）
└── build/高数/、build/线代/   book.tex / book.log / book.pdf 等编译中间件
```

重建（需 TeX Live，本机为 `/Library/TeX/texbin`）：

```bash
cd 数学二
python3 源文件/build_m2.py          # 编译两册并复制成品到本目录
python3 源文件/build_m2.py 高数      # 只编译高数册
python3 源文件/check_m2.py          # 质检全部章节
```

## 五、质检情况

- XeLaTeX 编译：**0 error、0 missing character**；仅剩 7 处 ≤7pt 的 Overfull（可忽略的排版溢出）。
- 章节质检：行内 `$` 全成对、`$$` 全闭合，`pmatrix`/`vmatrix`/`cases`/`aligned`/`array` 环境全部配对，
  表格无裸 `|`（绝对值统一 `\vert`），无一级标题、无代码围栏、无 HTML、无 `---`。
- 已修正的问题：`#` 误写导致标题变正文、`\right`/`\alpha`/`\beta` 被转义吞掉反斜杠、
  `\neq` 被吞成换行、`array` 列数不足、`(1+x)^x-1` 的错误等价、表格中 `$|x|$` 破坏列结构。
- 数值抽查：等价无穷小与泰勒表、Wallis 公式、施密特正交化例题、二阶常系数非齐次特解、
  二重积分例题等均由脚本或人工复核。
