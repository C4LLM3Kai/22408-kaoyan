# 《考研数学二·考纲知识点手册》写作规范

本规范面向两个分册：**高等数学分册**、**线性代数分册**。全部章节 Markdown 必须严格遵守本文件，
因为转换器只识别这里列出的语法。

---

## 一、总目标

编一本**严格按《考研数学二考试大纲》顺序编排**的知识点手册，读者是正在备考数学二的考生，
用途是「对着考纲查漏补缺 + 考前快速回顾 + 按星级分配复习精力」。因此：

- **覆盖**：考纲（见 `提炼/切分/数学二大纲-全.txt`）上出现的每一条都必须写到，一条不漏。
- **顺序**：章、节、知识点顺序与考纲**完全一致**。
- **深度**：以「能直接做题」为标准。定义、条件、公式、适用前提、边界情形、常见陷阱、解题步骤、易错点都要写清楚。
- **取精华去糟粕**：只写数学二考纲要求的内容（见第三节黑名单）。数一/数三专属、超纲的拓展一律不写，
  哪怕源材料里写得再多。**帮助理解考点所必需的最小前置知识可以写，但只写一两句。**

---

## 二、星级制度（本手册的核心特色）

每个知识点标题末尾必须带星标，星标**必须与本目录的《考点星级总表》一致**（`源文件/考点星级总表.md`），
不得自行改星。

| 星标 | 名称 | 含义（取"考频 × 难度 × 分值"的综合） | 复习要求 |
|---|---|---|---|
| ★★★★★ | 决胜考点 | 几乎年年必考，且是难题/易错点，一题 10 分上下 | 必须做到闭卷默写 + 限时算对 |
| ★★★★ | 高频重点 | 多年反复考，套路固定、计算量不小 | 必须熟练，形成条件反射 |
| ★★★ | 常考点 | 隔年出现或以小题形式考 | 理解 + 会用 |
| ★★ | 一般考点 | 低频，或是解题的基础工具 | 会算即可 |
| ★ | 了解性考点 | 考纲要求"了解"，考到也是送分 | 记住结论 |

写法示例（标题内直接写星号，**不要手写编号**，编号由排版自动生成）：

```
#### 未定式极限的计算 ★★★★★
```

每章开头必须有一张**星级汇总表**（考点 / 星级 / 考纲要求 / 难度 / 常见题型），
让读者 30 秒内看清本章重点分布。表格第一列只写考点名，**不要加编号列**。

难度列只填三个词：**基础 / 中等 / 难**。

## 三、考纲边界（去糟粕黑名单）

**高等数学——数学二不考，绝对不许写**：

- 向量代数与空间解析几何（向量运算、平面与直线、曲面与曲线）
- 无穷级数（数项级数、幂级数、傅里叶级数、收敛判别法）
- 三重积分、曲线积分、曲面积分、高斯公式、斯托克斯公式
- 场论（梯度散度旋度）、方向导数与梯度的深入应用（只需在偏导数处一句带过）
- 含参变量积分、傅里叶变换、Γ 函数等分析类拓展
- 微分方程的：欧拉方程、方程组、级数解法、拉普拉斯变换、差分方程
- 定积分应用中：数二**要**面积、体积、弧长、旋转体侧面积、平行截面体积、功、压力、质心形心、平均值；
  **不要**写数一专属的复杂物理应用（如转动惯量只一句带过即可，考纲未列则删）

**高等数学——数二只是"了解"的，点到为止**：多元函数极限与连续的严格定义、隐函数存在定理、
有界闭区域上二元连续函数性质、二重积分中值定理、反常积分收敛的比较判别法（会判断即可）。

**线性代数**：数学二线代大纲与数一基本一致（六章全考），但**不写**线性空间与向量空间的定义、
基变换与坐标变换、线性变换、若尔当标准形、矩阵的合同/相似的更深理论。只写到考纲六章为止。

**其他**：不写概率论与数理统计（数二不考）。

写每一节前先自问："数二考纲里有这一条吗？"没有就删。

## 四、Markdown 语法约定（转换器只认这些）

| 写法 | 用途 |
|---|---|
| `# 标题` | **不要用**。章标题由文件名与总装脚本生成 |
| `## 一、xxx` | 对应考纲的一级条目（一、二、三……） |
| `### （一）xxx` | 对应考纲的二级条目 |
| `#### 1. xxx ★★★★` | 对应考纲的三级条目 / 具体知识点（**星标写在这里**） |
| `##### xxx` | 更细的小点（尽量少用） |
| 普通段落 | 一句一行或一段多行皆可，段落之间空一行 |
| `- xxx` / `1. xxx` | 无序 / 有序列表，可嵌套（4 空格缩进） |
| `**粗体**` | 关键术语、需要记住的结论 |
| `` `代码` `` | 行内代码、标识符 |
| `\| a \| b \|` 表格 | 对比类内容优先用表格 |
| `$...$` / `$$...$$` | 行内 / 独立公式，**必须是合法 LaTeX** |
| `> 引用` | 用于章首"本章考纲要求" |

### 提示框（重要）

```
:::key 标题
内容（可多段、可有列表、可有公式）
:::
```

- `:::key` — **核心结论 / 必背**（蓝）
- `:::warn` — **易错点 / 常见陷阱**（红）
- `:::exam` — **真题考法 / 出题角度**（灰）

提示框内不能再嵌套提示框，不要在里面再写 `:::`。

### 禁止事项

- 不要用未标注语言的 ``` 围栏代码块（数学手册几乎不需要代码块）。
- 不要写 HTML 标签、不要贴图片链接 `![](...)`。
- 不要写 `#` 一级标题；不要用 `---` 分隔线（分页由脚本控制）。
- 公式里不要用 `\begin{align}`、`\begin{cases}` 之外需要额外宏包的环境；
  `$$...$$` 里可用 `aligned`、`cases`、`pmatrix`、`bmatrix`、`vmatrix`。
- 不要用 `\boxed`、`\text{}` 之外的复杂宏；不要用 Unicode 生僻符号（∫ √ ∞ 箭头等转换器会自动换成数学符号，但**优先直接写 LaTeX**）。
- 表格必须是标准 Markdown 表格，列数全表一致。

## 五、每章的结构模板

```
### 本章考纲要求

> （照抄《数学二大纲》中本章的"考试内容"与"考试要求"原文，逐条列出，不要改写用词）

### 本章星级总表

| 考点 | 星级 | 考纲要求 | 难度 | 常见题型 |
|---|---|---|---|---|
| 未定式极限的计算 | ★★★★★ | 掌握 | 中等 | 选择、填空、解答 |

## 极限的计算

### 未定式的化简

#### 未定式极限的计算 ★★★★★
...正文...

## 极限的存在性

### 夹逼与单调有界

#### 夹逼准则 ★★★★
...正文...

（章节末必须有）
### 本章易错清单

1. ...
2. ...
```

**层级约定（严格遵守）**：

- 章标题由文件名生成，**文件内不要写 `#`**。
- `## xxx` = 本章内部的二级板块（如"极限的计算""极限的存在性"），会自动编号为"一、二、…"。
- `### xxx` = 板块内的小节；但 `本章考纲要求`、`本章星级总表`、`本章易错清单` 这三个固定标题
  必须用 `###` 且**不会**被编号。
- `#### 考点名 ★★★★` = 具体考点，星标写在这里。
- `##### xxx` = 考点内部的更细分类（尽量少用）。

**每个知识点（`####`）的推荐骨架**（按内容自然组织，不要机械凑小标题）：

1. **定义 / 结论**：准确、可复述。关键公式用 `$$...$$`，说明符号含义和**适用前提**。
2. **解题步骤 / 套路**：给可执行的分步流程（"看到 X，先做 Y"）。
3. **典型例子**：带数字的小例子，能自己算一遍验证（**只写题干和关键步骤，不要写成题海**）。
4. `:::warn` **易错点**：考生最常错的地方（如"等价无穷小只能在乘除中替换，加减需谨慎"）。
5. `:::exam` **真题考法**：这一考点以什么形式出现、常见陷阱。**不确定的年份、题号一律不写。**

## 六、准确性要求（最重要）

- **不允许编造**：年份、题号、教材页码、"某年考过"这类表述，没有把握就不写。
- **公式必须自洽**：写完自己代入一组具体数字验证一遍。
- **术语用统考叫法**：如"导数""可微""基础解系""极大线性无关组""实对称矩阵正交相似对角化"。
- 不同教材写法不同处，说明"统考按 xxx 理解"。
- 源材料是 OCR 文本，公式常被拆散（如 `2 2 1 sin cos t t − =`），**必须按数学常识还原成正确公式**，
  还原不了的宁可不写，绝不照抄乱码。
- 源材料里的"哲学注解""历史趣事"一律不要写进手册（去糟粕）。

---

## 七、篇幅要求

- 高数分册每章正文 **12000～20000 字符**（中文字符计）；一元微分学、一元积分学写到上限。
- 线代分册每章正文 **8000～15000 字符**；矩阵、线性方程组、特征值与二次型写到上限。
- 公式、表格不计入上述字符数。
- 宁可写透一个考点，也不要罗列一堆只有标题的空话。**没有解释的标题列表没有任何价值。**
