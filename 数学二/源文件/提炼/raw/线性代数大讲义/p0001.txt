一、行列式
考试内容
1.【冯建轩】行列式的概念和基本性质
一、历史溯源
1.【冯建轩】1683 年：日本数学家关孝和在《解伏题之法》中首次提出行列式思想
（未命名），用于解三元方程组。
2.【冯建轩】1750 年：瑞士数学家克莱姆（GabrielCramer）在《线性代数分析导言》
中发表克莱姆法则，首次系统使用行列式解方程组。
3.【冯建轩】1772 年：法国数学家拉普拉斯（Laplace）提出行列式按行/列展开定理
（Laplace 展开）。
4.【冯建轩】1815 年：法国数学家柯西（AugustinLouisCauchy）首次使用"行列式"
（Determinant）一词，证明行列式乘法公式| | | | | | AB A B= 
。
5.【冯建轩】1841 年：德国数学家雅可比（Jacobi）建立行列式系统理论，提出雅可
比行列式。
二、历史趣事
克莱姆的"法则"误会：克莱姆法则的公式实为麦克劳林（Maclaurin）1748 年首创，但
克莱姆首次公开发表。因克莱姆在书中谦称"此乃前人所得"，后世误归功于他，成为数
学史上著名的"署名乌龙"
。
