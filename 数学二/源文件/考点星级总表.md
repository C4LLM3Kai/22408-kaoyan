# 数学二 考点星级总表（权威版）

本表是全书的**重难点分级依据**，所有章节的星标必须与本表逐条一致，不得自行改星。
星级取「考频 × 难度 × 分值」综合，定义见《写作规范》第二节。

- 考纲要求列：《数学二大纲》用词（了解 / 理解 / 掌握 / 会）。
- 难度列：基础 / 中等 / 难。
- 星标写法：直接写 `★★★★★` 这样的星号。
