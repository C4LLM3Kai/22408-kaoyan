## 一、两种约定的核心公式

循环队列用 `front` 指向队头元素、`rear` 指向队尾元素的下一个位置，队列容量为 `MaxSize`。判断队满的方式有两种，**必须按题目约定选一个**：

| 约定 | 队空 | 队满 | 元素个数 |
|---|---|---|---|
| 牺牲一个存储单元 | `front == rear` | `(rear+1) % MaxSize == front` | `(rear-front+MaxSize) % MaxSize` |
| 增设 `size` 变量 | `size == 0` | `size == MaxSize` | `size` |

> 元素个数公式是最高频考点：`(rear - front + MaxSize) % MaxSize`。加 `MaxSize` 再取模，是为了让 `rear < front`（已回绕）时仍得到正数。

## 二、关键代码

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;   // 队头元素下标、队尾元素的下一个位置
} SqQueue;

bool EnQueue(SqQueue &Q, int x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;  // 队满
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
```

## 三、配套结论

> 用 `front` 指向队头元素、`rear` 指向队尾元素（而非其后一位）时：队空条件变成 `(rear+1) % MaxSize == front`，队满条件变成 `rear == front`，元素个数变成 `(rear-front+1+MaxSize) % MaxSize`。**换约定就要整体换一套公式，不能混用。**

## 四、典型例题

**例** `MaxSize = 10`，`front = 8`，`rear = 3`，当前队列中有多少个元素？

解 元素个数 $=(3-8+10)\bmod 10=5$。即元素分布在 $8,9,0,1,2$ 五个位置，队头在 8、队尾元素在 2。

## 五、易错点

! ① 混用两套约定：题干说"牺牲一个单元"，就不要用 `rear == front` 判满；这是本题型第一大失分点。

! ② 忘记取模：`rear+1` 到 `MaxSize` 时必须回绕，写成 `rear+1` 会数组越界。

! ③ 元素个数用减法时忘记加 `MaxSize`：`(rear-front) % MaxSize` 在 `rear < front` 时得到负数。

! ④ 混淆 `rear` 的含义：指向"队尾元素"还是"队尾元素的下一个位置"，两种定义的判空/判满/计数公式全部不同。

! ⑤ 循环队列判满不能用 `rear == front`（那是队空），也不要用计数变量以外的第三种写法自创约定。
