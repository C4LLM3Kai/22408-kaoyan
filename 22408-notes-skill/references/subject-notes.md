# 学科内容要点

各科的"一页纸"该写什么、不该写什么。**共同底线：只写能直接拿去做题的内容，不写教材导语、不写背景故事。**

## 数学二（高数 + 线代）

- **一页一个考点**，不要试图把一整章塞进一页。用户问"中值定理"，就做"中值定理"这一页；不要顺手把导数应用全写上。
- **必写**：公式本体、成立条件（闭区间连续 / 开区间可导 / 分母不为零等）、几何意义（一句话）、典型例题一道。
- **公式表**：同一对象的多种形式（如弧长的四种坐标形式、二次型的四种判定）一律用表格。
- **易错点**：这是数学二笔记的核心价值。常见的：漏条件（如洛必达要求 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$）、忘记绝对值、区间端点、极坐标漏平方、参数方程求导对象搞错。
- **不写**：数一/数三专属内容（无穷级数、三重积分、曲线曲面积分、欧拉方程、概率统计）。数二考纲里"了解"级别的严格定义点到为止。
- **计算量大的题**只写关键变形和结果，中间代数步骤省掉。
- 参考工作区：`数学二/资料`（张宇 30 讲、李正元全书、喻老复盘讲义）、`数学二/源文件/考点星级总表.md`、`数学二/源文件/写作规范-数学二.md`。
- 星标沿用 `数学二/源文件/考点星级总表.md` 的星级，不要自己改星。

## 408（数据结构 / 计算机组成原理 / 操作系统 / 计算机网络）

- **一页一个机制或一个题型**（如"循环队列判满""Cache 映射方式""TCP 三次握手"）。
- **必写**：定义/前提、核心公式或流程、一张对照表、伪代码或 C 代码（管线支持 ``` 代码块）、易错点。
- **算法题**：代码只留关键几行（初始化、循环体、边界判断），不要贴完整 50 行；把完整代码放进对话正文。
- **对照表是 408 的杀手锏**：如三种 Cache 映射、四种页面置换算法、五层协议、三种 I/O 方式——一表顶一页。
- **易错点**常见来源：下标从 0 还是 1、`rear` 的两种约定、取模回绕、边界条件（`<` 还是 `<=`）、大小端、字节编址与字编址混淆。
- **不写**：具体机型的硬件细节、已删除考纲的考点、编译器实现细节。
- 参考工作区：`408计算机考研/王道408书`、`408计算机考研/408笔记`、`408计算机考研/源文件/知识点手册`、`408计算机考研/408真题+解析（09-26）`。
- 代码块语法：三个反引号开始，紧跟语言名（`c`、`cpp`、`python`）会渲染成小标题；写 `text` 则不显示标题。

## 英语二

- **一页一个题型或一组语言点**（如"阅读细节题定位三步法""作文首段模板""虚拟语气"）。
- **必写**：判断标志、操作步骤（编号列表）、常见陷阱、一两句可套用的例句。
- **作文模板**：给出可填空的骨架 + 3 个高分替换表达，不要给整篇范文（范文放对话正文）。
- **易错点**：中式英语、时态一致、主谓一致、冠词误用、逻辑连接词误用。
- 参考工作区：`英语二/源文件`、`颉斌斌考研英语阅读-PDF`。

## 政治

- **一页一个原理或一个时间线**（如"矛盾普遍性与特殊性""抗日战争阶段划分"）。
- **必写**：原理表述（原文级别的准确）、方法论意义、对应材料题的答题角度、易混概念对比。
- **时间线**用表格：时间 / 事件 / 意义，三列足够。
- **易错点**：概念混淆（如"主要矛盾"与"矛盾的主要方面"）、时间错位、会议与内容的对应。
- 政治内容时效性强，**涉及当年时政时必须核对最新表述**，不确定就不写进笔记。

## 跨科通用

- 用户问的是**错题**时，笔记标题写成知识点名而不是题号，并在易错点里体现"这道题错在哪"。
- 用户问的是**对比类问题**（如"顺序表和链表的区别"），整页以表格为主，文字只做补充。
- 用户问的是**流程类问题**（如"快排过程""TCP 挥手"），用编号步骤 + 关键状态表。
- 用户连着问同一章的多个问题时，笔记编号递增，但**页脚考点保持一致**，方便日后装订成一册。
