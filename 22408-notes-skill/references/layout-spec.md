# 排版规范

一页纸的目标是**站在打印机前 30 秒能抓住这一节**。所有排版决定都服务于这个目标。

## 一、版面参数（已在 `assets/note-preamble.tex` 中固定）

| 项目 | 取值 | 理由 |
|---|---|---|
| 纸张 | A4 纵向 | 家用打印机默认 |
| 页边距 | 上下 1.15/1.05 cm，左右 1.25 cm | 多数打印机不可打印区约 0.5 cm，留足余量 |
| 字号 | 11pt 起，用 `--auto-fit` 在 12/11/10pt 中挑最大能单页的 | 字号越大越好读，但不得超页 |
| 行距 | 1.14 | 公式密集，行距再大就装不下 |
| 正文 | 宋体（Songti SC），标题黑体（Heiti SC） | 打印清晰、省墨 |
| 西文/数字 | Times New Roman | 与宋体协调 |
| 数学 | LaTeX 默认 Computer Modern | 本机 `mathptmx` 在 XeLaTeX 下会报错，不要启用 |
| 主色 | 深蓝 `#1F4E79`（标题条）、砖红 `#9C2A20`（易错点） | 黑白打印仍有灰度层次，不依赖彩色 |
| 表格 | 三线表，禁竖线 | 竖线在打印件上显脏 |

## 二、页面结构（推荐顺序）

1. **题头**：`title`（一句话说清这页是什么）+ 科目 + 考点，下方一条深蓝细线。
2. **核心公式 / 定义**：整页最重要的东西放最上面，且要给足空间（用 `$$...$$` 独立成行）。
3. **对照表**：多种形式、多种情形的对比一律用表格，比段落快得多。
4. **结论条**（`> `）：必背结论、等价写法、配套公式。浅底衬托，一眼可辨。
5. **典型例题**：一到两道，只写关键步骤，不写"解：由题意得"这类废话。
6. **易错点**（`! `）：2–5 条，放页面最后，是复习时最常回看的部分。

## 三、视觉细则

- **一页纸最多 3 个层次**：小节标题（`##`）→ 段内小标题（`###`）→ 正文。再深就该拆成两页了。
- **小节数量 3–5 个**。少于 3 个说明内容太单薄，多于 6 个说明该拆分主题。
- **表格列数 ≤ 4**，列宽自动分配；单元格内容超过 15 字就换行写进正文。
- **公式不跨页**：本管线强制单页，不存在此问题；但公式之间要留 `\addvspace` 的呼吸感。
- **强调只用粗体**，不用下划线、不用荧光色。一页里加粗不超过 8 处，否则等于没加粗。
- **符号统一**：全篇 `\mathrm{d}` 正体微分；导数用 `y'`；向量用粗体 `\mathbf`；矩阵用大写字母。

## 四、常见排版问题与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 超出一页 | 内容太多或字号太大 | 先 `--auto-fit` 降字号；仍超页则删细节，把展开内容移到对话正文 |
| 版面只用了一半 | 内容太少或字号太小 | `--auto-fit` 会自动选最大字号；仍空则补一条易错点或例题 |
| 表格里公式被压扁 | 单元格用了 `\displaystyle` 但列宽不够 | 去掉 `\displaystyle`，或把该行拆成正文段落 |
| 中文旁边出现方框 | 该字符被判给西文字体且字体无此字形 | 在导言区 `\xeCJKDeclareCharClass{CJK}{...}` 里补该码位 |
| 打印出来左右被裁 | 打印机不可打印区大于 1.25 cm | 打印时选"适合可打印区域"，或把左右边距调到 1.5 cm |

## 五、打印建议（交付时一并告知用户）

- A4 单面，缩放选 **100%（实际大小）**，不要选"适合页面"。
- 需要装订时选"短边装订"；不装订直接单面打印即可。
- 双面打印时请把两页不同主题的笔记配对，避免同主题被拆到正反面。
