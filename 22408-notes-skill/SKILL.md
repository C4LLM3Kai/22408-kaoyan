# 22408 一页纸打印笔记

用户备考 22408（数学二 + 408 + 英语二 + 政治）。**默认约定：只要问题落在 22408 考试范围内，就一边正常作答，一边交付一份 A4 单页、可直接打印的 PDF 笔记。** 不用等用户开口要 PDF，也不要问"需不需要导出"。

范围判定：数学二（高数、线代，不含概率、不含数一/数三专属内容）、408（数据结构、计算机组成原理、操作系统、计算机网络）、英语二（阅读、翻译、写作、词汇语法）、政治（马原、毛中特、史纲、思修法基、时政）。范围外的问题（比如数一的三重积分、计组的超纲硬件细节）照常回答，但**不产出 PDF**，并一句话说明原因。

## 一、执行流程

每次触发都按这五步走，不要跳步：

1. **定位考点**：确认问题对应哪个科目、哪一章、哪条考点。若用户问题含糊，按最可能的考点作答并在笔记页脚标注考点。
2. **核对准确性**：公式、定义、条件、边界情形必须自己推一遍或与工作区资料（`数学二/资料`、`408计算机考研/王道408书`、`408计算机考研/408笔记`、`英语二`）核对。**宁可少写，不可写错**；不确定的内容不进笔记。
3. **写 Markdown**：用本 skill 的语法（见第三节）写成一份笔记源文件，控制在学科字数预算内。
4. **编译并自检**：`check_note.py` → `build_note.py`，然后**必须**打开生成的预览 PNG 逐页目视检查（公式有没有被挤断、表格有没有溢出、是否只有一页）。
5. **交付**：在回答里用 `![说明](<预览图路径>)` 展示成品，用 `[文件名](<路径>)` 链接 PDF，并给出打印建议。正文照常把知识点讲清楚，不要把回答缩成"已生成 PDF"。

> 只有在用户明确说"这次不用出 PDF"或问题超出 22408 范围时，才跳过第 3–4 步。

## 二、文件落位

一律放在用户工作区的对应科目目录下，不要新建平行目录树：

```text
<工作区>/<科目>/一页纸笔记/
├── N001-弧长公式.pdf              ← 最终交付物（顶层只放 PDF）
└── 源文件/
    ├── N001-弧长公式.md           ← 笔记正文（可重编）
    ├── N001-弧长公式.tex          ← 生成的 LaTeX（自包含、可重编译）
    ├── N001-弧长公式.log          ← 编译日志（查缺字/溢出）
    └── preview/
        └── N001-弧长公式-p1.png   ← 自检用预览图
```

- 科目目录名沿用工作区现有写法：`数学二`、`408计算机考研`、`英语二`、`政治`。
- 编号 `N001` 按该科目 `一页纸笔记/` 里已有文件递增；同一考点再次提问且内容有实质更新时，**覆盖同名文件**并保留编号，不要堆 `-v2`、`-最终版`。
- 若用户当次明确要求放在别处（例如某个每日学习文件夹），以用户要求为准。

## 三、笔记 Markdown 语法

只有下列语法会被 `build_note.py` 识别，其他 Markdown 会被当普通文字转义：

| 写法 | 渲染结果 |
|---|---|
| `---` 开头的 frontmatter | 元信息：`title` / `subject` / `topic` / `footer` |
| `## 一、xxx` | 小节标题（蓝色竖条 + 黑体 + 细分隔线） |
| `### xxx` | 段内小标题（黑体，不占一整行块） |
| `> 内容` | 结论条（浅蓝底，放必背结论） |
| `! 内容` | 提醒条（红色左竖条，放易错点/适用条件） |
| `- ` / `1. ` | 无序 / 有序列表 |
| `\| a \| b \|` + 分隔行 | 三线表（自动等宽自适应，禁竖线） |
| `$$...$$` | 行间公式 |
| `$...$` | 行内公式 |
| `**粗体**`、`*斜体*`、`` `代码` `` | 行内样式 |
| `[[cols2]]` … `[[/cols2]]` | 双栏区（左右分栏，中间有细线） |
| `---` 单独一行（3 个以上） | 分隔线 |

Frontmatter 示例：

```markdown
---
title: 弧长公式
subject: 数学二
topic: 高等数学 · 定积分应用
footer: 22408 一页纸笔记 · 数学二
---

## 一、四种形式（母公式 $\mathrm{d}s=\sqrt{\mathrm{d}x^2+\mathrm{d}y^2}$）
...
```

## 四、排版与内容规范

**准确优先于好看。** 一页纸的价值在于"扫一眼就能用"，所以：

1. **必须写适用条件**：公式成立的前提、参数的取值范围、定义域限制。漏条件的公式是负资产。
2. **必须写易错点**：用 `! ` 条列出 2–4 条，是这份笔记区别于教材目录的关键。
3. **来源可核对**：笔记正文不必写出处，但在回答里说明依据（考纲条目 / 教材章节 / 工作区哪份资料）。
4. **符号统一**：导数用 $y'$ 或 $\frac{\mathrm{d}y}{\mathrm{d}x}$，全篇一致；微分用 $\mathrm{d}$ 正体；矩阵用粗体或大写字母，别混用。
5. **控制篇幅**：单页硬约束。数学类约 3000 字（含公式），408 约 3400 字。超页就砍细节、留主干，把展开内容放进对话正文。
6. **标题短**：`title` 控制在 12 个汉字内，方便做文件名。
7. **不放外部图片、不放 tikz**：一页纸只用文字、公式、表格、结论条表达。需要图时改用文字描述或表格。

结构与视觉细节见 [排版规范](references/layout-spec.md)，各学科的内容取舍见 [学科要点](references/subject-notes.md)。

## 五、工具链

```bash
# 0. 环境（首次或换机时执行）
python3 scripts/doctor.py

# 1. 编译前检查（挡公式未闭合、超纲宏、缺字风险、超篇幅）
python3 scripts/check_note.py 数学二/一页纸笔记/源文件/N001-弧长公式.md --subject 数学二

# 2. 编译成 PDF（自动校验单页 + 缺字 + 溢出，并渲染预览图）
python3 scripts/build_note.py \
    数学二/一页纸笔记/源文件/N001-弧长公式.md \
    数学二/一页纸笔记/N001-弧长公式.pdf \
    --title 弧长公式 --subject 数学二 --topic 高等数学·定积分应用

# 3. 逐页目视检查预览图（必做）
#    打开 数学二/一页纸笔记/源文件/preview/N001-弧长公式-p1.png
```

`build_note.py` 的退出码：`0` 成功；`1` 编译失败；`2` 页数超过一页；`3` 有缺字。**退出码非 0 时必须修复后重跑**，不得把不合格的 PDF 交给用户。

PDF 一律由 XeLaTeX 实际编译产生（这是本 skill 的硬约束）：不允许用网页打印、Word 导出、ReportLab 等方式替代。编译器不可用时先跑 `doctor.py` 排查；确实无法编译时，明确告知用户"PDF 尚未生成"，并先交付 Markdown 与 LaTeX 源文件。

## 六、交付话术

回答里同时给出：知识点正文（讲清概念、条件、用法）+ 预览图 + PDF 链接 + 打印建议（"A4 单面、100% 比例、无需缩放"）。若这次只更新了已有笔记，说明改了哪几处。不要只说"已生成"。
